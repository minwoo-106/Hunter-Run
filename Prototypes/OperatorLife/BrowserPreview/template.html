오퍼레이터 생활 모션

오퍼레이터의 생활 모션 시연이에요. 기본 자세 위치를 유지하고 커피·태블릿·멍때리기·머리 넘기기·햄버거와 콜라를 추가했어요. 아래 버튼으로 새 행동을 골라보세요. 졸거나 햄버거를 먹을 때 캐릭터를 누르면 반응해요.

햄버거 먹기 → 캐릭터 터치 → 볼 빵빵한 놀람 → 콜라 한 모금 → 다시 쉬기

별도 PoC build 52에서 두 iPhone 크기의 앱 검사를 통과했어요. 기존 build 51 설치본에는 새 행동이 없습니다. 실제 앱 화면과 녹화 보기 · 브라우저용 임시 시연입니다. PNG 자세 전환과 작은 움직임을 사용하며 Cubism 리깅이나 실제 iOS 렌더링은 아닙니다. 새 기본 자세에 맞춘 눈깜빡임도 넣었습니다. 상단·하단 UI는 배치 참고용입니다.
