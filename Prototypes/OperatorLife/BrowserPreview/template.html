오퍼레이터 생활 모션

캐릭터를 위로 올린 위치 조정 시연이에요. 기본 자세 위치는 그대로 두고, 기지개 때 손이 위쪽 여백까지 보이도록 했어요. 캐릭터가 졸기 시작하면 직접 눌러보세요.

기지개 → 편안히 쉬기 → 꾸벅꾸벅 → 터치 → 화들짝 → 머쓱함 → 다시 쉬기

이번 위치 조정은 브라우저 시연과 앱 소스에 반영됐어요. 기존 build 51 설치본에는 아직 반영되지 않았습니다. 브라우저용 임시 시연입니다. PNG 자세 전환과 작은 움직임을 사용하며 Cubism 리깅이나 실제 iOS 렌더링은 아닙니다. 새 기본 자세에 맞춘 눈깜빡임도 넣었습니다. 상단·하단 UI는 배치 참고용입니다.
