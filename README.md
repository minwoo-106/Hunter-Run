## 최신 업데이트 — 1.9.2 / 빌드 65

- 주요 보스는 첫 공략 전에 얻을 수 있는 장비를 기준으로 교전 거리를 조정했습니다. Lv.30 비교에서 경계의 군주·첫 코어 1,050m, 공허의 사서·거울결 2,400m, 최종 보스·철갑 5,025m입니다.
- 일반·정예·선발대와 승급 심사도 역할별 HP를 조정했습니다. 공격 간격 75m, EXP, 장비 공격력과 해금 조건은 유지합니다.
- 이미 시작한 보스의 최대·남은 HP와 진행 중 활동의 전투 스냅샷을 보존합니다. 새 수치는 새 공략부터 적용됩니다.
- [모든 개체·재전·심사 37종의 장비별 거리표](docs/1.9.2-combat-balance.md)와 [변경·검증·설치 안내](docs/1.9.2-release.md)를 제공합니다. 거리표는 실제 전투 계산으로 생성합니다.
- 게임 엔진 309개, 센서 입력 재생 12개와 거리 조합 2,664개를 로컬 검증했습니다. 아이폰 빌드·화면 검증 상태는 설치 안내에 기록합니다.

## 게임 소개

대한민국 곳곳에 정체불명의 게이트가 나타난 뒤, 플레이어는 헌터 협회의 신규 조사 인원으로 배정됩니다. 현실에서 걷고 달리는 동안 오퍼레이터의 음성 안내를 받아 마력 흔적을 조사하고, 몬스터와 조우하며, 장기 토벌과 지부 성장에 참여합니다.

단순히 이동 거리를 숫자로 기록하는 대신 매 활동이 하나의 의뢰가 됩니다. 같은 경로를 달려도 선택한 모드, 진행 중인 퀘스트, 해금된 개체와 보스 상태에 따라 다른 사건과 대사가 등장합니다.

## 주요 기능

- **야외 헌터 활동**: 탐험, 일반 게이트를 추적하는 현장 사냥, 대상이 정해진 고위험 보스전을 시간·거리·자유 목표로 진행합니다.
- **상황형 음성 플레이**: 오퍼레이터가 출발, 조사, 조우, 전투 결과와 1km 단위 이동을 한국어 음성으로 안내합니다.
- **75m 거리 전투**: 조우 안내 후 인정된 달리기 75m마다 공격합니다. 걷기·정지·GPS 불량 구간에서는 일반 전투의 공격을 보류하고, 화면에 몬스터 HP와 다음 공격 누적을 따로 표시합니다. 일반 몬스터의 미완료 HP는 다음 활동에서 초기화하고 주요 보스는 실제 피해를 누적합니다.
- **지부 방어 작전**: 회차당 24분, 3강도, 20종의 저소음 운동을 조합한 30회 완결 홈트 캠페인입니다. 준비·서서 하는 운동·회복·자세 전환·바닥 운동·정리 순서로 안내하며, ‘서서 하기’를 선택하면 바닥 동작을 대체합니다. 연속 출석 없이 이어가며 강도에 관계없이 같은 이야기와 생활 일러스트를 받습니다. 예전 실내 운동 기록과 진행 중인 이전 루틴은 보존합니다.
- **스토리와 오퍼레이터**: 이름을 정한 파트너와 대화하고 관계를 쌓으며, 활동과 성장 조건에 따라 메인 스토리와 개인 이야기를 해금합니다.
- **헌터 성장**: 활동 레벨은 운동 누적 성장, 등급·스토리·시설은 콘텐츠 접근, 장비는 전투 성능을 담당합니다. 탐색 중심의 E급 고레벨도 유지하며, 증가하는 레벨업 요구량과 공격력 소프트캡을 적용합니다.
- **수집 콘텐츠**: 26종의 개체 일러스트, 무기·신발·유물 26종, 다단계 협회 시설과 활동 기록을 제공합니다. 단종 방어구 10종의 자료는 기존 세이브 이행과 과거 기록 확인용으로 보존합니다.
- **오프라인 중심**: 게임 진행, 음성, 이미지와 저장 데이터가 기기 안에서 작동합니다.

## 플레이 흐름

1. 헌터 활동에서 야외 활동 또는 지부 방어 작전을 선택합니다.
2. 야외에서는 탐험·현장 사냥·게이트와 시간·거리·자유 목표를 정하고 걷거나 달립니다.
3. 집에서는 다음 방어 작전의 강도를 정하고 24분 동안 운동 안내를 따라갑니다.
4. 야외는 거리·페이스·사건 결과를, 방어 작전은 완료 회차·선택 강도·후일담을 확인합니다.
5. 획득한 자원으로 성장하고 다음 이야기와 토벌, 생활 일러스트를 엽니다.

## 설치와 기기 요구사항

현재 Hunter Run은 App Store에 공개하지 않은 개인 개발 빌드입니다. macOS 빌드에서 만든 unsigned IPA를 Windows의 AltStore Classic으로 개인 서명해 설치합니다.

- iPhone, iOS 17 이상
- 야외 활동 시 위치 접근과 **정확한 위치** 허용
- 야외 걷기·달리기 판정을 위한 동작 및 피트니스 권한. 방어 캠페인은 GPS·Apple Watch 없이 시간 안내로 진행합니다.
- Apple Watch는 필수가 아니며, 비교 측정과 별도 운동 기록에 사용할 수 있습니다.
- 음성 안내를 위해 AirPods 또는 안전한 오픈형 이어폰 사용을 권장합니다.

## 개인정보와 저장

정확한 이동 좌표는 저장하지 않습니다. 활동 결과와 게임 진행은 iPhone 내부에 저장되며, 서버 계정·광고·분석 SDK·결제 기능은 현재 포함하지 않습니다. 설정에서 진행 데이터를 내보내거나 가져올 수 있습니다.

## 개발 정보

Hunter Run은 SwiftUI, Core Location, Core Motion과 AVFoundation으로 만든 네이티브 iOS 앱입니다. 게임 규칙은 `HunterCore` 모듈로 분리되어 Linux/macOS에서 테스트할 수 있고, 실제 iPhone 앱은 macOS 빌드 환경에서 컴파일합니다.

```sh
swift test
python3 scripts/validate.py
```

코어 테스트와 콘텐츠·음성·이미지 검증을 실행합니다. GPS 거리와 페이스, 센서 민감도, 오디오 타이밍은 iPhone 17 Pro 실기기 테스트를 계속 반영하고 있습니다.
