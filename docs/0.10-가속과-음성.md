# 0.10 · 선택적 가속과 음성 일관성

## 변경
- 신고된 음성14개를 A 방식으로 재제작. 전체 ‘우와’를 ‘대단해요/좋아요’로 교체.
- 기존 기본 안내 및 새 보스/가속 안내를 합쳐64개 음성. 참고 번호1~56은 이전 목록 순서를 유지.
- 설정의 ‘선택적 가속 허용’: 실제 가속을 감지한 경우에만 추격/보스 가속 공격을 선택.
- 기준 속도보다8% 빠른 움직임이4초 지속되면 선택. 그4초를10초 안에 포함하며, 가속 안내가 끝나기 전에는 판정하지 않음.
- 보스 가속을 선택하지 않으면30초 유지 공격. 추격을 선택하지 않으면 흔적 조사. 선택 거절 자체에는 피해/페널티 없음.
- 활동당 최대2회, 마지막 가속 종료 후180초 동안 다음 가속 금지. 첫60초 새 전투는 조사로 전환.
- GPS 불량·걷기·기준 미확보·회복 상태에서는 가속을 제안하지 않음. 주요 보스는 이때 유지 공격 또는 조사로 변환.
- 두 보스 각3단계에 가속/유지 조합. 활동 화면 남은 가속 시간과 회복 시간 표시.
- 중단/복구 시 남은 시간만 이어가며 가속 횟수를 중복 차감하지 않음. 보스 피해 저장과 모의 활동 보상 차단 유지.

## 확인
1. 토벌 게시판에서 공허의 사서 ‘모의 준비’를 열어 ‘20분 보스 패턴 모의 활동 · 가속 포함’을 실행.
2. 가속 안내를 들은 뒤 모의 속도를 기본보다 조금 높이면10초 가속 공격. 이후 편하게 회복하라는 안내와 회복 표시 확인.
3. 같은 조건에서 가속하지 않으면 유지 공격 안내가 나오는지 확인.
4. 실제 활동은 준비 화면에서 선택적 가속을 켠 경우에만 제공. 첫 활동은 기준 페이스를 확보하기 전까지 유지/조사로 대체될 수 있음.
5. 음성14개를 다시 듣고 중간에 음색이 바뀌면 번호와 앞/뒤 문장을 알려주기.
