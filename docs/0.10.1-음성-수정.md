# 0.10.1 · 음성 끝 잡음 제거와 최종 수정

- 28번 균열 살쾡이 기습 안내의 마지막0.5초 제거. 6.359초→5.859초. 원본 후보는 보존했습니다.
- 57번 경계의 군주 가속,61번 가속 시작,64번 가속 결과를 사용자가 선호한 새 후보로 교체했습니다.
- 나머지60개는 파일 그대로 유지했습니다. 총64개이며 번호도 같습니다.
- 0.10에서 추가한 선택적10초 가속,30초 유지 공격,가속 사이180초 회복 및 활동당2회 제한이 포함됩니다.

## 먼저 확인

1. 업데이트 후 홈 아래 FIELD DEMO · 0.10.1 확인.
2. [전체 음성 청취](http://127.0.0.1:8769/0.10.1/)에서28번 끝과57/61/64 확인. 이 주소는 개발PC에서 여는 목록입니다.
3. 게임은 토벌 게시판→보스 모의 준비→20분 보스 패턴 모의 활동 · 가속 포함으로 확인. 모의 활동은 실제 보상이나 보스 HP를 바꾸지 않습니다.
4. 실제 활동에서 가속 이벤트를 보려면 준비 화면의 선택적 가속 허용을 켭니다. GPS/걷기/기준 페이스 조건에 따라 유지 또는 조사로 바뀔 수 있습니다.
