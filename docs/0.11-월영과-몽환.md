# 0.11.0 · 월영과 몽환

신규 개체 4종, 장비 8종, 협회 부서 Lv.3, 전용 안내 16개를 연결한 콘텐츠 확장입니다.

## 바로 체험하기

헌터 활동 → 신규 개체 · 월영과 몽환 → 원하는 개체의 모의 활동 준비 → 선택 개체 모의 활동 시작.
모의 활동은 10배속으로 진행됩니다. 개체 안내가 끝난 뒤 대응 판정이 시작됩니다. 모의 체험으로 실제 자원·도감·장비가 해금되지는 않습니다.

| 개체 | 실제 출현 조건 | 대응 | 연계 장비 |
|---|---|---|---|
| 다크엘프 정찰자 | 처음부터 | 25초 기습 대응 | 월영 방어구·신발, 지원부2 |
| 서큐버스 환영술사 | 연구부2 | 35초 유지 | 몽환 방어구·신발, 지원부2 |
| 다크엘프 월영대장 | D급·관측부3 | 400m 전진, 짧은 활동은30초 유지 | 월영 무기·유물, 지원부3 |
| 서큐버스 몽환경비관 | D급·의뢰부3 | 선택적10초 가속 또는30초 유지 | 몽환 무기·유물, 지원부3 |

개체는 기존 의뢰·일반 게이트 사건 자리에 번갈아 출현합니다. 탐험에서는 일반 개체의 흔적 조사만 나옵니다. 주요 보스와 게이트 핵 사건은 유지됩니다. 출현 후보와 선택 규칙을 활동 시작 시 저장하므로 복구해도 개체가 바뀌지 않습니다.

장비는 해당 개체의 실제 발견 기록, 장비지원부 단계, 구매 자원이 필요합니다. 연구부3에서는 상세 전술과 연계 장비 분석을 확인할 수 있습니다. 처음 보는 그림은 협회 공개 자료이며 도감 해금과 구분됩니다.

기존 승인 음성64개는 변경하지 않고 같은 기준 음색으로16개를 추가했습니다. 총80개. 생성 음성은 대사별 청취 피드백을 계속 반영합니다.

새 이미지12개는 builtin image_gen으로 개별 제작했습니다. 프롬프트·원본 위치는 expansion-011-monster-art.json / expansion-011-gear-art.json에 기록했습니다. 앱 자산은 Resources/Assets.xcassets에 있습니다.

## 확인할 사항

- 네 개체 모의 체험의 이미지·안내·대응·결과 연결.
- 실제 탐험/의뢰 종료 후 발견 기록과 장비 잠금 해제.
- 협회 부서2→3 순차 확장, 활동 중 변경 차단.
- 기존 기록을 보존한 업데이트와 진행 중 활동 복구.

이 버전은 v1 완성이 아닙니다. 추가 효과음, 현장 GPS/백그라운드·가속 밸런스, 장기 성장과 복귀 콘텐츠 검증은 계속 진행합니다.
