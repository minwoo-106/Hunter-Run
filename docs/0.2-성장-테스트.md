# 0.2 성장 연결 데모

## 이번 버전

- RUN에서 탐험·헌터 의뢰·고위험 게이트 선택. 고위험 게이트는 관측부 Lv.2와 D급 평가 통과 후 입장.
- 탐험은 발견 3개와 조사 데이터, 의뢰는 기본 사건 4개, 게이트는 사건 5개와 보스 코어 보상.
- 무기·방어구·신발·유물 4슬롯, 장비 12종. 자원으로 확보하고 직접 장착.
- HP·공격·피해 경감·이벤트 피해·조사 보상 패시브. 요구 속도와 판정 기준은 장비로 변경하지 않음.
- 관측부: 게이트 접근. 연구부: 도감 분석. 장비지원부: 고급·코어 장비. 의뢰부: 45분 목표 및 20분 이상 의뢰의 추가 발견 사건.
- E~S 승급 평가. 레벨뿐 아니라 목표 완료 기록과 게이트 보스 토벌 조건 필요. 조건을 충족한 뒤 평가 버튼으로 승급.
- 결과에 조사 데이터와 코어 표시. 모의 러닝은 성장 보상 없음.

## 확인 순서

1. 업데이트 전 메뉴 → 백업 파일 만들기에서 기존 기록을 보관할 수 있습니다.
2. 기존 앱에 덮어 설치한 뒤 화면 아래 0.2.0과 기존 헌터명·경험치·기록을 확인합니다.
3. 홈 상단 ‘헌터 협회 · 지부 관리’ 또는 헌터 → 협회 부서 관리에서 네 부서를 확인합니다.
4. 헌터 → 장비 보관함에서 슬롯별 장비·비용·장착 상태를 확인합니다. 초기 장비는 마정석 4개부터 확보할 수 있습니다.
5. RUN의 탐험을 선택하고 5분 점검 또는 3분 모의 러닝을 실행합니다. 탐험은 걷기로도 발견 조사가 진행됩니다.
6. 실제 러닝 후 결과 자원을 확인하고 장비 확보/시설 확장에 사용합니다. 앱 재실행 후에도 구매·장착·부서 레벨이 남아야 합니다.
7. D급 조건은 Lv.2와 목표 완료 2회입니다. 헌터 → 협회 평가에서 확인합니다. 고위험 게이트에는 관측부 Lv.2도 필요합니다.

활동 또는 복구할 기록이 있으면 성장 변경을 막습니다. 해당 활동의 장비 능력치와 의뢰 구성은 시작 시 저장되어, 복구 후에도 유지됩니다.

## 아직 남은 v1 작업

거리·자유 목표, 장기 개인 페이스, 여러 러닝에 걸친 주요 보스 HP 누적,
온보딩·세계관 소개, 몬스터/장비 전용 일러스트, 협회 배경 성장 단계,
정식 오퍼레이터 목소리·BGM·음성 변주, 추가 이벤트/몬스터 콘텐츠와 장기 밸런스.

이번 성장 비용과 승급 기준은 실제 플레이 피드백을 받을 초기 수치입니다.
실기기에서 설치·0.1.1 홈 화면·스피커/AirPods 음성 재생은 사용자 확인을 받았습니다.
화면 잠금 GPS·자동 정지/재개·배터리 소모의 야외 검증은 계속 필요합니다.
