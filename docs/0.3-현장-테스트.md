# 0.3.0 현장·장비 업데이트

## 이번 묶음
- 홈의 큰 버튼을 협회 관리로 변경. 하단 중앙 RUN을 조금 더 크게 강조했습니다.
- 무기·방어구·신발·유물 12종 개별 일러스트를 보관함·장비 상세·착용 현황에 적용했습니다.
- 보유 장비 필터와 상세 화면에서 구매·착용을 연결했습니다.
- 시간 목표 외에 1/3/5/10 km 거리 목표와 자유 활동을 추가했습니다.
- 지난 활동의 거리, 활동시간, 달리기/걷기 시간, 목표, 사건과 보상을 확인할 수 있습니다.
- 메뉴에 활동과 성장 가이드를 추가했습니다.

## 설치 후 확인
기존 앱을 삭제하지 않고 같은 Apple 계정으로 업데이트합니다. 홈의 FIELD DEMO · 0.3.0을 확인하세요.
AltStore에 7 DAYS가 표시되는 것만으로는 버전 업데이트가 확인되지 않습니다.
설치 시 iPhone을 연결한 눈앞 PC에서 AltServer를 실행해야 합니다.

1. 홈의 협회 관리가 부서 화면으로 열리고 하단 RUN이 러닝 준비로 이동하는지 확인합니다.
2. 헌터 → 장비 보관함에서 네 종류의 이미지와 상세 보기를 확인합니다. 장비를 확보했다면 장착 후 헌터의 현재 착용 장비에 나타나는지 확인합니다.
3. RUN에서 거리 → 1 km로 짧은 실제 활동을 진행합니다. 정지한 동안 거리가 부풀지 않고, 기록 거리가 목표에 도달하면 종료되는지 확인합니다.
4. 자유 활동은 자동 종료하지 않습니다. 안전한 곳에서 활동 종료 → 저장하고 종료를 누릅니다. 결과는 헌터의 활동 기록에서 확인합니다.
5. 화면 잠금 중 기록과 음성, 통화·이어폰 변경 후 재개도 실기기 확인이 필요합니다.

## 목표에 따른 규칙
시간·거리 목표는 달성하면 현재 사건을 중립 종료하고 성과를 정산합니다. 일찍 종료해도 이미 확보한 보상은 저장합니다.
자유 활동에는 경험치와 자원 보상이 있지만 승급의 목표 완료 횟수에는 포함되지 않습니다.
거리·자유 활동의 사건은 활동시간 20분 주기로 다시 이어집니다. 이는 새 이야기 묶음이 아니라 기존 모드 사건의 반복 순찰입니다.
반복된 게이트 보스를 여러 번 잡아도 한 활동당 코어와 게이트 완료 기록은 최대 1회입니다.
거리 측정은 GPS·보조 센서 품질에 영향을 받습니다. 실제 거리와의 오차와 배터리 사용량은 실기기로 확인해야 합니다.

## 저장 호환
이전 기록과 성장 데이터는 유지하도록 구현했습니다. 이전 기록에 없었던 목표·달리기 시간은 임의로 만들어 표시하지 않습니다.
활동 복구 시 저장된 목표·장비·사건 구성을 사용합니다. 이전 앱으로 다운그레이드하는 것은 지원하지 않습니다.
