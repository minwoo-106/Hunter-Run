# 0.4.0 · 보스와 협회 성장

기존 앱을 삭제하지 않고 같은 Apple ID로 IPA를 덮어 설치합니다. 홈 하단 버전은 0.4.0입니다.

## 먼저 볼 것
1. 홈의 큰 RUN → 기존 시간·거리·자유 활동 준비.
2. 하단 중앙 협회 관리 → 주요 보스 토벌 → 보스 이미지와 남은 HP.
3. 잠겨 있어도 ‘모의 토벌 준비’ → 아래 ‘3분 모의 러닝’으로 체험. 실자원·HP·도감은 변경되지 않습니다.
4. 도감 → 미발견 개체를 실제 활동에서 조사하면 일러스트 공개. 기존 사건 기록도 반영합니다.
5. 메뉴 → 협회 BGM 켜기/끄기·음량. 홈과 협회에서만 재생하며 다른 앱 음악이 있으면 양보합니다.

## 실제 토벌
- 경계의 군주: D급 + 관측부 Lv.2, HP 300.
- 공허의 사서: C급 + 관측부 Lv.2, HP 540.
- 활동 종료 시 피해와 남은 HP를 저장하고 다음 활동에서 이어갑니다.
- HP 70%/35% 경계에서 사건 구성이 변합니다. 달려야 하는 속도 기준을 올리지는 않습니다.
- 걷기·GPS 불안정·일시정지는 보스 공격 성과로 바뀌지 않습니다.
- 토벌한 활동에 추가 EXP 120·마정석 15·코어 2를 한 번 지급합니다.
- 완료 후 게시판에서 새 회차를 열어야 HP가 초기화됩니다.

## 협회 외형
네 부서 중 2개가 Lv.2이면 정식 관측 지부, 4개 모두 Lv.2이면 광역 작전 지부입니다.
홈과 관리 화면에 새 배경이 적용됩니다. 기존 강화 효과는 그대로 유지됩니다.

## 소리 확인
BGM은 직접 합성한 초안이고, 오퍼레이터는 기존 임시 한국어 음성입니다.
음악 앱 재생 중 홈 진입, RUN 진입, 화면 잠금, 에어팟 분리 시 BGM이 멈추는지 확인해주세요.
실제 운동의 위치 추적·음성 혼합·복구는 아이폰 현장 확인이 필요합니다.
