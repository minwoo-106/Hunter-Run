# 0.5.0 · 이어지는 BGM과 협회 통신

## 이번 변경
- 홈·헌터·장비·도감·메뉴·협회 관리·통신 기록에서 같은 BGM을 이어 재생합니다.
- RUN 준비와 진행/결과 화면에서는 BGM이 멈춥니다. RUN 준비 위로 협회 관리가 열리면 보이는 협회 화면에 맞춰 재생합니다.
- 앱이 배경으로 가거나 외부 음악이 재생 중이면 BGM이 쉬어갑니다. 기존 음악 설정은 유지합니다.
- 4장의 건너뛸 수 있는 첫 이용 안내. 기존 저장이 있으면 강제로 보여주지 않고 메뉴에서 다시 볼 수 있습니다.
- 협회 통신 6편. 실제 활동·시설 확장·주요 보스 토벌로 순서대로 열립니다. 기존 기록도 반영합니다.
- 읽음 표시 저장과 홈의 새 통신 건수. 읽기 자체에는 자원 보상이 없습니다.

## 아이폰에서 확인
1. 홈에서 음악을 들으며 헌터 → 장비 → 도감 → 메뉴 → 협회 관리로 이동합니다. 매번 곡이 처음부터 시작하거나 끊기지 않는지 확인합니다.
2. 홈의 RUN을 누르면 BGM이 멈추는지, 준비 화면 위에 협회를 열면 음악이 나오고 닫으면 멈추는지 확인합니다.
3. 메뉴에서 BGM 끄기·켜기·음량 변경을 확인합니다. 다른 앱 음악 재생 시 이 앱의 BGM이 겹치지 않아야 합니다.
4. 협회 관리 → 협회 통신 기록을 엽니다. 첫 기록을 읽고 ‘기록 확인 완료’를 누르면 읽음으로 바뀌어야 합니다. 앱을 다시 열어도 유지됩니다.
5. 잠긴 기록에는 본문 대신 해금 조건이 표시됩니다. 모의 활동으로는 후속 기록이 열리지 않습니다.
6. 메뉴 → 첫 이용 안내 다시 보기. 네 장을 앞뒤로 넘길 수 있고 모든 페이지의 ‘건너뛰기’가 작동해야 합니다. 권한이나 소리 테스트는 버튼을 눌렀을 때만 실행됩니다.

오퍼레이터 음성과 BGM은 임시 제작본입니다. 이번에 추가한 통신은 읽는 이야기이며 새로운 음성 대사가 추가된 것은 아닙니다.
