# 0.6.0 · 헌터 활동과 개인 기준

- BGM은 활동 준비 화면에서도 이어지고 실제/모의 활동을 시작할 때 멈춥니다.
- 홈은 ‘헌터 활동’, 시작 버튼은 ‘현장 탐험 시작 / 헌터 의뢰 시작 / 게이트 조사 시작 / 보스 토벌 시작’입니다.
- 활동 중 페이스는 최근 12초의 속도를 시간 가중 평균해 표시하며 급격한 숫자 변화를 제한합니다. 처음 3초·정지·GPS 불안정 시에는 —로 표시하고 재출발 때 새로 모읍니다. 거리·시간·전투 판정에는 이 표시 보정을 적용하지 않습니다.
- 헌터 → 나의 활동 기준에서 현재 참고 페이스와 최근 반영 횟수를 봅니다. 활동 준비에서도 접근합니다.
- GPS가 양호한 달리기 구간 5분 이상을 확보한 실제 활동만 학습합니다. 걷기·정지·차량·신호 불안정·사건 중·전투 직후 1분은 제외합니다.
- 한 활동에서 최대 30분의 적격 구간을 0.1m/s 구간별 시간으로 모읍니다. 최근 5회 중앙값, 활동당 기준 속도 변화 ±5% 제한을 사용합니다.
- 과거 기준이 오늘 관측한 페이스보다 빠르면 오늘의 느린 값을 사용합니다. 학습 전에는 실제 추격이 조사로 전환됩니다.
- 결과와 활동 상세의 ‘현장 관측 보고’에서 GPS 상태, 학습 가능 구간, 반영 여부를 확인합니다.
- 학습 초기화는 확인 후 적용하며 활동 기록·자원·장비는 유지합니다. 초기화 뒤 이전 보고의 기준은 당시 기록으로 남지만 다시 학습에 넣지는 않습니다.
- 기존 저장은 유지하며, 예전 기록에 없던 센서 표본을 새로 추측해 만들지 않습니다. 모의 활동은 실제 기준을 바꾸지 않습니다.

## 기기 확인
1. 홈 → 활동 준비 → 모드 변경 → 협회 열기/닫기 동안 곡이 끊기지 않는지 확인합니다.
2. 모의 활동을 시작하면 BGM이 멈추고 안내 음성이 들리는지, 종료 후 돌아오면 음악이 이어지는지 확인합니다.
3. 20~30분 실제 활동 뒤 관측 보고를 확인합니다. 학습 가능 구간이 5분 미만이면 참고 기준을 유지하는 것이 정상입니다.
4. 앱 재실행 후 학습 기준이 유지되는지, 초기화 시 활동 기록은 그대로인지 확인합니다.
5. 일정한 속도로 1~2분 걷거나 가볍게 달린 뒤 정지·재출발하며 최근 페이스가 안정되는지 확인합니다. 실제 속도 변경은 약 12초에 걸쳐 반영됩니다.

화면 명칭은 바뀌었지만 기존 임시 음성 클립은 유지합니다. 최종 캐릭터 음성과 전체 음성 대사 교체는 후속 제작입니다.
