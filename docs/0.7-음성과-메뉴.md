# 0.7 · 활동 중심 메뉴와 음성 후보

## 메뉴
- 하단: 홈 / 헌터 / 헌터 활동 / 협회 관리 / 도감.
- 중앙 헌터 활동이 가장 크며 활동 준비 화면을 엽니다.
- 협회 관리는 그 오른쪽에서 기존 관리 화면을 엽니다.
- 홈의 큰 활동 카드를 제거했습니다. 이름·등급 아래 44pt 톱니바퀴로 설정을 엽니다. 텍스트는 숨기되 VoiceOver에는 ‘설정’으로 읽힙니다.
- 설정을 닫으면 기존 화면을 유지합니다. 설정의 첫 이용 안내는 설정을 닫은 뒤 별도 안내로 열립니다.

## 화면 유지
- 앱이 전면에 있고 미종료 활동 화면이 열려 있으면 자동 잠금을 막습니다. 일시정지 상태도 진행 중인 활동으로 봅니다.
- 활동 종료/결과, 홈/준비/협회/도감/설정, 앱 비활성 상태에서는 iOS의 원래 자동 잠금 동작을 따릅니다.
- 전원 버튼으로 직접 잠글 수 있습니다. 화면 잠금 상태의 활동 기능은 유지합니다.
- 실제 기기의 자동 잠금을 30초로 설정한 상태에서 준비 화면과 활동 화면, 종료 뒤 화면을 비교합니다.

## 오퍼레이터 음성 제작 상태
- 기본 여성 프리셋 A~E는 사용자의 기대와 달라 정식 음성으로 채택하지 않았습니다. 앱에는 기존 임시 안내 음성을 유지합니다.
- 새 음색을 설명으로 설계하는 Qwen3-TTS VoiceDesign을 로컬 PC에서 준비 중입니다. 실제 생성과 사용자 청취 후 결정합니다.
- UI와 화면 유지 변경은 음색 확정과 별개로 검증합니다.
- `scripts/generate-voice-candidates.py`와 Supertonic 모델 라이선스는 이전 비교본의 재현 기록입니다. 거절된 WAV는 앱에 포함하지 않습니다.
