# 0.8.0 · 오퍼레이터와 현장 사건

## 이번 변경
- 사용자가 선택한 성인 오퍼레이터 음색을 기본 14문장과 추가 5문장, 총 19개에 적용했습니다. 활동 시작/발견 WAV는 승인한 실제 대사 샘플과 해시가 동일합니다.
- 큰 눈, 귀여운 성인 인상, 남색 브릿지의 마지막 캐릭터를 적용했습니다. 배경은 실제 투명 alpha입니다.
- 장기전: 완만한 페이스로 400m를 이동합니다. 20분 이상 시간 목표 / 3km 이상 거리 목표 / 자유 활동의 의뢰와 게이트에서 등장합니다. 짧은 목표에서는 30초 견제로 바뀝니다.
- 기습 대응: 가속 없이 달리기 상태를 25초 유지합니다. 정지 중에는 판정이 멈춥니다.
- 사건 시점에 작은 변화를 주고 재실행 후에도 같은 일정으로 복구합니다. 도감 식별자와 20분 순찰별 중복 방지는 유지합니다.
- 발견/성공/부분 확보 안내는 두 대사를 번갈아 사용합니다. 사건 시작은 실제 안내 재생이 끝난 뒤입니다.
- HP 소진 후 회복 구간은 전투 대신 조사로 진행합니다.
- 준비 화면의 현장 사건 안내, 장기전 거리 표시, 20분 의뢰 모의 활동을 추가했습니다.

## 설치
새 빌드의 HunterRun-0.8.0-build9-install.zip을 iPhone 파일 앱에서 한 번 압축 해제하고, 안의 HunterRun-0.8.0-build9-unsigned.ipa를 AltStore My Apps의 +에서 선택합니다. 같은 Apple 계정으로 기존 앱 위에 설치합니다. 기존 앱을 삭제하면 저장 기록을 잃을 수 있습니다.
홈 하단과 설정의 개발 상태에서 0.8.0을 확인합니다. Codemagic 다른 아티팩트 묶음이나 소스 ZIP은 설치 파일이 아닙니다.

## 먼저 확인
1. 설정의 안내 음성 테스트, 새 캐릭터 눈/남색 머리 가닥, 준비 화면까지 이어지는 BGM.
2. 헌터 활동 준비 → 현장 사건 안내에서 장기전/기습 설명 확인.
3. 준비 화면 하단 20분 의뢰 모의 활동 → 진행 속도 10배. 기본 달리기 상태를 유지하면 장기전에서 400m 진행 표시가 나오고 사건을 마칩니다. 모의 활동은 음성 재생 중에도 실제 음성 길이를 기다리므로 정확히 2분에 끝나지는 않습니다.
4. 모의 장기전 중 정지/일시정지/중단 복구에서 거리 진행이 멈추고 복구 후 유지되는지 확인.
5. 실제 활동에서는 안전한 동선으로 평소처럼 이동합니다. 걷기로 시작한 전투는 조사로 바뀝니다. 신호 불안정 중 정밀 전투는 중립 종료됩니다.
