# 0.9.0 · 현장 도우미 오퍼레이터

## 방향
- 사용자 피드백: 해요체로 통일, 암울하고 딱딱한 보고 대신 밝고 다정하게 상황을 자세히 안내.
- 사용자가 새 잔향 늑대 처치/피해 안내를 청취하고 이 방향으로 승인했습니다.
- 성인 음색과 현재 캐릭터는 유지합니다. 실제 처치한 경우에만 이름을 부르며 축하합니다.
- 전투 피해/처치/조사/철수/회복을 구별합니다. 걷기나 추격 거절로 바뀐 조사는 같은 개체 ID라도 처치로 말하지 않습니다.
- 주요 보스는 토벌 대상과 현재 단계에 맞춰 안내합니다. 이전 피해와 혼동하지 않습니다.
- 협회 통신 6편에 짧은 핵심 요약 음성을 추가합니다. 전체 본문 낭독은 아닙니다. 해금 조건과 읽음/성장 상태는 그대로입니다.
- 활동 자막은 실제 선택한 음성 변형과 같은 대사입니다.
- 기본/안전/개체/보스/통신을 포함해56개 WAV를 제작합니다. 런타임 TTS와 새 결제는 없습니다.

## 테스트
1. 홈 인사와 설정 음성 테스트가 해요체인지 확인.
2. 20분 의뢰 모의 활동에서 잔향 늑대와 철각 파수병의 이름·행동 안내, 실제 처치와 피해 안내를 확인.
3. 걷기 상태나 추격 미허용에서 흔적 조사 결과를 처치라고 부르지 않는지 확인.
4. 토벌 게시판의 모의 활동에서 보스 이름을 안내하는지 확인. 실제 장기 토벌에서 단계가 바뀌면 다음 공격 안내도 바뀝니다.
5. 협회 통신 첫 기록의 ‘오퍼레이터 통신 듣기’를 확인. 잠긴 기록은 듣기 버튼이 없으며, 뒤로 가면 음성이 멈추고 BGM이 돌아옵니다.

## 검증 상태
로컬 게임 로직84개 통과. 실제 생성한56개 파일의 전체 검증 및 Apple 빌드는 진행 중입니다.
