## 변경 세부와 주의

- 새 Profile.journey는 optional. 과거 저장의 기록/장비/등급을 삭제하지 않는다. 기존6편은 이전 통신 기록으로 보존.
- NarrativeCatalog.refresh를 시작·정산·성장 변경에서 호출. 새 콘텐츠가 없는 저장은 등록을 먼저 요구하되 실제 활동 복구가 있는 경우 등록을 강제로 띄우지 않는다.
- 의뢰 ID를 RunSession/RunSummary에 기록. 증거는 별도 `evidence-*` event IDs로 일반 몬스터 토벌과 분리.
- 심사 보스는 `exam-D/C/B/A/S`이며 일반 보스 HP/코어/서사 ID와 분리. `major-strike-*` 피해 검증 규칙을 재사용.
- Quests.claim은 승급 후에도 완료 심사의 보상을 받을 수 있게 nextRank 자격과 분리.
