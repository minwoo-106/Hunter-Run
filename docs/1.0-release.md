# Hunter Run 1.0.0 변경 안내

스포일러 없는 안내입니다. 배포 파일과 Apple 검사 결과는 빌드 완료 후 기록합니다.

## 새로 즐길 수 있는 것

- 첫 실행에서 헌터와 오퍼레이터의 이름을 정할 수 있어요. 설정에서 다시 바꿀 수 있어요.
- 홈의 스토리 버튼에서 본편 16편을 진행하고, 읽은 이야기와 남은 잠긴 이야기 수를 확인할 수 있어요. 대화를 중간에 닫아도 이어서 볼 수 있어요.
- 오퍼레이터를 터치하면 일상 대화와 관계 이야기 12편을 만날 수 있어요. 선택한 취향과 약속을 기억하며 관계에 따라 대화가 달라져요. 같은 이야기를 반복해 호감도를 쌓도록 강요하지 않아요.
- 오퍼레이터의 호흡·눈 깜빡임과 여섯 표정을 추가했어요. 설정에서 움직임을 끌 수 있고, iPhone의 동작 줄이기 설정도 존중해요.
- 의뢰 15종, 선택한 의뢰의 조사·토벌 기록, 보상 수령과 등급별 승급 심사를 연결했어요. 심사 보스의 피해도 다음 활동으로 이어져요.
- 전체 개체 17종, 장비 32종, 협회 배경 5단계로 늘렸어요. 마녀와 타락한 요정도 포함돼요. 요정의 두 다리와 마력을 띄우는 손을 수정했어요.
- 기존 승인 음성 80개를 보존하고 상황 안내 33개를 더해 총 113개를 넣었어요. 화면 조작과 보상 효과음도 추가했어요.
- 콘텐츠가 한꺼번에 열리지 않도록 활동 시간·의뢰·등급·스토리를 연결했어요. 이전 저장의 보유 장비와 기록, 등급은 유지해요.
- 장비·활동·자료 도감을 보강하고 이름·활동 목표·음량·진동·움직임 설정, 백업/복원/초기화를 정리했어요.
- 실제 iPhone 배포 앱에서 모의 활동 진입을 제거했어요.

## 페이스 변경

속도 오차가 큰 GPS 값과 오래된 속도 표본을 페이스 계산에 사용하지 않도록 제한했어요. 신호가 좋지 않으면 부정확한 수치를 계속 표시하기보다 판정을 보류해요. 멈춤과 이동 재개 때 이전 속도 표본도 정리해요.

합성 입력 회귀 검사는 통과했지만, 이 버전의 실제 야외 정확도는 아직 사용자 기기에서 확인하지 못했어요. 산책→정지→다시 이동할 때의 표시와 실제 달리기에서의 반응을 확인해주세요.

## 업데이트 방법

현재 앱을 지우지 않고 새 IPA를 AltStore의 My Apps → +에서 선택해 덮어 설치해주세요. ZIP을 받았다면 iPhone 파일 앱에서 압축을 풀고 안의 `.ipa`를 선택해요. 기록이 중요하다면 앱 설정에서 백업 파일을 먼저 저장해주세요.

이번 배포는 기존 개인 설치 경로예요. App Store 공개 배포와는 별개이며 AltStore의 서명 갱신은 계속 필요해요.
