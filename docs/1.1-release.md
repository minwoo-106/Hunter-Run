# Hunter Run 1.1.0 — 미궁 인터페이스

## 변경 내용

- 앱을 켜면 미궁 입구의 시작 화면이 나타나요. 화면을 터치하면 홈으로 들어가요. 다른 앱을 보다가 돌아올 때는 시작 화면을 반복하지 않아요.
- 홈의 배치와 캐릭터는 유지했어요. 캐릭터를 누르는 영역은 더 확실하게 반응하도록 수정했어요.
- 오퍼레이터와 대화할 때 캐릭터가 크게 보이고, 아래 대화창에서 말을 선택해요. 긴 선택지는 대화창 안에서 스크롤할 수 있어요.
- 관계 이야기는 대화창의 ‘함께한 기록’에서 볼 수 있어요. 대답을 선택하면 새 답변이 보이는 위치로 돌아와요.
- 스토리도 캐릭터와 하단 대화창으로 진행해요. 읽던 곳 이어 보기와 선택 기록은 그대로 유지돼요.
- 헌터·장비·협회·도감·활동 준비·설정 화면을 미궁 배경, 금속 테두리, 모서리가 깎인 패널과 게임형 버튼으로 바꿨어요. 헌터 화면에는 등급 문장을 넣었어요.
- 글자 확대와 작은 화면에서 선택지를 읽고 누를 수 있도록 대응했어요.

## 설치

[Codemagic 설치 파일 페이지](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa68faa688764aa17be37ce?open-setting=build-artifacts)에서 `HunterRun-1.1.0-build19-install.zip`을 받아 압축을 풀고, 안의 `HunterRun-1.1.0-build19-unsigned.ipa`를 AltStore의 My Apps → +에서 선택해요.

기존 앱을 삭제하지 않고 덮어 설치하면 진행도를 이어갈 수 있어요. 이번 버전은 게임 규칙, 저장 형식, 승인된 음성 113개와 스토리 내용을 변경하지 않아요.

## 검증 기록

Codemagic build30이 2026-09-13에 성공했어요. 소스는 `2097d25`, 앱 버전은 1.1.0/build19예요.

- 코어 테스트 119개와 콘텐츠 검증을 통과했어요.
- iPhone 17 Pro 화면 검사 7개, 375×667 화면 검사 5개가 통과했어요. 시작 화면, 대화 선택, 관계 기록, 스토리 이어 보기, 설정 접근과 글자 최대 확대를 확인했어요.
- 작은 화면에서 잘라낸 캐릭터의 보이지 않는 영역이 대화 터치를 가로막지 않도록 수정했어요.
- 내려받은 설치 파일의 압축 무결성, arm64 실행 파일, 시작 이미지 설정과 음성 113개의 해시를 확인했어요.
- 설치 ZIP은 약 138 MB예요. [파일 검증 기록](release-110-verification.json)에 SHA-256을 기록했어요.

위 화면 검사는 시뮬레이터 결과예요. 실제 iPhone 설치 후의 최종 조작감은 기기에서 확인해주세요.
