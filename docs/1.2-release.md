# Hunter Run 1.2 — 실내 훈련 게이트

## 실내 활동

헌터 활동 → 활동 장소에서 ‘제자리 운동’ 또는 ‘러닝머신’을 선택해요. 시간이나 자유 목표를 고르고 ‘움직임 확인 후 입장’을 누르면 센서를 확인해요. 아이폰을 손에 들거나 몸에 지닌 채 몇 초간 움직여 ‘움직임이 잘 감지돼요’가 나온 후 시작해주세요.

- 애플워치와 GPS 없이 진행해요. 동작 및 피트니스 권한은 필요해요.
- 실제로 움직임이 감지되는 동안 탐색·전투·보상이 진행돼요. 손의 반복 움직임으로 시간이 인정돼도 걸음 수는 늦게 올라가거나 적게 측정될 수 있어요.
- 실내 거리·페이스는 만들지 않아요. 러닝머신의 속도·거리 표시와 자동 연동되지 않아요.
- 가속·거리 전투는 30초 움직임 유지로 바뀌어요. 걷기도 인정해요.
- 같은 장비·퀘스트·스토리·승급을 이어가요. 실내 활동은 야외 페이스 학습과 구분돼요.
- 직접 멈추면 진행도 기다려요. 화면 잠금·다른 앱 이동·통화 중단 시에는 일시정지하고, 돌아와 ‘계속’을 눌러 재개해요.
- 거치대나 책상에 아이폰을 놓으면 몸의 움직임을 감지할 수 없어요. 감지가 불안정하면 주머니나 운동 벨트로 위치를 바꿔보세요.

## 화면 변경

- 시작 화면의 ‘미궁 너머의 기록’을 밝은 색과 어두운 그림자로 바꿨어요.
- 오퍼레이터 대화는 캐릭터와 하단 대화창 중심으로 바뀌었어요. 대사를 터치하면 답변 2~3개가 나타나고, 선택 후에는 답변이 사라져 다음 말을 읽어요.
- 일상 대화에는 선택에 이어지는 짧은 후속 이야기를 넣었어요. 음료 취향과 관계 선택은 기억해요.
- 관계 수치와 지난 이야기는 왼쪽 위 책 모양의 ‘함께한 기록’에서 확인해요.

## 설치 및 검증

[1.2.0 다운로드 — Codemagic build32](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa69ff5c12cd81c2be0fe8c?open-setting=build-artifacts)

1. `HunterRun-1.2.0-build21-install.zip`을 아이폰에 내려받고 파일 앱에서 풀어요.
2. AltServer가 켜진 PC에 연결한 상태에서 AltStore → My Apps → + → `HunterRun-1.2.0-build21-unsigned.ipa`를 선택해요. 기존 앱을 삭제하지 않고 업데이트하면 진행 기록을 이어가요.
3. 시작 화면에서 1.2.0을 확인한 뒤 헌터 활동의 ‘제자리 운동’ 또는 ‘러닝머신’을 선택해요. 동작 및 피트니스 권한을 허용하고 움직임 확인 후 시작해요.

2026-09-13, 소스 `8dcbfd3`, 버전 1.2.0/build21. Codemagic build32가 16분 14초에 성공했어요. 게임 로직 128개, iPhone 17 Pro 화면 검사 11개, 375×667 작은 화면 검사 6개가 통과했어요. 최종 설치 ZIP/IPA, arm64 실행 파일, 시작 이미지, 113개 음성 해시와 콘텐츠 구성을 확인했어요. 설치 ZIP은 138,123,195바이트예요.

실내 기능 화면 검사는 시뮬레이터와 분리된 Debug 검사 도구로 진행했어요. 배포 앱에는 모의 활동 진입 버튼이 없어요. 센서 기준값은 실제 iPhone의 잡는 방법·제자리 뛰기·러닝머신 동작에 따라 추가 조정이 필요할 수 있어요. 처음에는 2~3분 움직인 후 멈췄을 때 시간이 멈추는지, 다시 움직일 때 재개되는지 확인해주세요.
