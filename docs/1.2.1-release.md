# Hunter Run 1.2.1 — 제자리 운동 보상 조정

## 적용 범위

| 활동 장소 | 반복 활동 경험치·마정석·조사 데이터 | 자유 활동 |
|---|---|---|
| 실외 | 기존 100% | 60분 이후에도 계속 |
| 러닝머신 | 기존 100% | 60분 이후에도 계속 |
| 제자리 운동 | 50% | 인정 운동 시간 60분에 자동 종료 |

제자리 운동은 한 활동당 최대 60분이에요. 5분·20분 등 짧은 시간 목표는 선택한 시간에 마쳐요. 정지·일시정지 시간은 운동 시간에 포함하지 않아요. 저장 후 다시 이어도 이미 운동한 시간이 유지돼요. 하루 총량 제한은 아니에요.

보상은 각각 합산한 뒤 절반으로 계산하고 소수점은 버려요. 일회성 의뢰 보상과 코어 등 핵심 재료는 그대로예요. 처치·스토리·승급 진행과 실제 인정된 시간도 유지해요. 과거에 이미 받은 보상과 기록은 바꾸지 않아요.

준비 화면과 움직임 확인 화면에 정책을 표시하고, 제자리 활동 중에는 자동 종료까지 남은 시간을 보여줘요. 결과와 지난 기록에는 실제 적용한 50% 비율을 표시해요.

실내 모드는 사용자가 선택해요. 러닝머신 기기와 직접 연결하지 않으므로 실제 운동과 다른 모드를 선택하는 우회까지 자동으로 구별하지는 못해요.

## 설치

[1.2.1 다운로드 — Codemagic build33](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa6a7acc12cd81c2be1115d?open-setting=build-artifacts)

`HunterRun-1.2.1-build22-install.zip`을 내려받아 압축을 풀고, AltStore의 My Apps → +에서 `HunterRun-1.2.1-build22-unsigned.ipa`를 선택해주세요. 기존 앱을 삭제하지 않고 업데이트하면 진행 기록을 이어갈 수 있어요.

2026-09-13, 소스 `2a2d636`, 버전 1.2.1/build22. Codemagic build33은 15분 50초에 성공했어요. 게임 로직 134개, iPhone 17 Pro 화면 검사 4개, 375×667 작은 화면 검사 2개가 통과했어요. 내려받은 ZIP/IPA 무결성, arm64 실행 파일, 시작 이미지, 113개 음성 해시와 콘텐츠 구성을 확인했어요. 설치 ZIP은 138,128,044바이트예요.

시간 제한과 보상은 자동 검사로 검증했고, UI 검사는 시뮬레이터에서 진행했어요. 실제 운동 감지의 민감도와 잡는 자세에 따른 차이는 이전 실내 모드와 같이 사용자 기기에서 확인해야 해요.
