# 1.2.2 — 실내 러닝 통합과 하루 합산 한도

1.2.1의 제자리 전용 규칙을 대체한다. 활동 장소는 야외 / 실내 러닝 두 가지다. 제자리 달리기와 러닝머신은 모두 같은 실내 센서와 보상 규칙으로 진행한다.

- 모든 실내 활동의 반복 경험치·마정석·조사 데이터는 합산 후 각각 50%, 소수점 버림. 일회성 의뢰 보상·코어·처치 및 성장 조건은 기존대로 유지한다.
- 실내 운동 인정 시간은 한국 시간(UTC+9) 하루 합산 3,600초. 여러 세션, 자유 목표, 일시정지·복구에도 하나의 한도를 공유한다. 더 짧은 목표가 있으면 먼저 끝난다. 멈춘 시간과 센서 공백은 소모하지 않는다.
- 오늘 완료한 실내 기록이 사용량의 기준이다. 기록은 현재 앱에서 삭제/절삭하지 않는다. 새 세션은 남은 한도를 저장하며, 복구 때 늘리지 않는다. 오늘 이미 진행한 이전 버전의 제자리/러닝머신 기록도 합산한다. 기존 지급 보상은 소급 변경하지 않는다.
- 자정 이후 첫 센서 프레임은 이전 활동을 종료·정산하며 새 날짜 시간을 추가하지 않는다. 잠금·정지 상태의 이전 활동도 복귀 후 정산한다. 자정 경계 직전의 미전달 센서 간격은 추정하지 않는다. 새 활동에서 다음 날 한도가 열린다.
- 기존 기록의 날짜는 시작 시각이다. 이전 버전에서 자정을 넘긴 실내 활동은 기존 시작 날짜에 귀속한다. 이미 사용한 이전 버전의 운동 시간을 소급 삭감하지 않으며 추가 적립을 막는다.
- 준비 화면과 움직임 확인에 남은 시간을 표시하고 소진 시 입장을 막는다. 활동 화면은 남은 세션 시간을 표시한다. 야외는 100% 지급하고 자유 활동에 새 시간 제한을 두지 않는다.
- 기기 시계와 로컬 저장 기록에 기반한다. 서버 운동 인증이나 앱 삭제·기기 시계 조작에 대한 완전한 방지는 아니다. 실제 센서 움직임 확인은 유지한다.
