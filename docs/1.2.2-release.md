# Hunter Run 1.2.2 — 실내 러닝 통합

## 적용 내용

| 활동 장소 | 반복 활동 경험치·마정석·조사 데이터 | 시간 제한 |
| --- | --- | --- |
| 야외 | 100% | 자유 활동에 새 제한 없음 |
| 실내 러닝: 제자리 달리기·러닝머신 공통 | 50% | 하루 합산 운동 인정 시간 60분 |

20분을 세 번 해도, 40분 뒤에 20분을 해도 같은 하루 한도를 써요. 준비 화면에 오늘 남은 시간이 표시되고, 남은 시간보다 긴 목표를 선택하면 한도에서 자동으로 마쳐요. 정지·일시정지·움직임을 확인하지 못한 시간은 차감하지 않아요. 앱을 다시 열어 이어 할 때도 사용한 시간을 유지해요.

한국 시간 자정에 새 한도가 열려요. 자정을 넘기는 실내 활동은 이전 날짜 기록으로 저장·종료하고, 새로 시작하면 다음 날 한도를 이용해요. 잠금 상태로 날짜가 바뀌었다면 앱에 돌아왔을 때 이전 활동을 정리해요.

이전 버전에서 오늘 완료한 러닝머신·제자리 운동도 합산해요. 과거에 이미 받은 보상은 바꾸지 않아요. 일회성 의뢰 보상, 핵심 재료와 이야기·승급 진행 조건은 기존대로예요.

## 설치

[1.2.2 다운로드 — Codemagic build34](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa6b0b5688764aa17be873e?open-setting=build-artifacts)

`HunterRun-1.2.2-build23-install.zip`을 내려받아 압축을 풀고, AltStore My Apps → +에서 `HunterRun-1.2.2-build23-unsigned.ipa`를 선택해요. 기존 앱을 삭제하지 않고 업데이트하면 기록을 유지할 수 있어요.

## 확인 상태

2026-09-13, 소스 `83b5369`, 버전 1.2.2/build23. Codemagic build34가 13분에 성공했어요. 핵심 로직 140개, iPhone 17 Pro 화면 5개, 375×667 작은 화면 3개 검사가 통과했어요. 내려받은 ZIP/IPA 구조와 무결성, arm64 실행 파일, 시작 이미지와 113개 음성 해시를 확인했어요. 설치 ZIP은 138,138,117바이트예요.

준비 화면의 단일 실내 선택지와 한도 소진 안내, 작은 화면의 움직임 확인, 활동 화면의 한도 표시를 캡처로 확인했어요. 자동 검사에서 실내 소진 후 야외 활동은 계속 시작할 수 있고, 백그라운드 이동 후 실내 일시정지·재개도 통과했어요.

운동 판정은 기존 아이폰 센서를 사용해요. 이번 업데이트는 측정 민감도를 바꾸는 작업이 아니며, 실제 제자리 달리기의 감지 상태는 사용자의 기기에서 확인해야 해요. 하루 한도는 로컬 저장과 기기 시간을 사용하므로 서버 기반 운동 인증은 아니에요.
