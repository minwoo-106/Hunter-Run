# 1.3.0 — 함께 진행하는 의뢰와 야외 조사

일반 의뢰 때문에 활동 방식을 바꿀 수 없던 구조를 해소한다. 활동 방식은 탐험·현장 사냥·고위험 게이트, 의뢰는 그 활동에서 함께 채우는 목표다. `contract` 저장 값은 유지하고 표시 이름만 현장 사냥으로 바꾼다.

## 의뢰

- 해금된 일반 의뢰는 모든 실제 활동의 종료 시 시간·조사 표본·토벌 기록을 함께 반영한다. 추적 대상 선택은 화면에 표시할 목표를 고르는 기능이다.
- 표본 종류는 정규화한 사건 ID로 구분한다. 같은 표본을 반복해서 얻어도 종류 수가 늘지 않는다. 중립 처리된 사건과 모의 활동은 인정하지 않는다.
- 기존 선택 의뢰의 누적 기록과 완료·수령 상태를 유지한다. 기존 활동 복구 시 저장된 임무는 보존한다.
- 승급 심사는 전용 보스 출동을 유지한다. 일반 의뢰도 조건이 맞으면 함께 진행한다.
- 활동 종료·저장과 의뢰 정산을 하나의 저장 작업으로 처리하고, 같은 활동을 재정산하지 않는다. 의뢰 달성으로 활동을 강제로 종료하지 않는다.

## 주간 야외 조사와 귀환

- 한국 시간 월요일 0시부터 다음 월요일 0시까지 집계한다. 활동 시작일에 귀속한다.
- 서로 다른 3일에 하루 합계 10분, 전체 합계 60분, 성공한 조사 단서 6개를 모은다. 각 일자의 활동을 나누어 진행해도 합산한다.
- 야외 활동 중 기록이 60초 이상이고 이동 거리가 50m 이상인 활동만 집계한다. 실내, 모의 활동, 미래 시각 기록, 중복 활동 ID를 제외한다.
- 세 조건은 지부의 발걸음·지속·단서 관측등에 각각 대응한다. 연속 출석·미참여 벌점은 없다.
- 주 1회 경험치 80, 마정석 6, 조사 데이터 4와 기념 인장을 받는다. 미수령 보상은 다음 주로 이월되지 않으며 받은 인장 수는 유지된다.
- 귀환 후 오퍼레이터가 운동 시간, 조사·전투 결과, 새로 달성한 의뢰와 주간 상태를 텍스트 대화로 정리한다. 마지막 보고는 홈에서 다시 볼 수 있다. 기존 음성은 교체하지 않는다.

## 토벌 후 변이

- 기존 주요 보스 2종에 각각 2개 패턴, 총 4개 변이 의뢰를 추가한다. 새 몬스터 종이나 새 삽화로 세지 않는다.
- 원형 보스 완전 토벌과 기존 등급·시설·이야기 조건을 만족해야 열린다. 야외 전용이다.
- 잔향 분열: 두 번의 45초 유지 공격. 봉인 역류: 첫 공략에서 선택적 10초 가속, 응하지 않으면 30초 유지 공격.
- 기존 가속 동의·안정된 기준 페이스·좋은 신호·활동당 최대 2회·180초 간격 규칙을 그대로 따른다.
- 체력은 원형의 115%, 변이별 남은 체력과 회차는 따로 저장한다. 기존 토벌 정산 규칙을 사용한다.

## 성장 속도 점검

야외 시간 기본 경험치는 5분 30, 20분 120, 30분 180이고 성공한 사건마다 20을 더한다. 주간 최소 조건인 60분과 조사 성공 6개만 계산하면 기본 480 경험치에 주간 80이 추가되어 약 16.7% 증가한다. 한 레벨은 300 경험치다. 반복 보상은 늘리되 매일 받는 보너스나 연속 출석 배수는 추가하지 않는다.

D급 심사 자격은 Lv.2와 누적 활동 60분, 이야기 조건을 모두 요구하며 실제 심사 보스 완전 토벌도 필요하다. 이후 C/B/A/S급의 누적 활동 하한은 각각 300/700/1500/2600분이고 레벨·게이트·심사 조건이 함께 적용된다. 주간 경험치만으로 이 시간 하한을 넘길 수 없다. 일반 의뢰의 자동 병행은 선택을 놓쳐 생기는 재출동을 줄이지만, 해금 전 표본과 시간을 소급해서 채우지는 않는다. 실제 플레이에서 장비 구매와 전투 성공 빈도에 따른 체감 속도는 추가 관찰 대상이다.

## 화면 역할

| 위치 | 맡는 기능 |
|---|---|
| 홈 | 오퍼레이터 대화, 스토리, 마지막 귀환 보고, 설정 |
| 헌터 | 성장·장비·승급·활동 기록 |
| 헌터 활동 | 장소·방식·목표, 추적 의뢰 확인, 게이트 토벌 대상 선택, 시작 |
| 협회 관리 | 의뢰 / 주간 조사 / 시설을 탭으로 구분 |
| 도감 | 몬스터·조사 자료·사건 대응 기록 |

헌터의 협회 부서 이동, 시설의 의뢰·보스·스토리·개체 이동, 활동 기록의 의뢰·보스 이동, 설정의 이야기 이동을 제거한다. 현재 준비 중인 목표를 바꾸는 링크 등 맥락상 필요한 이동은 남긴다. 완료한 의뢰는 접어 현재 목표가 먼저 보이게 한다. 모든 화면에서 하단 이동을 일관되게 유지한다.

## 참고한 공식 자료와 적용 범위

- [Pokémon GO Routes](https://pokemongo.com/routes): 실제 야외 이동을 탐색·발견·보상에 연결하는 구조를 참고했다. 위치 기반 실시간 경로 기능을 구현한 것은 아니며, 3일·60분 주간 목표는 Hunter Run 자체 설계다.
- [Zombies, Run! 소개](https://zrx.app/news/explore-ZR): 운동 중 얻은 자원과 이야기, 기지 성장을 이어주는 구조를 귀환 보고와 관측등에 적용했다.
- [Monster Hunter Now 이야기 퀘스트](https://monsterhunternow.com/howtoplay/story-quests): 진행에 따라 새로운 사냥 도전을 여는 구조를 토벌 후 변이 패턴으로 재해석했다.

캐릭터·이야기·이미지·UI를 복제하지 않는다. 실내 활동 50% 반복 보상과 하루 합산 60분 제한, 야외 자유 활동 무제한 정책은 유지한다. 이 패치에 GPS 페이스 추정식 변경은 포함하지 않는다.
