# Hunter Run 1.3.0 — 의뢰 병행과 주간 야외 조사

## 바뀐 사용 흐름

하단은 **홈 / 헌터 / 헌터 활동 / 협회 관리 / 도감**을 유지한다. 같은 화면으로 가는 큰 버튼을 여러 곳에 반복하지 않고 각 탭의 역할을 구분했다.

- **헌터 활동**: 장소 → 탐험·현장 사냥·고위험 게이트 → 운동 목표 → 시작 순서. 기존 ‘헌터 의뢰’ 모드 이름은 ‘현장 사냥’으로 바뀐다.
- **일반 의뢰**: 이미 열린 의뢰들은 평소 활동과 함께 진행한다. 하나를 추적해도 다른 모드를 선택할 수 있다. 의뢰 달성 때문에 활동을 끝내거나 다시 시작하지 않는다. 승급 심사는 전용 출동이다.
- **협회 관리**: 의뢰·주간 조사·시설을 위쪽 선택지로 나눴다. 헌터 화면의 협회 이동, 시설 화면의 스토리·의뢰·보스 바로가기 등 중복 이동을 정리했다.
- **주간 야외 조사**: 서로 다른 3일에 각 10분 이상, 한 주 총 60분, 조사 성공 단서 6개를 모은다. 완료하면 관측등 세 개가 켜지고 주 1회 인장과 경험치 80·마정석 6·조사 데이터 4를 받는다. 월요일 0시 한국 시간 기준으로 갱신하며 연속 출석은 요구하지 않는다.
- **귀환 보고**: 홈의 새 귀환 보고를 누르면 오퍼레이터가 방금의 조사·전투·의뢰 성과를 텍스트 대화로 정리한다. 마지막 보고를 다시 볼 수 있다.
- **변이 의뢰 4개**: 기존 주요 보스 2종을 완전히 토벌하면 각 2개 패턴이 열린다. 고위험 게이트 → 토벌 대상 선택 → 변이 의뢰에서 준비한다. 야외 전용이며 변이별 남은 체력을 따로 저장한다. 유지 공격 중심과 선택적 10초 가속 중심으로 나뉜다.

실내 러닝은 반복 보상 50%, 하루 합산 60분을 유지한다. 야외 자유 활동에 새 시간 제한은 없다. 기존 음성과 장비·몬스터 삽화, 저장 기록을 유지하며, 이 패치에 페이스 추정식 변경은 포함하지 않는다.

## 확인 결과

2026-09-14, 소스 `878ed2b`, 버전 1.3.0/build27. 최종 로직 149개와 iPhone 17 Pro·작은 화면 각각 3개의 보정 검사가 통과했다. 직전 build37에서는 전체 변경 경로의 기본 화면 9개·작은 화면 4개 검사가 모두 통과했고, 마지막 보정은 토벌 선택창 닫기 아이콘과 안내 이름이다.

내려받은 ZIP/IPA 구조와 무결성, arm64 실행 파일, 시작 이미지, 113개 승인 음성의 해시를 확인했다. 설치 ZIP은 138,218,536바이트다.

검증 범위는 의뢰 추적 중 모드 선택, 주간 보상 한 번 수령, 귀환 보고, 원형 토벌 후 변이 준비, 중복 이동 제거, 홈·목표·실내 한도와 일시정지다. 최종 보정 검사에서는 토벌 선택창을 닫았다 다시 여는 경로도 확인했다. 실제 야외 페이스 측정을 다시 검증한 패치는 아니다. 개인 AltStore 설치 경로이며 App Store 배포를 의미하지 않는다.
