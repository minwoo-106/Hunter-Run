# Hunter Run 1.3.1 — 야외 사냥 판정 보정

야외 기록에서 GPS 양호가 0%로 남아 잔향 늑대가 조사로 바뀌고 페이스 표본도 쌓이지 않던 경로를 수정했습니다. 위치 좌표의 정확도와 속도 측정의 정확도를 분리하고, 움직임 분류를 받은 시각을 올바르게 기록합니다. 신뢰할 만한 달리기 속도는 판정에 활용하되, 불안정한 위치·차량 이동을 토벌로 인정하지 않습니다.

활동 화면에 **달리기/걷기 판정, GPS 상태, 토벌 가능 여부**가 바로 표시됩니다. GPS가 약하면 이유도 표시됩니다. 준비 화면에는 탐험과 현장 사냥의 차이, 추적 중인 의뢰, 위치 권한 설정을 설명합니다. ‘나의 활동 기준’은 목표를 일찍 종료해도 성과가 저장되며, 최근 횟수는 5분 이상 유효한 달리기 표본을 확보한 활동의 수라는 점을 명확히 했습니다.

의뢰 완료 음성을 승인된 새 목소리로 교체했습니다. 경계의 군주 음성은 별도 확인 뒤 반영합니다.

위치 권한을 매번 묻는 경우 iPhone **설정 → 개인정보 보호 및 보안 → 위치 서비스 → Hunter Run → 앱을 사용하는 동안**을 선택하고 **정확한 위치**를 켜주세요. ‘한 번 허용’은 앱을 닫은 뒤 만료됩니다.

핵심 로직 테스트 152개와 콘텐츠·음성 검증이 통과했습니다. iPhone 실외 측정과 설치 확인은 새 IPA를 받아 검증할 예정입니다.
