# Hunter Run 1.3.10 — 초중반 이야기 연결

버전 1.3.10 / 빌드 40입니다. 기존 앱 위에 설치하면 활동 기록과 진행 데이터가 유지됩니다.

- 초반부터 상위 게이트까지 협회의 한 헌터에 관한 이야기가 조금씩 이어지도록 대본을 보강했습니다. 후반부 내용은 해금 전까지 공개하지 않습니다.
- 지역 사건의 결말과 후반 작전 사이의 연결을 다듬었습니다. 이미 완료한 장면도 이야기 목록에서 다시 볼 수 있습니다.
- 이전 대화의 노드 ID를 유지했습니다. 운동 거리·시간·페이스 측정 코드는 1.3.9와 같습니다.

## 설치

[Codemagic 빌드 #51의 설치 파일](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aba0bfb3f90aeed966c17e1?open-setting=build-artifacts)에서 `HunterRun-1.3.10-build40-install.zip`을 받아 압축 해제한 뒤, 안의 unsigned IPA를 AltStore Classic에서 기존 앱 위에 설치하세요. 앱을 삭제하면 백업하지 않은 진행 데이터가 사라질 수 있습니다.

콘텐츠 검증, Swift 게임 엔진 테스트, iPhone용 Release 컴파일, 시뮬레이터 화면 검사와 설치 ZIP/IPA 생성이 빌드 #51에서 통과했습니다.
