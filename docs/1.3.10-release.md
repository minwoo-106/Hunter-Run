# Hunter Run 1.3.10 — 초중반 이야기 연결

버전 1.3.10 / 빌드 40입니다. 기존 앱 위에 설치하면 활동 기록과 진행 데이터가 유지됩니다.

- 초반부터 상위 게이트까지 협회의 한 헌터에 관한 이야기가 조금씩 이어지도록 대본을 보강했습니다. 후반부 내용은 해금 전까지 공개하지 않습니다.
- 지역 사건의 결말과 후반 작전 사이의 연결을 다듬었습니다. 이미 완료한 장면도 이야기 목록에서 다시 볼 수 있습니다.
- 이전 대화의 노드 ID를 유지했습니다. 운동 거리·시간·페이스 측정 코드는 1.3.9와 같습니다.

## 설치

Codemagic 빌드가 완료되면 이곳에 설치 파일 링크를 추가합니다. `HunterRun-1.3.10-build40-install.zip`을 압축 해제해 unsigned IPA를 AltStore Classic에서 기존 앱 위에 설치하세요. 앱을 삭제하면 백업하지 않은 진행 데이터가 사라질 수 있습니다.
