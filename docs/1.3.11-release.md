# Hunter Run 1.3.11 — 인물과 선택의 회수

버전 1.3.11 / 빌드 41입니다. 기존 앱 위에 설치하면 활동 기록과 진행 데이터가 유지됩니다.

- 초반 인물을 대사와 일상 기록으로 더 알아가고, 지부에 남겨진 공간과 오래된 기록의 의미를 후반에서 다시 확인하도록 했습니다. 자세한 전개는 해금 전까지 공개하지 않습니다.
- 일부 이야기 선택은 나중에 대사로 돌아옵니다. 이전 버전에서 이미 선택한 진행 데이터는 기본 대사로 이어지며, 저장 상태가 초기화되지 않습니다.
- 기록 속 인물의 발화에는 출처 이름과 해당 장면의 이미지를 표시해, 오퍼레이터가 직접 말하는 장면과 구분했습니다.
- 기존 장면의 대화 노드 ID와 운동 거리·시간·페이스 계산을 유지했습니다.

## 설치

Codemagic 빌드가 완료되면 설치 링크를 추가합니다. `HunterRun-1.3.11-build41-install.zip`을 받아 압축을 풀고 unsigned IPA를 AltStore Classic에서 기존 앱 위에 설치하세요. 앱을 삭제하면 백업하지 않은 진행도가 사라질 수 있습니다.
