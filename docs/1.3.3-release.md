# Hunter Run 1.3.3 — 야외 페이스·거리 음성

야외 활동 화면에 최근 12초를 평활화한 현재 페이스와 활동 전체 평균 페이스를 `/km` 단위로 표시합니다. 평균에는 걷기 구간도 포함되며, 활동 보고와 이전 활동 상세에서도 확인할 수 있습니다. GPS 신호가 불안정하거나 정지 중이면 현재 페이스를 `—`로 표시합니다. 실내 모드는 거리·페이스를 추정하지 않습니다.

야외 활동에서 확인된 거리가 1km 경계를 넘을 때마다 오퍼레이터가 안내합니다. 탐험은 “이동했어요”, 현장 사냥·게이트는 “달렸어요”로 구분합니다. 1~10km에는 각각의 거리 음성이 있고, 11km 이후에도 매 1km마다 추가 안내가 나옵니다. 전투·의뢰 음성이 먼저 재생 중이라면 거리 안내는 뒤로 미룹니다. GPS 신호가 약한 동안 경계를 넘었으면 양호한 신호가 돌아온 후 알려줍니다. 일시정지·기기 중단·세션 복구 시 이미 알려준 거리를 중복 재생하지 않습니다.

이 기능은 거리와 음성 표시를 추가하며 기존 걷기/달리기 판정이나 보상 기준을 바꾸지 않습니다. 1.3.2의 3분 미만 기록 제외와 1.3.1의 GPS 신호·움직임 분류 수정도 유지됩니다. 실제 iPhone 야외 측정 검증은 여전히 필요합니다.
