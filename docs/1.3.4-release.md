# Hunter Run 1.3.4 — 거리 안내 음성 수정

현장 사냥·게이트의 2km와 9km 안내에서 뒷문장에 다른 음색이 섞여 들리던 부분을 제거했습니다. 기존 첫 문장의 음성은 그대로 유지하며 각각 “2킬로미터 달렸어요!”, “9킬로미터 달렸어요!”로 끝납니다. 탐험 3km 안내는 “3킬로미터 이동했어요! 편안하게 이동해봐요!”로 다시 제작했습니다.

거리 안내는 랜덤으로 선택되지 않습니다. 탐험에서는 이동 안내, 현장 사냥·게이트에서는 달리기 안내를 사용합니다. 이벤트 대사와 동시에 재생되지 않도록 하나의 음성 채널에서 이벤트 대사를 우선 재생하고 거리 안내를 대기시킵니다. 이번 패치는 거리 측정과 걷기/달리기 판정을 변경하지 않습니다.
