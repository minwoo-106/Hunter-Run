# Hunter Run 1.3.5 — 야외 거리·평균 페이스 수정

버전 1.3.5 / 빌드 32의 iPhone 빌드와 설치 패키지 검증을 완료했습니다.

정상적인 GPS 좌표가 6초 이상 간격으로 들어오면 해당 구간을 전부 버리던 문제를 수정했습니다. 위치 좌표가 타이머 직후 전달될 때 여러 초 동안 이동한 거리를 마지막 수백 밀리초의 거리로 잘라내던 문제도 수정했습니다. 이 두 문제가 겹치면 실제 5km 안팎의 활동이 1km 미만으로 기록되고 평균 페이스가 수십 분대로 표시될 수 있었습니다.

새 거리 누적기는 최대 30초 동안의 정상적인 묶음 좌표와 그 좌표가 나타내는 시간을 함께 보존합니다. 시속 28.8km를 넘는 이동, 정확도가 낮은 좌표, 30초가 넘는 공백과 비정상적인 순간이동은 계속 제외합니다. 활동시간, 보상 규칙, 걷기·달리기 판정과 기존 저장 데이터는 변경하지 않습니다.

재현 테스트에서 6초 간격의 정상 보행 경로 4.536km가 온전히 기록되고, 타이머 직후 전달된 8.1m가 0.8m로 잘리지 않는 것을 확인했습니다. 전체 코어 테스트 158개, iPhone 17 Pro 화면 테스트 4개와 소형 화면 테스트 4개가 통과했습니다. 내려받은 설치 ZIP과 IPA도 정상 압축, 1.3.5/build32, arm64 실행 파일, 스토리 28개, 몬스터 17종, 장비 32종과 음성 135개의 해시를 확인했습니다.
