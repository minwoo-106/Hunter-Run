# Hunter Run 1.3.6 — 새로운 강적과 장비 성장

버전 1.3.6 / 빌드 33입니다. 기존 앱 위에 설치하면 저장된 활동·보유 장비·이야기 진행이 유지됩니다.

- 새 개체 9종의 일러스트와 야외 조사·전투 사건을 추가했습니다. 오염된 선발대 네 사람의 정화 기록이 모이면 새로운 장기 토벌이 열립니다.
- 거울마녀와 철갑 코뿔소의 실제 토벌로 각 계열 장비가 열립니다. 월영·몽환은 일반 개체를 통해 준비 장비를 얻고, 엘리트 토벌 뒤 상위 방어구·신발을 별도로 제작합니다. 기존 장비는 회수하지 않습니다.
- 같은 슬롯의 단계가 높을수록 핵심 전투 수치가 올라가도록 재조정했습니다. 레벨 26 이후 장비의 공격 보정도 적용되도록 총합 상한을 넓혔습니다. 장비 화면에서 단계와 현재 장비 대비 수치 차이를 볼 수 있습니다.
- 승인된 오퍼레이터 목소리의 참조 파일로 새로운 안내 42개를 한 문장씩 합성했습니다. [번호별 미리듣기](voice-review-1.3.6/index.html)에서 확인하고, 다른 목소리로 들리는 번호를 알려주세요.
- 오퍼레이터 초상에 미세한 고개 기울임과 좌우 이동을 더했습니다. iOS 동작 줄이기 설정을 존중합니다.

기존 1.3.5의 야외 거리·페이스 센서 처리 방식은 이번 버전에서 변경하지 않았습니다. 1.3.5 실외 측정 수정은 아직 사용자 실기기 비교 결과를 기다리고 있습니다.

## 설치 및 음성 확인

[Codemagic 1.3.6 빌드 #44의 아티팩트](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6ab936893f90aeed96678355?open-setting=build-artifacts)에서 `HunterRun-1.3.6-build33-install.zip`을 받아, 안의 unsigned IPA를 AltStore Classic에 추가합니다. 같은 빌드의 `HunterRun-1.3.6-voice-preview.zip`은 새 음성 42개만 담고 있습니다. 압축을 풀고 `index.html`을 열면 번호별로 들을 수 있습니다.

코어 테스트 161개와 콘텐츠, 삽화, 대사·WAV 해시 검증을 통과했습니다. iPhone 17 Pro에서 실제 전투 출현, 화면 배치, 음성의 자연스러움은 설치 후 확인이 필요합니다.
