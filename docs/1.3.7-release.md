# Hunter Run 1.3.7 — 야외 시간·페이스 재측정

버전 1.3.7 / 빌드 37입니다. 기존 앱 위에 설치하면 활동 기록과 진행 데이터가 유지됩니다.

이번 버전은 야외 걷기 실측 피드백을 반영했습니다. 활동 중과 종료 후에 **경과시간**(출발부터 종료까지)과 **움직인 시간**(정지 구간을 뺀 게임 판정 시간)을 따로 보여줍니다. **전체 평균 페이스**는 애플워치 운동 기록과 비교할 수 있도록 경과시간으로 계산합니다. 신호등 대기 중에도 게임 보상 시간이 쌓이지 않는 규칙은 유지됩니다.

**현재 페이스**는 순간 GPS 속도보다 최근 약 40초간 수신된 이동 거리로 계산해 속도 표시가 8~20분/km 사이를 급히 오가던 현상을 줄였습니다. GPS가 불안정하거나 멈추면 현재 페이스를 숨깁니다. 야외 거리와 보상 계산 방식 자체는 이번에 변경하지 않았습니다.

걷기 중 순간 GPS 속도가 높아져도 동작 센서의 걷기 판정을 달리기로 덮어쓰지 않도록 고쳤습니다. 이전 기록에서 실제로 달리지 않았는데 ‘학습 가능 구간’과 빠른 참고 페이스가 생겼다면 **헌터 → 나의 활동 기준 → 학습 기준 초기화**를 한 번 사용하세요. 활동 기록·장비·자원은 유지됩니다.

1.3.6에서 기록한 예시처럼 애플워치 5.11km와 헌터런 5.38km의 차이는 이 버전에서도 확인이 필요합니다. 헌터런 설정의 **진단 정보 내보내기**에는 좌표를 저장하지 않고 GPS로 누적한 거리, 신뢰 가능한 속도 적분 거리, 평균 위치 정확도만 집계해 기록합니다. 재측정 후 이 숫자를 비교하면 거리 오차의 원인을 좁힐 수 있습니다.

## 설치

[Codemagic 빌드 #48의 설치 파일](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6ab9e3e33f90aeed966b3851?open-setting=build-artifacts)에서 `HunterRun-1.3.7-build37-install.zip`을 받아 압축을 풀고 unsigned IPA를 AltStore Classic에서 기존 앱 위에 설치하세요. 개인 서명 만료 전이면 진행 데이터는 유지됩니다. 삭제 후 재설치하면 백업하지 않은 진행 데이터가 사라질 수 있습니다.

빌드 #48은 콘텐츠 검증, 코어 테스트 166개, iPhone 컴파일, iPhone 17 Pro와 작은 화면의 시뮬레이터 검사를 통과했습니다. 설치 ZIP과 unsigned IPA가 게시된 것을 확인했습니다.

## 재측정할 내용

애플워치의 실외 걷기 운동과 헌터런 탐험을 거의 동시에 시작하고, 둘 다 일시정지하지 않은 채 20분 이상 같은 경로를 기록해 주세요. 종료 후 두 앱의 **전체 경과시간·거리·전체 평균 페이스**를 비교하고, 헌터런의 **움직인 시간**도 확인해 주세요. 차이가 여전히 크면 헌터런 설정에서 진단 정보를 내보내 수치 부분을 공유해 주세요. 위치 좌표와 닉네임은 포함되지 않습니다.
