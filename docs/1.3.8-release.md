# Hunter Run 1.3.8 — 화면 정리와 새 이야기

버전 1.3.8 / 빌드 38입니다. 기존 앱 위에 설치하면 활동 기록과 진행 데이터가 유지됩니다.

- 홈의 새 귀환 보고는 한 번 열면 읽음 처리되어 버튼이 사라집니다. 전체 활동 기록은 헌터 화면에서 계속 볼 수 있습니다.
- 활동 준비의 위치 권한 확인 카드를 제거하고 **설정 → 위치 및 활동 권한**으로 옮겼습니다. 야외 활동 시작 시 권한이 없으면 다시 안내합니다.
- 기존 본편 뒤에 이어지는 새 이야기와 일회성 협회 시설을 추가했습니다. 이야기 내용은 해금 전까지 공개하지 않습니다.
- 청월의 일상 초상은 해당 장면에서만 등장합니다. 가벼운 복장, 도시 배경, 선명한 눈동자를 반영했습니다.
- 1.3.7의 경과시간·현재 페이스·걷기 판정 보정은 그대로 포함됩니다. 실제 GPS 거리 차이는 아직 현장 비교가 필요합니다.

## 설치

[Codemagic 빌드 #49의 설치 파일](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6ab9f69d3f90aeed966b9db3?open-setting=build-artifacts)에서 `HunterRun-1.3.8-build38-install.zip`을 받아 압축을 풀고, 들어 있는 unsigned IPA를 AltStore Classic에서 기존 앱 위에 설치하세요. 앱을 삭제하면 백업하지 않은 진행도가 사라질 수 있습니다.

빌드 #49는 콘텐츠 검증, 코어 테스트 167개, iPhone 앱 컴파일, iPhone 17 Pro 시뮬레이터 화면 검사를 통과했습니다. 설치 ZIP과 IPA 게시를 확인했습니다. 실제 GPS 거리의 정확도는 실기기 측정 결과로 확인해야 합니다.
