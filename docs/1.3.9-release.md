# Hunter Run 1.3.9 — 강해솔 캐릭터 아트

버전 1.3.9 / 빌드 39입니다. 기존 앱 위에 설치하면 활동 기록과 진행 데이터가 유지됩니다.

- 후반 인물의 이름을 강해솔로 바꾸고, 밝은 빛의 이미지에 맞춰 대사를 정리했습니다. 구체적인 이야기는 해금 전까지 공개하지 않습니다.
- 평상시 초상을 교체하고 머리 묶기·호기심·작은 벌레에 놀란 모습까지 네 장을 추가했습니다. 일상 갤러리는 해당 이야기를 마친 뒤에만 열립니다. 전투 모습은 그대로입니다.
- 저장 데이터의 기존 내부 진행 키는 호환을 위해 유지합니다. 이야기를 다시 시작하거나 앱을 삭제할 필요가 없습니다.
- 거리·페이스 측정 코드는 1.3.8과 동일합니다. GPS 거리 차이는 계속 실기기 비교가 필요합니다.

## 설치

최신 Codemagic `ios-demo` 빌드의 `HunterRun-1.3.9-build39-install.zip`을 받아 압축을 풀고, 들어 있는 unsigned IPA를 AltStore Classic에서 기존 앱 위에 설치하세요. 앱을 삭제하면 백업하지 않은 진행도가 사라질 수 있습니다.
