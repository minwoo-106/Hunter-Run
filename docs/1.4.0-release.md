# Hunter Run 1.4.0 — 시즌 1

버전 1.4.0 / 빌드 42입니다. 기존 앱 위에 설치하면 활동 기록과 이야기 진행도가 유지됩니다.

- 시즌 1의 21개 장면과 후반 활동을 확정된 원고에 맞춰 다듬었습니다. 장면의 구체적인 전개는 게임에서 직접 확인할 수 있습니다.
- 승인된 강해솔 음성 16개와 오퍼레이터 음성 23개, 새 인물 초상과 후반 시설 이미지를 적용했습니다. 놀라는 음성은 제외했습니다.
- 후반 작전에서 GPS 수신이 약해져도 걸음이 확인되면 안전한 유지 활동으로 진행합니다. 걸음도 확인할 수 없으면 진행 상태를 보존하고 일시정지합니다.
- 이전 버전에서 대화 중이었다면 해당 장면의 시작부터 다시 볼 수 있습니다. 완료한 장면과 저장된 선택·활동·보상은 유지됩니다.

## 설치

[1.4.0 build 42 iPhone 설치 파일](https://github.com/minwoo-106/Hunter-Run/actions/runs/36506747632/artifacts/11007881087)을 GitHub에 로그인한 상태에서 다운로드합니다. 다운로드한 ZIP을 풀면 `HunterRun-1.4.0-build42-unsigned.ipa`가 있습니다. 이를 기존처럼 AltStore에서 선택해 설치합니다. 기존 앱 위에 설치하면 저장 데이터가 유지됩니다. 앱을 삭제하면 백업하지 않은 진행도가 사라질 수 있습니다.

이 링크의 GitHub Actions 보관 기간은 7일입니다. 앱 콘텐츠 검사, Swift 게임 엔진 테스트, 실제 iPhone 앱 컴파일, IPA 내부 버전 및 음성 파일 검증을 통과했습니다. 시뮬레이터 화면 검사는 GitHub에서 시간이 오래 걸려 이 빠른 설치 빌드에서는 분리했습니다.
