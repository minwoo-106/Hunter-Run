# Hunter Run 1.4.1 — 화면 이동 연출

버전 1.4.1 / 빌드 43입니다. 기존 앱 위에 설치하면 활동 기록과 이야기 진행도가 유지됩니다.

- 홈: 미니 오퍼레이터가 노트북 업무 → 커피 → 햄버거 → 노트북 닫기 → 짧은 졸음 순서로 등장합니다.
- 헌터: 장비실 조명과 카메라 이동으로 기록 화면에 들어갑니다. 화면 배경도 장비실로 바뀝니다.
- 헌터 활동: 게이트가 커지며 활동 준비 화면으로 이어집니다.
- 협회 관리: 무거운 문이 잠금 해제되어 열리고 협회 내부 배경이 나타납니다.
- 도감: 늑대와 서큐버스가 그려진 두루마리가 펼쳐지고 기록 보관소로 이어집니다.
- iPhone의 **동작 줄이기**를 켜면 긴 연출 없이 곧바로 화면을 이동합니다.

운동 측정 방식, 보상, 저장 데이터 형식과 기존 이야기 진행도는 바뀌지 않았습니다.

## 설치

검증된 설치 파일 링크는 iPhone 빌드가 완료되면 이 문서에 추가합니다. 기존처럼 설치 ZIP 속 unsigned IPA를 AltStore에서 선택하면 됩니다. 앱을 삭제하면 백업하지 않은 진행도가 사라질 수 있으므로 기존 앱 위에 설치해주세요.
