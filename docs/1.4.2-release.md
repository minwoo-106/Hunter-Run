# Hunter Run 1.4.2 — 시작 화면과 화면 이동 수정

버전 1.4.2 / 빌드 44입니다. 기존 앱 위에 설치하면 활동 기록과 이야기 진행도가 유지됩니다.

- 승인한 공명문 시작 화면을 앱에 적용하고, 안개·공명원·서로 다른 속도로 도는 빛과 터치 후 진입 연출을 연결했습니다.
- 헌터 화면 이동 연출이 화면 상단에서 잘려 이전 화면이 보이던 문제를 수정했습니다.
- 홈 이동 연출 뒤 이전 화면이 다시 잠깐 보이던 문제를 수정했습니다.
- **동작 줄이기** 설정에서는 긴 진입·이동 연출을 생략합니다.

운동 측정 방식, 보상과 저장 데이터 형식은 바뀌지 않았습니다.

## 설치

[Hunter Run 1.4.2 설치 ZIP 다운로드](https://github.com/minwoo-106/Hunter-Run/actions/runs/36549037081/artifacts/11023588263) — GitHub 로그인 후 받을 수 있으며, GitHub Actions 보관 기간은 7일입니다. ZIP 안의 unsigned IPA를 기존처럼 AltStore에서 선택하고, 진행도를 유지하려면 앱을 삭제하지 말고 기존 앱 위에 설치해주세요.

GitHub Actions [빌드 #6](https://github.com/minwoo-106/Hunter-Run/actions/runs/36549037081)에서 콘텐츠 검증, 게임 엔진 테스트, iPhone 앱 컴파일, 설치 파일 포장과 업로드가 모두 통과했습니다. 실제 화면 연출은 iPhone에서 확인해야 합니다.
