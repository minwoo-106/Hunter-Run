# Hunter Run 1.4.3 — 야외 활동 시간과 토벌 수정

버전 1.4.3 / 빌드 45입니다. 기존 앱을 삭제하지 않고 덮어 설치하면 활동 기록과 이야기 진행도가 유지됩니다.

- 야외 활동의 **활동시간과 전체 평균 페이스에서 직접 누른 일시정지 시간을 제외**합니다. 활동 결과에도 같은 운동시간을 기록합니다.
- 20분 시간 목표는 일시정지를 제외한 운동시간이 20분이 되면 자동 종료합니다. 보상 인정시간은 실제 움직인 시간으로 따로 계산합니다.
- 정확한 GPS 속도가 여러 초 동안 달리기를 나타내면 움직임 감지의 늦은 걷기 판정을 보완합니다. 한 번 튄 GPS 속도만으로는 달리기로 바꾸지 않습니다.
- ‘첫 잔향 토벌’ 또는 ‘잔향수 분석 의뢰’를 추적 중인 **야외 현장 사냥**에서는 잔향 늑대 조우를 우선합니다. 예정 시점에 걷기 판정이나 GPS 저하가 잠깐 있어도 전투 기회를 조사로 소모하지 않고, 달리기와 신호가 회복되면 이어집니다.

## 설치

[Hunter Run 1.4.3 설치 ZIP 다운로드](https://github.com/minwoo-106/Hunter-Run/actions/runs/36556581243/artifacts/11027484216) — GitHub 로그인 후 받을 수 있습니다. ZIP 안의 `HunterRun-1.4.3-build45-unsigned.ipa`를 기존처럼 AltStore에서 선택해주세요. GitHub Actions의 파일 보관 기간은 7일입니다.

[빌드 #7](https://github.com/minwoo-106/Hunter-Run/actions/runs/36556581243)에서 콘텐츠 검증, Swift 게임 엔진 테스트, iPhone 앱 컴파일과 설치 파일 포장이 모두 통과했습니다. 실제 GPS 분류와 Apple Watch 평균 페이스의 일치 정도는 실기기 활동으로 다시 확인해야 합니다.

## 짧은 실기기 확인

1. 야외 현장 사냥, 시간 목표 20분을 선택하고 ‘첫 잔향 토벌’을 추적합니다. 출발 전 위치 신호가 양호한지 확인합니다.
2. 몇 분 달린 뒤 **일시정지**를 누릅니다. 활동시간과 전체 평균 페이스의 시간 분모가 멈추는지 확인하고, 다시 **계속**을 눌러 움직입니다.
3. 실제 이동시간 약 6분 전후에 첫 잔향 늑대 구간을 확인합니다. 잠깐 걷거나 신호가 약해져도, 다시 달리기와 양호한 신호가 확인되면 조우해야 합니다.
4. 일시정지를 제외한 활동시간이 20분이 되면 자동으로 활동 보고가 열리는지 확인합니다. Watch와 비교할 때는 양쪽을 같은 시점에 일시정지·재개해주세요.

페이스는 두 기기의 GPS 경로와 거리 누적 방식이 달라 완전히 같을 필요는 없습니다. 늑대가 다시 나타나지 않으면 활동 화면의 **움직임 판정**과 **위치 신호**, 종료 보고의 기록을 알려주세요.
