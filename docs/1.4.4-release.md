# Hunter Run 1.4.4 — 이후 토벌 기회 보존

버전 1.4.4 / 빌드 46입니다. 기존 앱을 삭제하지 않고 덮어 설치하면 활동 기록과 이야기 진행도가 유지됩니다.

- 야외 현장 사냥에서 첫 늑대 이후의 몬스터도 예정 시점에 잠깐 걷거나 GPS가 약해지면 최대 90초 동안 조우를 보류합니다. 다시 달리고 위치 신호가 양호해지면 그 전투가 시작됩니다.
- 계속 걷는 활동은 조사로 전환되어 진행이 멈추지 않습니다. 탐험 모드는 원래대로 조사 중심입니다.
- 진행 중인 일반 전투에서 GPS가 잠깐 약해지면 판정만 멈추고, 신호가 회복되면 이어집니다. 가속 전투는 불확실한 신호에서 즉시 안전하게 취소됩니다.
- 추적한 일반 의뢰의 활동 시간과 표본은 평소 활동에서도 쌓입니다. 승급 심사는 별도 보스전입니다.

## 짧은 실기기 확인

야외 **현장 사냥**을 선택하고, 활동 화면의 움직임 판정과 GPS 상태를 확인하며 달려주세요. 몬스터 예정 시점에 횡단보도 대기나 일시적인 GPS 저하가 겹쳐도, 목표 길이에 따른 대기 시간 안에 달리기와 양호한 신호가 돌아오면 조우가 이어지는지 확인할 수 있습니다. 계속 걷거나 위치 신호가 오래 불안정하면 전투가 보장되지는 않습니다. 탐험 모드는 조사 중심으로 유지됩니다.
