# Hunter Run 1.5.0 — 게이트·보스·승급 개편

버전 1.5.0 / 빌드 47입니다. 기존 앱을 삭제하지 않고 덮어 설치해야 과거 기록과 진행도가 유지됩니다. **iPhone 실기기 검증 전의 시험 빌드**입니다.

- 현장 사냥 준비 화면에서 일반 게이트 추적을 켤 수 있습니다. 추적 중인 적격 야외 사냥에서 첫 출현 확률은 60%이며, 놓치면 다음 적격 사냥에서 보장합니다. 걷기·GPS 불량·짧은 활동은 추적 횟수를 소모하지 않습니다.
- 발견한 일반 게이트에서 철수하면 다음 적격 활동에서 다시 접근할 수 있습니다. 핵심 개체 HP는 새로 시작합니다.
- 고위험 게이트에서는 이름 있는 주요 대상만 고릅니다. 첫 토벌 이후 허용된 대상의 재전은 잔향 재현, 변이 전투는 변이 재현으로 표시합니다.
- 과거 승급용 게이트 실적은 차감하지 않습니다. 새 활동부터 일반 게이트 해결과 주요 보스 첫 토벌만 실적을 주며, 승급 심사와 재현은 별도 보상을 줍니다.
- 저장 실패 뒤 결과 저장을 다시 시도해도 동일 활동이 한 번만 정산되도록 결과 저장 단계를 묶었습니다.

## 실기기 확인

관측부 Lv.2와 D급 이후 현장 사냥 준비에서 ‘일반 게이트 추적’을 켭니다. 야외에서 현장 사냥을 하며 게이트 출현·전투·철수 후 재접근·코어와 누적 게이트 실적을 확인합니다. 적격 활동 두 번 안에 게이트가 나타나는지 확인해주세요. 실내와 GPS 불량 활동은 천장이 소모되지 않아야 합니다. 주요 보스의 HP 이어하기와 첫 토벌·재현 보상 분리도 확인 대상입니다.
