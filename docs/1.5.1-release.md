# Hunter Run 1.5.1 — 늑대 의뢰 출현 기회 보존

버전 1.5.1 / 빌드 48입니다. 기존 앱을 삭제하지 않고 덮어 설치해야 기록과 진행도가 유지됩니다. 실제 iPhone 야외 러닝 검증은 별도로 필요합니다.

- 열린 첫 잔향 토벌·잔향수 분석 의뢰가 있으면 추적 버튼 선택과 무관하게 야외 현장 사냥에 늑대를 우선 배치합니다.
- 자유·거리 목표에서 20분 활동 주기가 넘어가도 출현 대기 중인 늑대 의뢰의 기회를 보존합니다.
- 야외 달리기 판정과 GPS 양호가 함께 확인되면 조우합니다. GPS·페이스 측정 기준을 완화하지 않습니다.
- 의뢰 완료 뒤에는 일반 몬스터 선택으로 돌아갑니다. 기존 저장 데이터와 보상은 유지합니다.

## 검증

미선택 상태의 열린 늑대 의뢰와 자유 활동 주기 경계의 조우 보존을 회귀 테스트에 추가했습니다. 원격 macOS에서 전체 Swift 테스트 190개가 실패 없이 통과했고, iPhone Release 컴파일과 IPA 패키징도 성공했습니다. 설치 파일의 버전, 실행 파일 및 기존 음성 177개의 해시도 검증했습니다.

## 설치

[1.5.1 빌드 48 다운로드](https://github.com/minwoo-106/Hunter-Run/actions/runs/36652771665/artifacts/11070757740)

다운로드한 ZIP에서 `HunterRun-1.5.1-build48-unsigned.ipa`만 AltStore로 설치합니다. 기존 앱에 덮어 설치하면 진행도를 유지할 수 있습니다. 파일은 2026년 10월 7일 오전 10시(KST)까지 제공됩니다.

설치 후 새 야외 현장 사냥을 시작해 실제 달리기 판정과 늑대 조우를 확인해야 합니다. 자동 테스트 통과가 실기기 GPS 및 동작 판정까지 검증한 것은 아닙니다.
