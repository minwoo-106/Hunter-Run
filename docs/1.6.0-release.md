# Hunter Run 1.6.0 — 공간으로 보는 협회 시설

버전 1.6.0 / 빌드 49입니다. 기존 앱을 삭제하지 않고 덮어 설치해야 기록과 진행도가 유지됩니다.

- 협회 관리의 첫 화면을 시설 조감도로 바꾸고 네 부서의 내부로 바로 들어갑니다. 의뢰와 주간 조사 탭도 유지합니다.
- 관측부·연구부·장비지원부·의뢰부는 Lv.1~3마다 서로 다른 설비 그림을 사용합니다. 확장은 기존 자원·등급 조건에 따릅니다.
- 각 부서의 업무가 실제 관측·개체 분석·장비·의뢰 화면으로 연결됩니다. 관측부에는 회전 레이더 효과를 넣지 않습니다.
- 지상 관제실과 지하의 안정화 게이트로 연결된 시설 구역을 구분하고, 협회 진입 연출과 초반 안내를 연결했습니다.
- 후반의 일회성 시설은 조건 충족 전에는 빈 공간으로 남습니다. 표시와 터치가 없으며 진행 이후에 건설·가동할 수 있습니다. 기존 완료 기록은 유지됩니다.
- 시설 내부에 작은 부유 입자를 적용했습니다. 동작 줄이기 설정 또는 앱이 비활성 상태이면 애니메이션을 멈춥니다.

운동 거리·시간·페이스와 몬스터 출현, 보상 및 기존 장비 밸런스는 1.5.1과 동일합니다. 기존 승인 음성은 변경하지 않았고 시설 관련 이야기 안내만 텍스트로 보강했습니다. 줄거리는 공개하지 않습니다.

## 검증 및 설치

설치 파일은 원격 iPhone 컴파일·게임 테스트·시설 UI 검증이 끝난 뒤 이곳에 연결합니다.
