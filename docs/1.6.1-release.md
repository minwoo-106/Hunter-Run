# Hunter Run 1.6.1 — 홈 오퍼레이터 생활 모션

버전 1.6.1 / 빌드 54. 코드 적용 완료, 새 설치 파일 검증은 대기 중입니다.

## 적용한 동작

- 양팔 기지개와 힘주는 표정 → 기본 호흡·눈깜빡임 → 천천히 눈을 감으며 졸기.
- 졸 때 캐릭터를 누르면 놀람 → 부끄러움과 세 줄의 임시 대사 → 기본 자세.
- 이후 커피 향 음미, 태블릿 확인, 멍때리기, 한 손으로 머리 넘기기, 햄버거 먹기를 기본 자세 사이에 순환합니다.
- 점심 중 터치하면 볼이 부푼 놀람 → `>_<` 표정으로 가슴 두드리기 → 급히 빨대로 콜라 마시기 → 기본 자세.
- 졸음과 점심 반응 중 연속 터치는 대화를 열거나 반응을 다시 시작하지 않습니다. 다른 때는 기존 대화를 엽니다.
- 승인된 16장의 투명 그림을 그대로 사용합니다. 기본 위치를 낮추지 않고 위쪽 그리기 영역을 확장했습니다. 기존 버튼과 대화 카드 배치는 유지합니다.
- 화면 전환·다른 메뉴·대화·설정·활동·백그라운드에서는 상태 시간을 멈춥니다. 동작 줄이기는 정지 그림으로 반응하며 모션 끄기는 기본 자세와 기존 대화를 유지합니다.
- 대사와 시간은 `Resources/operator-life-cues.json`, 상태 제어는 `Sources/OperatorLifeCore`, 그리기는 `App/OperatorLife`로 분리했습니다.
- 새 음성·메뉴·보상·스토리 조건은 없습니다. 기존 운동과 게임 엔진, 저장 형식은 변경하지 않았습니다. 정상 앱의 식별자 `com.hunterrun.demo`를 유지합니다.

## 현재 검증

Windows에서 전체 콘텐츠 검사, 승인한 16장 이미지의 해시·RGBA 형식·1024×1536 크기, 대사 파일, 정상 앱 연결 검사를 통과했습니다. 첫 실행을 우회하던 PoC 전용 분기는 제거했습니다. 기존 게임 데이터·음성 검사도 통과했습니다.

아직 **빌드 54 Swift 컴파일, 게임 및 생활 모션 단위 검사, 두 iPhone 크기의 UI 검사는 실행되지 않았습니다.** 게임 엔진 193개와 생활 상태·잘못된 설정 처리 11개의 단위 검사, 실제 연속 활동 순환과 화면 복귀를 포함한 생활 UI 검사 6개 및 홈·등록 회귀 검사 4개를 두 화면 크기에 실행하도록 준비했습니다. 이 수치는 준비한 검사 수이며 통과 수가 아닙니다. 빌드 52의 PoC 성공 결과를 1.6.1의 검증 결과로 취급하지 않습니다.

[GitHub 빌드 요청](https://github.com/minwoo-106/Hunter-Run/actions/runs/36710364313)은 실행기 시작 전에 계정 결제·사용 한도 제한으로 중단됐습니다. 코드 컴파일 오류는 보고되지 않았습니다. 기존 Codemagic에 `ios-build-1.6.1-54` 태그로 대체 빌드를 요청했습니다. 로그인 후 확인한 계정 화면은 무료 macOS 빌드 시간 **506/500분 사용**으로 새 빌드 시작이 비활성 상태입니다. 두 경로 모두 실행기 시작 전에 막혀 있습니다. 결제·사용 한도·공개 범위 설정을 바꾸지 않았습니다.

**새 IPA 다운로드 링크는 아직 없습니다.** 검증에 성공하면 여기에 실제 빌드 소스, 검사 결과, IPA 해시와 다운로드를 기록합니다. 기존 앱을 삭제하지 않고 새 정상 앱 IPA를 덮어 설치해야 기록을 유지할 수 있습니다.

## 표현 방식과 한계

현재 방식은 그림 사이의 짧은 전환, 작은 전체 회전·호흡 변형, 눈깜빡임과 두 장의 씹기·가슴 두드리기 그림 교차 표시입니다. 팔·손·머리의 관절을 연속적으로 움직이는 Cubism 리깅이 아닙니다.

실제 Live2D로 전환하려면 가려진 부분까지 그린 파츠별 PSD, 눈·입·머리카락·팔·몸의 메시와 변형기, 표정·모션·물리 리깅 및 `.moc3`·`.model3.json`·텍스처·모션 파일이 필요합니다. `OperatorLifeRendering`을 구현하는 렌더러로 바꾸어 현재 상태 제어를 재사용할 수 있습니다.

그림 16장을 모두 RGBA로 해제하면 약 96 MiB이며 이는 실제 앱 메모리 측정이 아닙니다. 렌더러는 현재 상태에 필요한 그림만 표시합니다. 실제 iPhone의 GPU 프레임, 최대 메모리와 발열은 이번 Windows 환경에서 측정하지 못했습니다.
