# Hunter Run 1.6.3 · 빌드 56

## 친밀도 체크포인트

대화 화면 상단의 하트 버튼에서 현재 친밀도를 `현재 값 / 100`으로 확인합니다. 관계 성장 구간을 0→20→40→70→100으로 넓히고 친밀도 MAX도 100으로 맞췄습니다.

| 관계 | 친밀도 기준 |
| --- | --- |
| 1단계 · 배정된 파트너 | 0 |
| 2단계 · 익숙한 동료 | 20 |
| 3단계 · 믿고 기대는 사이 | 40 |
| 4단계 · 특별한 파트너 | 70 |
| 5단계 · 서로의 편 | 100 |

각 체크포인트에 달성 여부, 현재 단계, 부족한 친밀도를 표시합니다. 숫자는 채웠지만 이야기 조건이 남은 경우 `친밀도 충족 · 이야기 진행 필요`로 안내합니다. 구체적인 메인 이야기 내용은 공개하지 않습니다.

## MAX 표시

- 최종 5단계에 도달하면 `관계 MAX · 5 / 5단계`를 표시합니다.
- 수치 100에 도달하면 `친밀도 MAX`를 표시합니다. 친밀도 MAX여도 이야기 조건이 남았다면 최종 관계는 아직 잠겨 있습니다.
- 상한에서 선물 화면에 추가 친밀도가 없다는 안내를 표시하고, 건네기 버튼과 받은 반응도 `친밀도 MAX`로 표시합니다. 선물 하나를 건네는 동작과 재고 소비는 유지합니다.
- 선물 +2, 이야기 보너스 +4는 유지하되 상한까지 남은 만큼만 오릅니다. 상한에 도달한 뒤에도 이야기 완료와 저장이 정상적으로 이어집니다.

이전 버전에서 이미 달성한 관계 단계와 열린 대화를 보호합니다. 새 기준보다 낮은 점수로 달성했던 관계에는 유지 안내를 표시하며, 업데이트와 재실행 후에도 단계가 내려가지 않습니다.

이전 점수가 100을 넘었다면 원래 저장값은 보존하고 화면에는 `100 / 100 · 친밀도 MAX`로 표시합니다. 추가 점수를 지급하거나 원래 값을 낮추지 않습니다. 선물 재고, 대화 선택, 운동 기록과 이야기 진행을 유지합니다. 새 대사나 음성을 추가하지 않으며 운동·전투·기존 보상 계산은 변경하지 않습니다.
