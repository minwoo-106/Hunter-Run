# Hunter Run 1.7.0 — 지부 방어 작전

버전 1.7.0 / 빌드 57. 2026-10-07 기준 iPhone 설치 파일 제작·검증 중이다. 아래 기능의 코드와 승인 자산은 반영했으며, 설치 링크는 실제 빌드 검증이 끝난 뒤 추가한다.

## 새로 할 수 있는 것

헌터 활동 → **지부 방어 작전**에서 30회로 끝나는 별도 홈트 이야기를 시작한다. 연속 출석이나 달력 기한이 없으며 쉬었다가 다음 회차를 이어간다. 플레이하지 않았다고 시설이 파괴되거나 자원이 차감되지 않는다.

- 회차당 24분: 준비 4분 / 교전 5분 / 재정비 1분 / 교전 5분 / 재정비 1분 / 교전 5분 / 정리 3분.
- 가볍게·기본·조금 더 도전: 각 교전 1분 안에서 동작 20·30·40초, 나머지는 회복·준비다. 이야기와 그림 보상은 같다.
- 제자리 걷기, 좌우 스텝, 니업, 스쿼트, 벽 푸시업, 뒤꿈치 들기, 가벼운 섀도복싱. 시작 전 동작 설명과 쉬운 대안을 볼 수 있다.
- 운동 중에는 오디오 안내를 따라간다. 화면 잠금·다른 앱 이동·통화·이어폰 분리는 일시정지하며, 계속 버튼으로 재개한다.
- 중간에 저장하고 나와도 현재 회차를 이어간다. 완료한 작전 기록과 생활 앨범을 다시 볼 수 있다.
- 1·5·10·15·20·25·30회차 생활 일러스트, 30회차 별도 비하인드. 매회 최초 완료 시 EXP 10·마정석 2.

## 기존 기록과의 관계

기존 실내 러닝의 새 시작 입구를 교체하며 과거 기록과 성과는 유지한다. 야외 거리·페이스·토벌·메인 스토리는 별도다. 방어전의 안내 완료 시간은 실제 운동 자세·횟수·칼로리 인증값이 아니며, Apple Watch나 HealthKit은 이번 버전의 필수 조건이 아니다.

## 검증 상태

- Windows/WSL Swift 6.2 게임 테스트 226개 통과.
- 30회 × 3강도 시간 구성, 중복 정산 방지, 중단 후 재개, 구세이브 보존 검사 통과.
- 사용자가 승인한 음성 151개·이미지 9개를 해시로 고정. 수정본 47개를 앱에 반영하고 바뀐 2개 대사를 자막과 동기화했다.
- GitHub Actions는 계정 결제/사용 한도 사유로 실행되지 않았다. Codemagic에서 동일 커밋의 iOS 빌드와 두 화면 크기 검증을 진행한다.
- 실제 iPhone의 24분 운동 사용감·발열·배터리·통화/오디오 장치 변화는 설치 후 확인할 항목이다.

설치 시 기존 앱을 삭제하지 않고 같은 번들 ID `com.hunterrun.demo`에 IPA를 덮어 설치한다. iPhone용 파일은 APK가 아닌 IPA다.
