# 1.7.1 — 전투 거리와 승급 조건 안내

## 수정 내용

- 장기전 게이지를 `달리기 인정 거리`로 표시하고 전체 이동거리와 구분한다.
- 조우 후 양호한 GPS에서 달리기로 판정된 구간만 누적하는 기존 규칙을 안내한다. 걷기·정지·GPS 확인·안내 중·일시정지의 대기 이유를 함께 표시한다.
- 승급 조건 카드에 전용 승급 심사 토벌 항목을 추가한다. 이야기 진행으로 심사를 열어야 하는 상태와 열린 심사의 토벌 대기를 구분한다.
- 활동 중 또는 저장한 활동 때문에 승급이 잠긴 경우 이유를 표시한다.
- 운동 측정, 전투 인정 기준, 승급 조건, 기존 저장 데이터 및 승인된 음성·일러스트는 변경하지 않는다.

## 재현과 검증

- 총거리 560m 중 달리기 인정 33m인 상황에서 장기전 게이지가 33m 증가하는 실제 엔진 경로를 재현했다. 보고된 사진과 일치하는 가능한 조건이며, 사용자의 실제 구간별 센서 기록을 재현한 것은 아니다.
- 레벨 15·누적 434분이어도 전용 심사가 완료되지 않으면 승급되지 않는 조건과 완료 후 승급을 검사했다.
- 휴대 가능한 Swift 테스트 229개 통과. Swift 구문과 셸 스크립트 구문 확인 통과.
- 두 아이폰 화면 크기에서 거리 안내, 심사 미해금, 심사 출동, 실제 승급, 저장한 활동 잠금 및 홈 화면을 검사하도록 구성했다.
- iPhone Release 빌드와 화면 검사, 실제 IPA 검증은 대기 중이다. 이 문서는 설치 파일 생성 성공을 의미하지 않는다.

## 현재 버전에서 확인하는 방법

승급 화면 아래의 ‘전용 승급 심사 확인’에서 현재 의뢰를 확인한다. 심사가 아직 잠겨 있으면 지부 이야기와 현재 의뢰를 진행한다. 기본 자격을 갖춘 뒤 전용 감시체를 토벌해야 승급할 수 있다.

사진만으로는 실제로 걷고 있었는지, 달렸는데 걷기로 판정됐는지 확정할 수 없다. 이번 수정은 기준과 대기 이유를 설명하는 것으로, 운동 분류 정확도 개선을 주장하지 않는다.
