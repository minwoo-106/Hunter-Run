# 1.7.2 — 생활 앨범 일러스트와 감상 화면

## 반영 내용

- 사용자가 최종 승인한 생활 일러스트 7장과 마지막 비하인드 1장, 제목·설명을 반영한다.
- 빵집, 졸린 침대 컷, 새 운동복, 떡볶이·우유·튀김, 쇼핑카트 장면을 채택한다. 사적인 장면의 업무용 이어피스를 제거한다.
- 일반 글자 크기에서는 그림 전체와 설명, 비하인드 버튼이 화면 높이에 맞춰 배치된다. 큰 접근성 글자에서는 읽을 수 있는 크기를 유지하며 스크롤한다.
- 음성, 앨범 해금 조건, 운동·전투·보상·저장 규칙은 변경하지 않는다.

## 검증 상태

- 콘텐츠 및 승인 이미지 해시 검사 통과.
- 오퍼레이터 생활 모션 자산 검사 통과.
- 화면 검사 스크립트 문법 검사 통과.
- 두 iPhone 화면 크기에서 전체 8장 감상, 비하인드 전환, 접근성 큰 글자, 홈 화면 검사를 준비했다.
- iPhone 컴파일과 실제 설치 파일 검증은 빌드 완료 후 기록한다.

## 설치

1.7.2(빌드 59) 설치 파일 준비 중. 검증 완료 후 Codemagic 다운로드 페이지를 기록한다.
