# 1.7.2 — 생활 앨범 일러스트와 감상 화면

## 반영 내용

- 사용자가 최종 승인한 생활 일러스트 7장과 마지막 비하인드 1장, 제목·설명을 반영한다.
- 빵집, 졸린 침대 컷, 새 운동복, 떡볶이·우유·튀김, 쇼핑카트 장면을 채택한다. 사적인 장면의 업무용 이어피스를 제거한다.
- 일반 글자 크기에서는 그림 전체와 설명, 비하인드 버튼이 화면 높이에 맞춰 배치된다. 큰 접근성 글자에서는 읽을 수 있는 크기를 유지하며 스크롤한다.
- 음성, 앨범 해금 조건, 운동·전투·보상·저장 규칙은 변경하지 않는다.

## 검증 상태

- 콘텐츠 및 승인 이미지 해시 검사 통과.
- 오퍼레이터 생활 모션 자산 검사 통과.
- 화면 검사 스크립트 문법 검사 통과.
- Codemagic #58에서 iPhone Release 컴파일과 Swift 테스트 229개를 통과했다.
- iPhone 17 Pro 및 작은 화면 시뮬레이터에서 전체 8장 감상, 비하인드 전환, 접근성 큰 글자, 홈 화면 검사 각 3개·총 6개를 통과했다.
- 작은 화면의 실제 앱 캡처 8장과 운동복·큰 글자 화면을 시각 확인했다. 일반 크기에서는 그림·설명·비하인드 버튼이 화면 안에 배치된다.
- 내려받은 IPA의 버전·빌드, 게임 데이터, 음성 367개 해시, 방어전 자산 9개와 생활 모션 16개 포함, 시험 데이터 제외를 검증했다. [설치 파일 검증 기록](1.7.2-installer-verification.json).
- 이번 검증은 시뮬레이터 및 설치 파일 검사이며, 실제 iPhone에서 직접 실행한 검증은 아니다.
