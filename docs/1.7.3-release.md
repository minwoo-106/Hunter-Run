# 1.7.3 — 활동 성장과 거리 전투

- 확정된 3차 경험치·레벨 곡선·공격력 소프트캡·장비 계수를 적용한다.
- 활동 레벨은 헌터 등급과 분리한다. 탐색과 주간 의뢰로 성장한 E급 고레벨 기록을 그대로 유지한다.
- 기존 레벨·총 경험치·장비·등급·스토리·시설을 보존하며, 기존 고레벨의 실질 공격력 하한도 보호한다.
- 조우 안내 후 인정된 달리기 75m마다 공격한다. 몬스터 HP와 공격 횟수·다음 공격 누적을 각각 표시한다.
- 일반 몬스터의 미완료 HP는 세션 종료 후 초기화하고, 주요 보스·승급 심사는 실제 피해를 저장해 이어간다.
- 몬스터별 고정 경험치는 토벌 때 한 번만 지급한다. 기존 보스·심사 완료 보상은 유지한다.
- 승급 심사와 재전 보스를 동일 거리 전투에 연결한다. 이미 진행 중인 보스의 최대·남은 HP는 변경하지 않는다.
- 업데이트 전에 시작한 활동은 기존 스냅샷으로 마치고 다음 활동부터 새 규칙을 사용한다.
- 경험치 표시가 새 레벨 요구량을 따르도록 연결한다.
- 수동 일시정지·안내를 가로지르는 묶음 GPS 거리와 종료 프레임·중복 정산 문제를 방어한다.
- 새 방식과 맞지 않는 고정 시간·400m 안내는 기존 승인 음성 중 일반 유지 안내로 대체한다. 새 음성이나 일러스트는 생성하지 않는다.

## 검증

로컬에서 기존 기능을 포함한 Swift 테스트 273개, 레벨·장비 조합 72행, 세이브 진행값 300개와 대표 재생 시나리오 12개를 통과했다. 승급 심사·주요 보스·재전 대상 12종의 실제 전투 연결과 정산을 추가 검증했다. 게임 콘텐츠·기존 승인 음성·생활 이미지 검사도 통과했다.

iPhone용 배포 컴파일에 성공했다. iPhone 17 Pro와 375×667 크기의 소형 iPhone 시뮬레이터에서 각각 화면 검사 10개, 총 20개가 모두 통과했다. 전투 HP·75m 공격 누적·걷기 보류·일시정지·승급 조건·홈 화면을 확인했다. 원격 Mac에서도 핵심 테스트 273개와 전투 재생 12개를 통과했다. 물리 iPhone의 센서·음성·공격 간격 체감은 설치 후 확인 범위다.

설치 파일은 버전 1.7.3, 빌드 60으로 생성·다운로드·검증 완료했다. 게임 자료 18개와 승인 음성 367개의 내용이 소스와 일치하며 방어전 이미지 9개·생활 이미지 16개가 포함되어 있다. 배포 실행 파일에 시뮬레이터용 시작 옵션이 포함되지 않은 것도 확인했다.
