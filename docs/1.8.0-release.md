# 1.8.0 — 공간을 잇는 화면 전환

- 승인된 시연 04를 바탕으로 시작 화면의 흡입 가속, 원화 잔상, 경계 잔광을 네이티브로 옮겼다. 2.1초 뒤 실제 홈으로 연결한다.
- 협회 관리: 문에 붙은 양쪽 잠금 장치가 해제되고 두꺼운 문이 레일 안으로 열린다. 중앙 막대·회전 원 장식은 제거했다.
- 헌터 활동: 원화의 룬을 따라 빛이 이어지고 게이트가 안정된다. 활동 준비 화면도 같은 게이트 원화를 사용한다.
- 헌터: 승인된 개인 증표와 무기·방어구·기록 장치의 순차 점등을 적용했다.
- 홈의 미니 오퍼레이터와 도감 두루마리의 기존 연출은 유지했다.
- 목적지 화면을 전환 덮개 아래에서 먼저 준비하고, 전환 중 재입력을 막는다. 앱이 비활성화되면 목적지로 정리해 복귀 시 덮개가 남지 않게 한다.
- 동작 줄이기 설정에서는 강한 진입·메뉴 연출을 생략한다. 배경에서는 장면 타임라인을 멈춘다.
- 세이브 형식, 운동 측정, 전투, 경험치, 보상, 음성, 스토리는 변경하지 않았다.

## 제작과 검증 범위

웹을 앱에 삽입하지 않고 SwiftUI Canvas에서 동일 원화와 시간 곡선을 사용한다. 원화 분리·발광 텍스처는 한 번 준비해 재사용한다. 웹의 예시 홈 이미지 대신 실제 사용자 홈으로 연결한다.

콘텐츠·승인 음성·생활 이미지 무결성 검사는 로컬 통과. iPhone 배포 컴파일과 두 화면 크기의 시작/다섯 탭/백그라운드 복귀/중간 장면 검증은 빌드 서버에서 수행한다. 설치 파일 검증과 다운로드 주소는 빌드 성공 후 기록한다. 물리 iPhone 발열·프레임 체감은 아직 검증하지 않았다.
