# 1.8.1 — 저소음 전신 운동과 화면 전환 복귀

버전 1.8.1 / 빌드 62. App Store 정식 배포가 아닌 개인 설치용 iPhone 빌드입니다.

## 반영 내용

- 지부 방어 작전 1~30회에 20종 동작을 조합한 저소음 전신 루틴을 배치했습니다. 점프 없이 진행하고 서서 하는 동작을 먼저, 무릎을 짚거나 누워 하는 동작을 뒤에 모았습니다.
- 총 24분은 준비 4분 → 교전 6분 → 회복 1분 → 교전 6분 → 자세 전환 1분 → 교전 4분 → 정리 2분입니다. 준비 이후 20분 안에 회복·전환·정리가 포함됩니다.
- ‘가볍게 / 기본 / 조금 더 도전’은 각 1분 교전 구간에서 운동·준비 시간을 30/30초, 45/15초, 50/10초로 나눕니다. 이야기와 주요 일러스트 보상은 동일합니다.
- 매트 없이 진행할 수 있는 ‘서서 하기’를 제공합니다. 바닥 동작은 벽 푸시업·힙 힌지·스쿼트·교차 무릎 올리기·옆구리 접기 등으로 대체합니다.
- 사용자가 최종 승인한 신규 운동 안내 29개를 적용했습니다. 기존 캠페인 음성은 재사용하며, 승인된 WAV 해시를 빌드 검사에서 대조합니다.
- 홈 제스처와 백그라운드 이동 시 시작·메뉴 애니메이션이 바로 끝나던 처리를 수정했습니다. 비활성 상태에서는 연출 시간을 멈추고 복귀 후 남은 구간을 이어 재생합니다. 동작 줄이기 설정은 유지합니다.
- 일시정지·중단 뒤 오래된 운동 음성 재생 요청이 뒤늦게 이어지는 것을 방어합니다.
- 기존 야외 측정·75m 전투·성장 규칙은 변경하지 않았습니다. 저장된 기록·스토리·보상과 진행 중인 이전 방어전 루틴을 보존합니다.

## 검증과 확인 범위

- 로컬 Swift 테스트 280개가 실패 없이 통과했습니다. 전환 시간의 중단·복귀와 30회×3강도×두 자세 방식의 운동 구성을 포함합니다.
- 신규 운동 안내 29개는 사용자가 청취 후 승인했으며, 승인 기록은 `indoor-defense/reviews/workout-v2-approval.json`에 보관합니다.
- Codemagic 빌드에서 콘텐츠 검사, 게임 엔진 테스트, iPhone 컴파일, 시뮬레이터 화면 검사, IPA 생성·게시가 완료됐습니다.
- 실제 iPhone에서 홈 제스처 복귀의 사용감, 운동 전환·음성 간격, 24분 운동과 발열·배터리는 설치 후 확인 범위입니다. 자동 검사 통과를 실기기 운동 검증으로 대신하지 않습니다.
- 방어전은 시간과 안내 진행을 기록하며 실제 자세·칼로리·운동량을 인증하지 않습니다. Apple Watch·HealthKit 직접 연동은 포함하지 않습니다.
