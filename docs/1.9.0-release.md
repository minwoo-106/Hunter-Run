# 1.9.0 — 장비 성장과 운동 리포트

버전 1.9.0 / 빌드 63. App Store 배포가 아닌 개인 설치용 iPhone 업데이트입니다.

## 연출

- D: 금속 조각이 천천히 모이는 청동 인장.
- C: 여러 방향에서 짧고 강하게 결합하는 은빛 인장.
- B: 파편이 회전하며 중심으로 모이고 드러나는 공명 코어.
- A: 아래에서 드러나는 자수정 인장과 빛줄기·보석 결합.
- S: 금빛 파편 압축, 짧은 정적, 왕관 돌출과 충격파, 정착.
- 신규 장비는 별도 획득 화면에서 확인하고 바로 장착할 수 있습니다.
- 보상은 EXP 숫자와 자원 항목을 순서대로 보여줍니다. 화면 연출은 정산을 재실행하지 않습니다.
- 그래프는 처음 나타날 때만 짧게 채워지고, 전투 연출은 실제 공격 시점에만 반응합니다.
- 동작 줄이기를 따르며 전체 화면 연출은 백그라운드에서 멈추고 복귀 후 이어집니다.

## 기록과 기존 사용자 보호

- 활동 레벨, 누적 EXP, 장비, 등급, 스토리, 시설과 기존 기록을 유지합니다.
- 운동 판정, 전투 공식, 75m 공격 간격, 경험치·보상 수치를 바꾸지 않습니다.
- 장비 시험실은 실제 전투 계산 함수를 재사용합니다. 최대 HP를 기준으로 하며 조우 대기·음성·GPS 보류 구간은 예상 거리에 포함하지 않습니다.
- 장비 조합은 이미 보유한 장비만 착용할 수 있고, 야외 활동·방어전 중에는 변경할 수 없습니다.
- 과거 기록에 없는 장비 획득일, 당시 착용 장비, 레벨 변화를 추정하지 않습니다. 새 기록부터 누적합니다.
- 방어전은 실내 시간·횟수에 합산하고 야외 거리·페이스와 분리합니다. 리포트의 러닝 EXP에는 방어전 보상을 섞지 않습니다.
- 평균 페이스는 총 거리와 기록된 시간을 사용합니다. 코스·날씨 차이를 무시한 실력 향상이나 운동 처방을 제시하지 않습니다.

## 검증 상태

- 게임 엔진 자동 테스트 292개 통과. 장비 비교와 실제 전투 공식의 일치, 조합의 원자적 적용, 활동 중 착용 제한, 정산 중복 방지, 과거 기록 호환과 실내·야외 집계 분리를 포함합니다.
- iPhone 16 Pro와 iPhone SE(3세대) 시뮬레이터에서 각 10개, 총 20개 UI 검사 통과. 장비 목표·시험실·조합 저장과 착용, 리포트, D~S 승급, 획득, 백그라운드 복귀, 전투와 홈 화면을 확인했습니다.
- 실제 앱 캡처 38장과 D~S 승급 녹화 5개를 확보했습니다. HTML 모형이 아닌 SwiftUI 앱 실행 결과입니다.
- Release iPhone 앱 컴파일과 설치 파일 패키징 통과. [검증 빌드](https://github.com/minwoo-106/Hunter-Run/actions/runs/40331032989)의 앱 소스는 `d3b33a467f8f54282dbaa8a718d2ae1129f73a05`입니다.

검사 중 승급·획득 연출이 초기 비활성 상태를 계속 참조해 멈추는 문제를 발견했습니다. 활성 상태 변경 시 작업을 재시작하되 누적 연출 시간을 보존하도록 수정했고, 백그라운드 복귀 회귀 검사도 통과했습니다. 자동 UI 검사가 장비 조합 저장 버튼을 지나쳐 스크롤하던 문제는 요소의 현재 위치를 기준으로 이동하도록 수정했습니다.

실물 iPhone의 발열·배터리·야외 사용감은 시뮬레이터 검사와 별도입니다. 화면 캡처의 운동량과 장비는 테스트 전용 예시 데이터입니다.

## 설치

[GitHub Actions 빌드 페이지](https://github.com/minwoo-106/Hunter-Run/actions/runs/40331032989)에서 `HunterRun-1.9.0-build63-iPhone` 자료를 내려받고 압축을 풀면 설치 파일이 있습니다. 빌드 자료 보관 기한은 2026년 11월 2일까지이며 다운로드에는 GitHub 로그인이 필요할 수 있습니다.

`HunterRun-1.9.0-build63-unsigned.ipa`를 기존처럼 AltServer·AltStore로 개인 서명하여 기존 앱 위에 설치합니다. 앱 식별자는 `com.hunterrun.demo`를 유지합니다. 기존 앱을 삭제하지 마세요. 이번 빌드는 GitHub Actions에서 생성했으며 이전 Codemagic 1.8.1 설치 페이지와 다릅니다.
