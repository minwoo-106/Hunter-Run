# Hunter Run 1.9.1 — 장비 3슬롯과 실제 효과

## 변경 사항

- 장비를 무기·신발·유물로 정리했습니다. 방어구 구매·착용 입구와 용도별 조합 UI를 제거했습니다.
- 새 활동에서 플레이어 HP·방어·HP 부족에 따른 사건 제한을 제거했습니다. 몬스터 HP와 75m 공격 누적은 유지합니다.
- 75m 거리 전투에 전달되지 않던 신발의 유지·추격 피해 옵션을 다음 일반 사건 대기 단축으로 교체했습니다. 최초 사건·보스·실내 활동은 제외하며, 한 번에 최대 30초를 단축합니다. 전투 사이 시간이 충분할 때 최소 30초를 남기고, 이미 예정 시각이 지난 사건을 오히려 늦추지 않습니다.
- 무기와 기존 상위 신발·유물의 공격 보정은 유지합니다. 유물의 조사 보너스도 실제 정산에 연결됩니다.
- 장비 비교 화면에 공격력·사건 대기 단축·조사 보너스를 표시합니다. 공격 횟수가 같더라도 피해량은 달라질 수 있으므로 장비 시험실에서 둘을 함께 비교합니다.

## 기존 기록 보호

보유 방어구의 카탈로그 가격을 마정석·조사 데이터·코어로 한 번 지급합니다. 과거 실제 구매 금액 기록이 없으므로 실제 구매가 환불이 아니라 단종 보상입니다. 보유 이력과 착용 활동 기록은 유지하고, 방어구 착용 상태와 방어구 목표만 정리합니다. 예전 장비 조합 자료도 세이브에서 지우지 않지만 화면에서 사용하지 않습니다.

진행 중이던 야외 활동과 실내 방어 작전은 완료 또는 종료 후 이행합니다. 구버전 야외 활동의 장비 스냅샷과 판정은 그 활동 종료까지 보존합니다. 새 활동부터 새 장비 규칙을 적용합니다.

레벨·EXP·등급·스토리·시설·기존 장비 소유는 유지됩니다. E급 Lv.15 기준 공격력 2.915, 잔향 늑대 159 피해·2회·150m, 철각 파수병 139 피해·3회·225m, 신호의 심장 152 피해·2회·150m를 확인했습니다.

## 검증

- 변경 전 신발 +8% 피해가 75m 전투에 반영되지 않는 현상을 자동 테스트로 재현했습니다.
- 장비 개편 회귀 테스트 12개와 기존 테스트를 합친 304개 통과.
- Lv.1·15·30·60·100과 모든 신발 조합에서 이행 전후 실제 공격력 유지 검사.
- 단종 보상 중복 방지·저장 재복원·활동 중 이행 보류·자원 상한 초과 시 원본 보존 검사.
- 실제 엔진에서 무기별 75m 피해와 토벌 거리, 신발의 다음 사건 시작 시각, 일시정지·GPS 불량·정지 중 공격 보류, 유물 조사 정산 검사.
- 콘텐츠·음성 파일 검증과 Swift 앱 소스 구문 검사 통과.
- Release iPhone 앱 컴파일·설치 파일 패키징 통과.
- iPhone 16 Pro와 iPhone SE(3세대) 시뮬레이터에서 각 11개, 총 22개 UI 검사 통과. 3슬롯·단종 보상 확인·신발 효과·도감·장비 비교·리포트·승급·백그라운드 복귀·전투·홈 화면을 확인했습니다.
- 실제 앱 화면 캡처 42장과 D~S 승급 영상 5개 확보. 화면의 진행도와 자원은 검사 전용 예시 데이터입니다.
- 내려받은 IPA의 버전·빌드·앱 식별자·게임 JSON과 기존 음성 파일 검증 통과. GitHub 아티팩트 ZIP의 SHA-256도 업로드 기록과 일치합니다.

아이폰 검증 중 출발 준비 화면에 남아 있던 삭제된 장비 조합 화면 참조를 제거했습니다. 단종 보상 카드가 확인 버튼의 접근성 식별자를 덮어쓰는 문제도 실제 화면 계층에서 확인해 수정했습니다. 보상 지급 자체는 정상 표시됐으며, 확인 버튼을 누르고 안내를 닫는 과정은 별도 UI 검사로 확인합니다.
