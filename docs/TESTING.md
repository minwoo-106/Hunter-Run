# First real-device test checklist

Record device/iOS and whether headphones were used. Do not test in traffic.
This is a test checklist, not a medical training plan.

1. Install the personally signed IPA. Confirm the association home and readable RUN button.
2. In RUN, allow location. Test audio over music you already started in another app.
3. Start a 5-minute real run with optional pursuit OFF. Allow Motion if prompted.
4. Lock the screen, walk/run in a safe area, stop for about 15 seconds, then move again.
5. Confirm progress pauses while stopped and resumes without touching the phone.
6. Confirm spoken cues mix with music and music returns to normal volume.
7. Pause manually and move: it must remain paused until Continue is tapped.
8. Unplug/disconnect headphones: the app should pause rather than unexpectedly continue instructions.
9. End early: acquired activity and completed-event rewards remain.
10. Complete another goal: automatic ending and one result are expected.
11. Close/reopen after a saved in-progress session: recover paused, no invented offline distance.
12. Export a backup and diagnostic report. Share only what you intend to share.

## Mock tests
Use three-minute simulation with 1x/5x/10x controls.
Try stationary, vehicle, GPS unavailable, and the recovery drill.
Simulation must not alter real XP/resources/history.

## Feedback to report
- Did lock-screen distance/time stop unexpectedly?
- Was stop/resume late?
- Were instructions heard fully and in the right order?
- Was music ducked too long?
- Any overlap/cropping with Dynamic Island, home indicator or large text?
- Crash, lost record, duplicate reward, excessive heat or battery drain?

## Known limits
No field results yet. Background GPS is requested, not guaranteed against OS termination.
Step-based distance can be unavailable or delayed. No exact raw route is saved.
Free personal signing normally needs periodic renewal; this is separate from game recovery.
