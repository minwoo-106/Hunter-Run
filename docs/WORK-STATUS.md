# 0.6.0 작업 상태

## 구현 완료
- 활동 준비 화면까지 BGM 재생, 실제/모의 활동 진입 시 정지.
- 헌터 활동 및 탐험/의뢰/게이트 조사/보스 토벌 명칭.
- 페이스 학습, 최근 5회 중앙값과 5% 변화 제한, 오늘 느린 페이스 우선.
