# Equipment artwork — 0.3

Twelve original raster assets generated individually with the built-in image tool on 2026-09-11.
Each original was visually inspected and copied unchanged into its Gear-<catalog-id>.imageset.
The asset-to-source filename mapping is in equipment-art-sources.json.

Shared direction: premium semi-realistic Korean urban-fantasy RPG item illustration;
one complete centered object (or pair of shoes), generous margins, dark navy studio background;
soft warm key light, cyan rim light, believable leather, fabric and metal; no text, people or UI.

The progression follows the existing item catalog:
- Field sword, resonance dagger, core spear.
- Tactical vest, barrier long coat, guardian chest armor.
- Practical field running shoes, trace high-tops, core armored shoes.
- Survey compass, archive monocle lens, orbiting crystal relic.

Basic items are restrained. Advanced items add cyan channels; core items add gold structure and crystal energy.
The app draws names, ownership, item tier, costs and effects separately. Images are bundled for offline use.
