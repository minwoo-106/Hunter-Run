# 장비 성장과 첫 토벌 — 다음 패치 설계

상태: 설계안. iPhone 1.3.5의 야외 거리·페이스 재측정 전에는 활동 센서와 현재 설치 빌드를 변경하지 않는다.

## 확인한 현재 동작

- 탐험 모드의 기본 사건은 조사 3개이며 잔향 늑대 전투가 없다. 잔향 늑대는 현장 사냥의 `beast` 사건에 들어 있다.
- 현장 사냥이라도 전투 슬롯에서 달리기 판정 또는 양호한 GPS 신호가 없으면 안전을 위해 조사 사건으로 전환한다. 이전 사용자 기록은 현장 사냥 36분 중 달리기 2분 13초, GPS 양호 0%였다. 1.3.5의 거리 보정 이후 현장 판정은 아직 실기기에서 다시 확인하지 않았다.
- 일반 고급 장비는 장비지원부 Lv.2와 제작 자원만으로 열린다. 잔향 늑대 토벌은 선행 조건이 아니다.
- 장비 목록의 `코어 장비` 표시는 현재 코어 제작 비용이 1개 이상이라는 뜻일 뿐, 별도의 성능 단계는 아니다.
- 월영·몽환 장비의 `requiredEvent`는 해당 사건의 중립이 아닌 기록을 요구한다. 실제 처치(`defeated`)는 요구하지 않는다.
- 공격력 총합 상한 ×3은 레벨 26의 기본 공격력만으로 도달한다. 이때부터 공격 장비의 수치가 실제 피해를 더 높이지 못한다. `eventBonus`는 유지·추격 피해 보너스인데 일부 장비 문구는 판정 보정처럼 읽힌다.

## 목표 성장 구조

| 구간 | 획득 목적 | 제안 조건 | 역할 |
| --- | --- | --- | --- |
| 기본 | 첫 활동과 장비 체험 | 낮은 자원 비용 | 슬롯별 효과를 익힌다 |
| 고급 | 첫 지부 확장 | 장비지원부 Lv.2와 일반 자원 | 첫 체감 성장; 첫 늑대 전에도 접근 가능 |
| 첫 코어 | 첫 전투 성취 | 실제 잔향 늑대 토벌과 첫 게이트 성과를 확인한 뒤 코어 제작 | 동일 역할의 고급 장비보다 확실한 기본 성능 상승 |
| 전문 장비 | 서로 다른 전술 선택 | 해당 엘리트 실제 토벌과 등급·시설 조건 | 공격·생존·조사 등 서로 다른 빌드 |
| C/B/A 장비 | 장기 성장 | 각 단계의 고유 강적 토벌, 등급, 제작 자원 | 이전 단계보다 높은 기본 성능과 고유 패시브 |

단계가 높아질수록 같은 역할의 장비는 명백히 강해진다. 같은 단계의 장비끼리는 공격·방어·조사 특성을 달리해 선택의 여지를 남긴다. 장비는 현실 목표 페이스를 낮추거나 높이지 않고 **게임 피해·생존·조사 결과**에만 영향을 준다.

## 필요한 구현 순서

1. 첫 늑대 토벌 경로를 먼저 검증한다. 탐험의 흔적 조사 뒤 현장 사냥으로 자연스럽게 안내하고, 아직 토벌하지 않은 사용자의 양호한 현장 사냥에는 첫 조우 기회를 확실히 제공한다. 걷기·나쁜 GPS를 전투로 위장하지 않으며, 조사로 전환된 이유를 활동 결과에 표시한다.
2. 장비 조건에 `발견`과 `실제 토벌`을 별도로 표현한다. 기존 `requiredEvent`는 호환성을 유지하고, 새 토벌 조건은 저장된 사건의 `defeated == true`로 판단한다. 과거 실제 토벌 기록도 소급 인정한다.
3. C/B/A 단계에 독자적인 강적·전술·삽화·도감·음성·제작 조건을 추가한다. 새 몬스터가 단순 열쇠로만 쓰이지 않도록 각 장비의 전투 역할과 연결한다. 이야기의 반전은 해금 전 UI에서 공개하지 않는다.
4. 공격·방어·조사 효과의 상한과 보스 체력을 함께 재조정한다. 레벨 상승과 장비 교체가 끝 단계까지 눈에 띄되 한 번의 사건으로 누적 보스를 지우지 않도록 실제 성장 경로를 시뮬레이션한다.
5. 보관함에는 성능 단계와 역할, 현재 장비 대비 실제 능력치 변화, 정확한 해금 조건을 보여준다. `코어 장비`라는 비용 기반 표시는 성능 등급과 구분한다. 피해 보너스를 `판정 보정`이라고 부르는 문구도 수정한다.

## 호환성과 검증

- 이미 구매·장착한 장비는 유지한다. 새 획득 조건을 추가해도 과거 보유 장비를 회수하거나 잠그지 않는다.
- 활동 중 저장된 전투 장비 스냅샷은 해당 활동이 끝날 때까지 유지한다.
- 첫 늑대 조우/토벌, 과거 토벌 인정, 장비별 실제 피해 차이, 레벨 26 이후의 공격 성장, C/B/A 획득 경로를 회귀 검사한다.
- 실기기에서 1.3.5의 거리·페이스·GPS·걷기/달리기 판정이 확인된 뒤, 게임 밸런스 패치를 별도 버전으로 묶어 테스트한다.
