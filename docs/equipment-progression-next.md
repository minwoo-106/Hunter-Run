# 장비 성장과 강적 토벌 — 다음 패치 설계

상태: 설계안. iPhone 1.3.5의 야외 거리·페이스 재측정 전에는 활동 센서와 현재 설치 빌드를 변경하지 않는다.

## 확인한 현재 동작

- 탐험 모드의 기본 사건은 조사 3개이며 잔향 늑대 전투가 없다. 잔향 늑대는 현장 사냥의 `beast` 사건에 들어 있다.
- 현장 사냥이라도 전투 슬롯에서 달리기 판정 또는 양호한 GPS 신호가 없으면 안전을 위해 조사 사건으로 전환한다. 이전 사용자 기록은 현장 사냥 36분 중 달리기 2분 13초, GPS 양호 0%였다. 1.3.5의 거리 보정 이후 현장 판정은 아직 실기기에서 다시 확인하지 않았다.
- 일반 고급 장비는 장비지원부 Lv.2와 제작 자원만으로 열린다. 잔향 늑대 토벌은 선행 조건이 아니다.
- 장비 목록의 `코어 장비` 표시는 현재 코어 제작 비용이 1개 이상이라는 뜻일 뿐, 별도의 성능 단계는 아니다.
- 월영·몽환 장비의 `requiredEvent`는 해당 사건의 중립이 아닌 기록을 요구한다. 실제 처치(`defeated`)는 요구하지 않는다.
- 공격력 총합 상한 ×3은 레벨 26의 기본 공격력만으로 도달한다. 이때부터 공격 장비의 수치가 실제 피해를 더 높이지 못한다. `eventBonus`는 유지·추격 피해 보너스인데 일부 장비 문구는 판정 보정처럼 읽힌다.

## 목표 성장 구조

| 구간 | 획득 목적 | 제안 조건 | 역할 |
| --- | --- | --- | --- |
| 기본 | 첫 활동과 장비 체험 | 낮은 자원 비용 | 슬롯별 효과를 익힌다 |
| 고급 | 첫 지부 확장 | 장비지원부 Lv.2와 일반 자원 | 첫 체감 성장; 첫 늑대 전에도 접근 가능 |
| 첫 코어 | 일반 제작으로 첫 확실한 성장 | 장비지원부와 코어 제작 자원. 잔향 늑대 토벌을 요구하지 않는다 | 고급 장비보다 확실한 기본 성능 상승 |
| 월영·몽환 | 이름 있는 적을 넘는 성장 | 월영대장·몽환경비관의 실제 토벌과 제작 조건 | 앞 단계보다 높은 성능에 별도의 전술 특성 |
| 거울결·철갑·귀환 | 장기 성장 | 각 단계의 고유 강적 실제 토벌, 등급, 제작 자원 | 이전 단계보다 높은 기본 성능과 고유 패시브 |

단계가 높아질수록 같은 역할의 장비는 명백히 강해진다. 같은 단계의 장비끼리는 공격·방어·조사 특성을 달리해 선택의 여지를 남긴다. 장비는 현실 목표 페이스를 낮추거나 높이지 않고 **게임 피해·생존·조사 결과**에만 영향을 준다.

## 확정한 장비 순서와 강적

무기는 `공명 단검 → 잔향의 창 → 월영 반월검 → 몽환의 장봉 → 거울결 세검 → 철갑 파쇄추 → 귀환의 검` 순서로 성장시킨다. `재갑 파쇄추`의 표시 이름은 `철갑 파쇄추`로 바꾸되 기존 장비 ID와 보유 기록은 유지한다. 귀환의 검이 이 성장선의 최상위 장비다.

| 성장선 | 해금에 연결할 강적 | 전투와 장비의 성격 |
| --- | --- | --- |
| 공명 단검 | 없음 | 고급 장비의 기준점 |
| 잔향의 창 | 없음 | 첫 코어 장비. 일반 제작 자원으로 획득 |
| 월영 반월검 | 다크엘프 월영대장 | 기민한 공격 |
| 몽환의 장봉 | 서큐버스 몽환경비관 | 공격과 생존을 함께 강화 |
| 거울결 세검 | 신규 보스 `거울마녀` | 환영을 파악하며 공격. 기존 `장막의 마녀`와 다른 개체·역할로 제작 |
| 철갑 파쇄추 | 신규 보스 `철갑 코뿔소` | 단단한 외피를 무너뜨리는 중장 전투 |
| 귀환의 검 | 신규 보스 `타락 헌터` | 이 성장선의 최종 전투 성취. 성인 여성 검사의 기사적 실루엣, 어두운 기운과 역안 표현 |

방어구·신발·유물도 각각 `고급 → 첫 코어 → 월영 → 몽환 → 거울결 → 철갑 → 귀환` 순으로 성장시킨다. 월영·몽환 장비의 현재 일반 몬스터 발견 조건은 해당 지휘관의 **실제 토벌** 조건과 정합되게 조정한다. 새 보스 셋은 해당 단계의 네 슬롯 장비 해금에 연결하되, 장비마다 역할은 유지한다. 현재처럼 후반 방어구·유물이 앞 단계보다 약해지는 역전은 없앤다.

높은 단계의 주 능력은 이전 단계보다 실제 게임 전투에서 우세해야 한다. 부가 효과는 빌드를 구분하되 낮은 공격 수치를 보상한다는 명목으로 주 성장감을 없애지 않는다. 레벨·장비를 합산한 공격 상한을 재설계하여 레벨 26 이후에도 새 장비가 유효하게 만든다. 수치와 제작 비용은 전체 성장·보스 체력 시뮬레이션으로 결정하며, 지금 숫자를 임의로 확정하지 않는다. 등급만 올려서 얻는 장비가 되지 않도록 이름 있는 적의 실제 토벌 기록을 요구한다. 최종 장비의 토벌 및 플레이어 등급 조건은 서로 순환하지 않게 설정한다.

새 강적은 각 단계의 이야기와 도감에서 자연스럽게 등장시키되, 미해금 이야기의 반전을 사전 설명이나 장비 UI에서 공개하지 않는다. 현실의 무리한 가속을 요구하지 않고, 선택 가속은 안전한 상황에서만 보너스로 작동한다.

## 필요한 구현 순서

1. 첫 늑대 토벌 경로를 검증한다. 탐험의 흔적 조사 뒤 현장 사냥으로 자연스럽게 안내하고, 아직 토벌하지 않은 사용자의 양호한 현장 사냥에는 첫 조우 기회를 확실히 제공한다. 걷기·나쁜 GPS를 전투로 위장하지 않으며, 조사로 전환된 이유를 활동 결과에 표시한다. 늑대 토벌은 첫 코어 장비 제작의 조건으로 사용하지 않는다.
2. 장비 조건에 `발견`과 `실제 토벌`을 별도로 표현한다. 기존 `requiredEvent`는 호환성을 유지하고, 새 토벌 조건은 저장된 사건의 `defeated == true`로 판단한다. 과거 실제 토벌 기록도 소급 인정한다.
3. 거울마녀·철갑 코뿔소·타락 헌터에 독자적인 강적·전술·삽화·도감·음성·제작 조건을 추가한다. 새 몬스터가 단순 열쇠로만 쓰이지 않도록 각 장비의 전투 역할과 연결한다. 이야기의 반전은 해금 전 UI에서 공개하지 않는다.
4. 공격·방어·조사 효과의 상한과 보스 체력을 함께 재조정한다. 레벨 상승과 장비 교체가 끝 단계까지 눈에 띄되 한 번의 사건으로 누적 보스를 지우지 않도록 실제 성장 경로를 시뮬레이션한다.
5. 보관함에는 성능 단계와 역할, 현재 장비 대비 실제 능력치 변화, 정확한 해금 조건을 보여준다. `코어 장비`라는 비용 기반 표시는 성능 등급과 구분한다. 피해 보너스를 `판정 보정`이라고 부르는 문구도 수정한다.

## 호환성과 검증

- 이미 구매·장착한 장비는 유지한다. 새 획득 조건을 추가해도 과거 보유 장비를 회수하거나 잠그지 않는다.
- 활동 중 저장된 전투 장비 스냅샷은 해당 활동이 끝날 때까지 유지한다.
- 첫 늑대 조우/토벌, 첫 코어 장비의 독립적인 제작, 과거 토벌 인정, 네 슬롯의 단계별 실제 성능 상승, 레벨 26 이후의 공격 성장, 신규 강적 토벌에 따른 획득 경로를 회귀 검사한다.
- 실기기에서 1.3.5의 거리·페이스·GPS·걷기/달리기 판정이 확인된 뒤, 게임 밸런스 패치를 별도 버전으로 묶어 테스트한다.
