# Hunter Run 실내 콘텐츠 확장 마스터 설계 패키지

기준일: 2026년 10월 7일. 콘텐츠: **지부 방어 작전 — 30회 캠페인**.

목표는 기존 iOS 앱에서 30회차까지 완주하는 정식 콘텐츠다. 1회차는 내부 검증 단위이며 최종 제공 범위를 뜻하지 않는다. 기존 실내 러닝의 신규 시작 입구를 교체한다. 이전 실내 운동 기록과 이미 획득한 성과는 보존한다. 사용자의 새 음성·일러스트 검수와 명시적인 OK 이후에만 IPA 제작·배포 단계로 진행한다.

이 문서는 기존 메인 스토리의 후반부 인물 정체와 결말을 다루지 않는다. 캠페인 전체 대사는 `Resources/defense-campaign.json`, 음성 제작 원문은 `Resources/defense-lines.json`에 분리한다.

## 1 현재 프로젝트 분석 요약

조사 기준 커밋은 `740b91e`다. 앱은 SwiftUI, iOS 17 이상이며, XcodeGen이 `App`, `Sources/HunterCore`, `Sources/OperatorLifeCore`, `Resources`를 앱 대상으로 수집한다. 패키지 테스트와 실제 iOS 앱 검증은 서로 구분한다.

| 영역 | 확인한 파일과 구조 | 확장 방법과 충돌 지점 |
|---|---|---|
| 활동 입구 | `App/ActivityPreparationView.swift`의 기존 `SetupView` | 새 `SetupView`가 야외 활동과 지부 방어 작전을 선택한다. 기존 준비 화면은 `OutdoorSetupView`로 유지한다. 시설 화면에 중복 입구를 추가하지 않는다. |
| 기존 실내 | `Sources/HunterCore/IndoorActivity.swift`, `IndoorDailyLimit.swift`, `App/IndoorCheckView.swift` | 이전 활동 해석·복구에 필요한 타입과 50% 보상 규칙은 호환성 코드로 남긴다. 신규 실내 러닝 시작을 막고 새 캠페인으로 안내한다. |
| 운동 진행 | `RunEngine.swift`, `RunDirector.swift`, `AppModel.swift` | GPS·페이스·실내 움직임 자격과 분리한 `DefenseClock`을 사용한다. 방어전을 `RunSession`으로 위장하지 않는다. |
| 앱 화면 계층 | `App/HunterRunApp.swift`의 5개 탭과 전체 화면 활동 | 기존 헌터 활동 탭 안에서 진입하며 운동만 전체 화면으로 표시한다. 새 전역 탭을 만들지 않는다. |
| 오퍼레이터 | `HomeView`, `App/OperatorLife/OperatorLifeRuntime.swift`, `OperatorPoseRenderer.swift` | 홈 생활 모션은 유지한다. 방어전 전체 화면이 열리면 홈 모션 가시성 조건에서 제외한다. |
| 현재 얼굴 원화 | `Resources/Assets.xcassets/OperatorLifeIdle.imageset/art.png` | 사용자가 보낸 1.6.3 홈 화면의 기준 얼굴. 이전 `Operator.imageset/operator.png`의 날카로운 인상을 새 보상 제작 기준으로 사용하지 않는다. |
| 오디오 | `App/AudioDirector.swift`, `Sources/HunterCore/AudioWorker.swift` | 기존 승인 음색을 기준으로 별도 `DefenseAudio` 묶음을 제작한다. 재생 중단·이어폰 분리·파일 오류는 작전을 멈춘다. |
| 저장 | `Models.swift`의 `Profile`/`SaveState`, `SaveRepository.swift` | optional `Profile.defense`를 추가한다. `save.json`/`backup.json`의 기존 원자적 저장을 사용해 회차·보상·보류 보고를 한 번에 반영한다. |
| UI 색상 | `Theme`, `Labyrinth`, `RelicShape`, `GameButtonStyle` | 잉크색 바탕, 청록색 선택·진행, 금색 기념 표현과 기존 모서리 장식을 재사용한다. |
| 시설 | `FacilityViews.swift`, `FacilityBase-*`, 부서별 1~3 이미지 | 방어전 대표 배경은 습격받은 지부 앞 도심과 지하 시설 진입로다. 실제 시설 레벨·업그레이드 조건과는 별개다. |

새 모듈의 외부 interface는 시작, 진행 저장, 완료 정산이다. 시간 진행·30회 순서·중복 지급·다음 회차 자격은 `DefenseCampaign` 안에 모은다. 화면은 상태를 표시하고 사용자 의도를 전달한다. `DefenseRuntime`은 실제 시간·오디오·저장 adapter를 연결한다. 기존 야외 엔진을 대규모로 재구성하지 않는다.

중요한 충돌 방지는 다음과 같다. 야외 활동과 캠페인은 동시에 시작하지 않는다. 중단된 캠페인이 있으면 이어하기 또는 이번 작전 종료를 선택한다. 캠페인 기록을 야외 거리·페이스 학습·토벌 수·메인 퀘스트·주간 야외 조사에 합산하지 않는다. 백업 가져오기와 초기화는 진행 중인 캠페인 종료 후에만 허용한다.

## 2 신규 콘텐츠 총괄 컨셉

**밖에서는 게이트를 찾아 나가고, 집에서는 돌아올 지부를 지킨다.**

지부 지하의 귀환 안내 장치와 오래된 반사 설비가 잘못 연결되어, 안전한 길을 알리던 신호가 격리 통로로 새어 나간다. 몬스터들이 그 신호를 따라 모여든다. 협회는 자동 격리벽으로 사람과 시설을 보호하고, 플레이어는 준비가 되었을 때 한 구역씩 정리한다. 초반에는 통로를 버티고, 중반에는 잘못된 신호 경로를 찾아 바꾸며, 후반에는 모두의 귀환을 확인하고 마지막 연결을 차단한다.

이야기의 보상은 평범한 저녁을 되찾는 일이다. 매번 세상을 구하는 규모로 과장하지 않고, 빵집에 들르기·침대에서 폰 보기·장을 보기 같은 일상이 조금씩 돌아온다. 오퍼레이터가 그 생활의 얼굴이 된다.

| 고정 원칙 | 제품 동작 |
|---|---|
| 회차는 이야기 진행도 | `완료 14 / 30`, `다음 작전 15 / 30`으로 표시한다. 날짜·연속 출석 배지를 쓰지 않는다. |
| 강도는 오늘의 선택 | 가볍게·기본·조금 더 도전 모두 같은 이야기와 주요 보상을 받는다. |
| 기다림에 벌점 없음 | 미접속 중 시설 손상, 자원 차감, 오퍼레이터 부상, 일일 실패를 만들지 않는다. |
| 안내를 따라 하는 운동 | 현재 버전은 자세·횟수·열량을 자동 인증하지 않는다. 기록은 안내 완료 시간이다. |
| 한 번의 완결 | 30회 후 사건이 끝나며 앨범·후일담·완주 기록을 계속 볼 수 있다. 자동으로 새 일일 방어전이 생기지 않는다. |

## 3 30회 캠페인 전체 설계

6막, 막당 5회다. 1·5·10·15·20·25·30회는 주요 장면과 생활 일러스트가 있다. 작전은 모두 서 있는 동작 중심이며, 주요 회차의 서사적 크기를 운동 강도와 동일시하지 않는다.

| 막 | 회차 | 사건 | 오퍼레이터의 변화 | 지부 표현 |
|---|---|---|---|---|
| 1 닫힌 문과 불빛 | 1~5 | 첫 침입 격리, 반복 경보와 안내등 연관 발견 | 책임감 있게 상황을 정리하며 작은 안도감을 보임 | 격리된 입구, 점검 표시, 한 구역 확보 |
| 2 길을 지키는 사람들 | 6~10 | 점등 분리와 중앙 통로 확보 | 혼자 서두르던 말투가 지원팀과 호흡을 맞추는 말투로 바뀜 | 세 구역으로 나뉜 점등과 안전 동선 |
| 3 잘못 전해진 초대 | 11~15 | 귀환 안내 신호의 반사 경로 발견과 수정 | 막는 것에서 이해하고 고치는 방향으로 자신감 회복 | 붉은 표시가 줄고 신호 방향표가 정리됨 |
| 4 돌아갈 길을 만들다 | 16~20 | 개체 유도와 지원팀 전원 복귀 | 장비보다 돌아오는 사람을 먼저 확인하는 다정함 | 비어 있는 우회 통로와 복귀 확인등 |
| 5 다시 켜지는 일상 | 21~25 | 남은 파동 정리, 생활 구역 전력 회복 | 편한 농담과 사적인 이야기가 자연스럽게 늘어남 | 휴게실·복도에 따뜻한 조명이 돌아옴 |
| 6 불을 끄고 나서는 밤 | 26~30 | 마지막 연결점 정비와 원격 차단 | 과장된 승리 선언 대신 함께 마쳤다는 담백한 감사 | 경보 해제, 안정화된 통로, 일상적인 야간 조명 |

개별 회차 제목·작전·변화·대사는 별첨 `campaign-content.md`에 30회 모두 싣는다. 앱 자료와 이 별첨은 같은 원본에서 만든다.

작전 유형의 역할은 다음과 같다.

| 작전 | 운동의 인상 | 대표 조합 | 사건의 성과 |
|---|---|---|---|
| 방어선 유지 | 반복되는 리듬과 가벼운 유산소 | 걷기, 스텝, 니업, 섀도복싱 | 구역 확보와 침입 통로 분리 |
| 시설 복구 | 느리고 제어된 움직임 | 스쿼트, 가벼운 팔 움직임, 걷기, 벽 푸시업, 뒤꿈치 | 전원·반사판·격리벽 정비 |
| 구조팀 지원 | 상체·하체·이동 교대 | 스텝, 섀도복싱, 스쿼트, 걷기, 뒤꿈치 | 팀과 자재의 통과·복귀 확인 |
| 봉인 안정화 | 부담이 적은 일정한 흐름 | 걷기, 뒤꿈치, 스텝, 낮은 니업 | 안정 상태 확인과 연결 전환 |

4·8·14·18·23·28회는 서사적으로도 조용한 점검이다. 시스템이 사용자의 강도 선택을 몰래 올리거나 내리지 않는다. 일상적인 회차도 단서·시설 상태·동료의 귀환 중 하나가 변하며, 같은 작전명이어도 이유와 끝의 상황은 달라진다.

## 4 운동 구조 설계

모든 강도에서 기준 길이는 **24분**이다. 기존 논의의 짧은 12~15분 코스는 이번 채택안에 포함하지 않는다. 운동 중 일시정지와 시작 안내 재생 시간은 24분 안내 시간에 합산하지 않아 실제 시계 시간은 더 길 수 있다.

| 안내 시간 | 구간 | 길이 | 역할 |
|---|---|---|---|
| 00:00~04:00 | 준비 | 4분 | 제자리 걷기, 작은 스텝, 지지한 뒤꿈치 들기, 걷기. 브리핑 동시 진행 |
| 04:00~09:00 | 교전 1 | 5분 | 60초 단위 5개 |
| 09:00~10:00 | 재정비 1 | 1분 | 쉬기·물 마시기·짧은 상황 보고 |
| 10:00~15:00 | 교전 2 | 5분 | 60초 단위 5개 |
| 15:00~16:00 | 재정비 2 | 1분 | 회복과 두 번째 상황 변화 |
| 16:00~21:00 | 교전 3 | 5분 | 60초 단위 5개 |
| 21:00~24:00 | 정리 | 3분 | 천천히 걷기·호흡 정리·귀환 후일담 |

각 교전 1분은 **회복·다음 동작 설명부터 시작하고 이후 동작**으로 이어진다. 벽으로 옮기거나 자세를 준비할 시간을 동작 시간에서 빼앗지 않는다.

| 강도 | 한 교전 분의 회복·준비 | 동작 | 15개 동작의 합계 | 보상 |
|---|---:|---:|---:|---|
| 가볍게 | 40초 | 20초 | 5분 | 동일 |
| 기본 | 30초 | 30초 | 7분 30초 | 동일 |
| 조금 더 도전 | 20초 | 40초 | 10분 | 동일 |

‘교전 15분’은 회복·안내를 포함한 게임 구간이다. 이를 전부 고강도 운동 시간이라고 표시하지 않는다. 준비와 정리 구간에도 가벼운 움직임이 포함되므로 실제 운동량·열량과 위 합계를 동일시하지 않는다.

| 동작 | 기본 안내 | 낮은 강도 대안 | 배치 기준 |
|---|---|---|---|
| 제자리 걷기 | 발을 가볍게 딛고 편한 리듬 유지 | 앉아서 발 움직이기 | 기본 연결 동작. 제자리 러닝은 선택적 대체이며 자동 판정하지 않음 |
| 좌우 스텝 | 발을 교차하지 않고 한 걸음씩 | 좁고 느린 스텝 | 주변 공간을 많이 요구하지 않음 |
| 무릎 번갈아 올리기 | 편한 높이까지만 | 낮게 들기 또는 앉아서 | 반복 점프 지시 없음 |
| 스쿼트 | 엉덩이를 뒤로 보내 천천히 앉았다 일어나기 | 튼튼한 의자 또는 걷기 | 반복 횟수 경쟁과 깊이 강요 없음 |
| 벽 푸시업 | 벽에 손을 대고 천천히 굽혔다 펴기 | 벽에 가까이 서기 또는 편한 팔 동작 | 시작 전 튼튼한 벽 확인. 바닥 푸시업 전환 없음 |
| 뒤꿈치 들기 | 벽을 가볍게 짚고 반동 없이 | 작은 범위로 | 균형 경쟁 없음 |
| 가벼운 섀도복싱 | 팔꿈치를 세게 잠그지 않고 번갈아 뻗기 | 앉아서 천천히 팔 뻗기 | 무게를 들거나 강한 펀치를 요구하지 않음 |

1회차는 걷기·스텝·뒤꿈치·섀도복싱 4종으로 진입한다. 이후 7종을 섞되 바닥에 눕고 일어나는 전환을 넣지 않는다. 한 운동이 불편하면 걷기로 바꿔도 회차와 일러스트에 불이익이 없다.

음성 규칙: 상황 → 동작명 → 시간. 예: “방어선을 유지해요. 이번에는 스쿼트예요. 30초 진행할게요. 편한 동작으로 바꿔도 괜찮아요.” 실제 동작 시작 때는 짧은 “지금부터 시작해요”로 구분한다. 긴 이야기와 새 동작 안내를 동시에 재생하지 않는다.

24분은 제품 구성안이며 보편적인 운동 처방이 아니다. NHS의 일반 준비 운동 안내는 최소 6분을 제안한다. 따라서 채택한 4분을 충분하다고 단정하지 않고, 출발 전 추가 준비와 일시정지를 안내한다. 실제 출시 검증에서 준비 부족이 관찰되면 회차 강도를 올리는 대신 준비 설계를 수정한다. 동작 안내의 근거는 [NHS 준비 운동](https://www.nhs.uk/live-well/exercise/how-to-warm-up-before-exercising/)과 [가벼운 근력 운동](https://www.nhs.uk/live-well/exercise/strength-exercises/)을 참고한다.

## 5 UI UX 설계

정보 구조는 `헌터 활동 → 야외 활동 / 지부 방어 작전`이다. 지부 방어 작전 안에서 다음 회차, 전체 진척도, 생활 앨범, 완료 기록에 접근한다. 기존 실내 러닝 선택은 제거한다. 협회 관리에는 동일 버튼을 또 배치하지 않는다.

| 화면 | 목적 | 핵심 구성 | 다음 이동 |
|---|---|---|---|
| 활동 선택 | 장소와 콘텐츠 선택 | 야외 활동 / 지부 방어 작전 2분할 선택 | 각각의 준비·캠페인 허브 |
| 캠페인 허브 | 현재 상태와 다음 행동 | 지부 배경, 완료 n/30, 다음 작전 또는 이어하기, 소개 펼치기 | 브리핑, 기록, 앨범 |
| 진행도 | 30회 전체 호흡 | 6줄 × 5개 노드, 완료·다음·잠김의 문자/기호 | 앞으로의 제목은 감춤 |
| 브리핑과 강도 | 한 손으로 준비 완료 | 제목, 짧은 사건, 강도 3개 세로 선택, 시간 구성, 동작 안내, 시작 | 운동 전체 화면 |
| 동작 안내 | 처음 하는 동작 이해 | 동작명, 간단한 방법, 쉬운 대안 | 브리핑 복귀 |
| 운동 진행 | 화면 없이 따라가기 | 현재 구간, 현재/다음 동작, 남은 초, 최근 음성 자막, 전체 안내 시간 | 일시정지 |
| 일시정지 | 사용자 통제와 복구 | 계속, 저장하고 나중에, 이번 작전 종료 | 계속 또는 허브 |
| 완료와 후일담 | 기록과 감정적 마무리 | 회차·강도·24분 안내 기록, 후일담, 최초 자원, 새 그림 | 그림 감상 또는 허브 |
| 생활 앨범 | 보상 다시 보기 | 7개 슬롯, 해금 회차, 획득 그림 | 전체 그림 |
| 그림 감상 | 원화 구도 유지 | scaledToFit 전체 그림, 제목과 짧은 글 | 30회만 비하인드 전환 |
| 완료 기록 | 개인 여정 확인 | `14회차 완료 · 기본`, 날짜, 안내 시간, 후일담 펼치기 | 허브 |
| 완주 기념 | 끝이 있는 성취감 | 30/30, 강도별 횟수, 총 안내 12시간, 앨범 안내 | 일상 앱으로 복귀 |

모의 화면 구조:

```text
헌터 활동
[ 야외 활동 | 지부 방어 작전 ]
┌ 습격받은 지부 앞 도심 배경 ─────────┐
│ 돌아올 곳을 지켜요                  │
│ 완료 4 / 30       격리 유지 중       │
└───────────────────────────────┘
[ 다음 작전 5 / 30 · 돌아오는 경보 → ]
1막  [✓1] [✓2] [✓3] [✓4] [→5]
2막  [🔒6] …                     6막까지
[ 지켜낸 일상 · 생활 앨범 ]
[ 완료한 작전 기록 ]
```

```text
지부 통신                     기본
작전 5 / 30 · 돌아오는 경보
격리벽 ① 확보   ② 대응 중   ③ 대기
교전 2                     03:42
스쿼트
22초
“방어선을 유지해요. 이번에는…”
안내 진행                 11:18 / 24:00
[           일시정지           ]
```

사용자 시나리오: 퇴근 후 헌터 활동에서 방어전을 고른다. 다음 회차를 확인하고 가볍게를 선택한다. 휴대폰을 세워두고 안내를 따른다. 초인종이 울리면 일시정지하고 나중에 이어간다. 완료 후 그림을 보고 닫는다. 며칠 뒤에도 밀린 경고 없이 다음 회차가 그대로 기다린다.

큰 글씨에서는 세로 스크롤을 허용하고 시작·정지 버튼을 축소하지 않는다. 잠금은 색만으로 구분하지 않는다. 정적인 배경과 작은 상태 변화로 충분히 읽히게 하며, Reduce Motion에서는 불필요한 전환을 끈다. 운동 중 화면 자동 잠금을 막고, 명시적으로 잠그거나 다른 앱으로 이동하면 진행을 멈춘다. 잠금 화면에서도 계속 운동하는 경험은 현재 구현 범위와 구분한다.

## 6 스토리와 대사 방향

주제는 ‘돌아올 곳을 지키는 사람들’이다. 기술적 원인으로 시작하지만 끝은 지부의 평범한 생활로 돌아온다. 오퍼레이터가 플레이어에게 호의를 보이기 위해 위험을 과장하거나 죄책감을 주지 않는다. 지원팀은 존재하지만 새 동료 육성·펫·관계 시스템으로 확장하지 않는다.

| 주요 회차 | 핵심 장면 | 감정선 | 생활 컷 연결 |
|---|---|---|---|
| 1 | 첫 통로 확보, 안내등을 따라 모이는 반응 | 긴장 속 친절한 안내 → 작은 안도 | 퇴근길 빵집 |
| 5 | 같은 경보가 반복됨, 점등과 반응의 연관 확인 | 걱정을 숨기기보다 다음 조치를 제시 | 업무 화면을 덮고 침대에서 폰 |
| 10 | 여러 문을 순서대로 지켜 중앙 통로 확보 | 동료와 맞춘 호흡에 자신감, 가벼운 자조 | 운동 따라 하다 지친 휴식 |
| 15 | 귀환 안내가 잘못 반사된 것이 원인임을 확인 | 이해하고 고칠 수 있다는 안도 | 매운맛 선택 실수 |
| 20 | 마지막 정비팀까지 전원 복귀 확인 | 성과 숫자보다 돌아온 사람을 챙김 | 편한 옷으로 장보기 |
| 25 | 예비 전원과 차단 순서 준비 | 내일을 일상적인 말로 이야기함 | 치약이 떨어진 아침 |
| 30 | 마지막 연결 차단과 경보 종료 | 짧고 분명한 감사, 편안한 해방감 | 특별한 외출과 몬스터 추격전 비하인드 |

1회차 실제 대사:

> 준비: “지부 아래 격리 통로에서 작은 침입이 있었어요. 바깥문은 닫혔고, 사람들은 모두 안전해요. 오늘은 안쪽 방어선부터 함께 확인해요.”
>
> 재정비 1: “첫 격리벽은 잘 버티고 있어요. 잠깐 숨을 고르세요. 다음 통로는 제가 확인할게요.”
>
> 재정비 2: “이상하네요. 문이 닫혔는데도 개체들이 안내등 쪽으로 모여요. 지금은 길만 지켜주세요.”
>
> 귀환: “첫 통로 확보 완료예요. 오늘은 퇴근길에 빵집에 들를 수 있겠네요. 종이봉투가 따뜻할 때 집에 가는 게 얼마 만인지 몰라요.”

5회차 톤: “반복 경보를 따로 격리했어요. 계속 보고 있던 화면은 이제 덮어도 되겠네요. 오늘 밤엔 침대에서 아무 생각 없이 웃긴 영상이나 볼래요.”

30회차 톤: “작전 종료예요. 서른 번, 함께 지켜냈네요. 지부 불은 이제 당직팀에 맡겨둘게요. 오늘은 저도 천천히 걸어서 저녁 먹으러 갈래요. 정말 수고하셨어요.”

최종 메인 그림에서는 특별한 외출을 담백하게 보여준다. 감상 화면의 비하인드 버튼을 누르면 같은 외출 복장의 오퍼레이터가 “으아앙!” 하고 몬스터에게 쫓기며 달아나는 코믹한 컷으로 전환한다. 당황한 표정과 휘날리는 머리·가디건, 뒤따르는 몬스터로 추격 상황을 명확히 전달한다. 본편 사건의 재발이나 실패를 뜻하는 추가 에피소드가 아닌 별도 보너스 개그 일러스트다. 식사·햄버거 장면으로 대체하지 않는다.

## 7 보상과 일러스트 구조

일러스트는 7개 이정표의 메인 컷과 마지막 비하인드 1컷으로 총 **8장**이다. 무작위 드롭·강도별 확률·추가 구매 없이 최초 회차 완료로 해금한다. 캐릭터가 카메라를 바라보는 수집용 포즈보다 자신의 행동에 집중하는 장면을 우선한다.

| 회차 | 자산 ID | 제목 | 장면 |
|---:|---|---|---|
| 1 | DefenseReward01 | 빵집에 들른 날 | 크림 카디건과 청록 상의, 빵집 앞에서 빵을 바라봄 |
| 5 | DefenseReward05 | 딱 하나만 더 | 편한 잠옷, 침대에 기대 휴대폰을 보며 웃음 |
| 10 | DefenseReward10 | 잠깐만 쉬고요 | 티셔츠와 긴 운동복, 매트 위에서 물병을 바라보며 휴식 |
| 15 | DefenseReward15 | 괜히 매운맛을 골랐지 | 잠옷 차림으로 매운 음식을 먹고 물컵을 찾음 |
| 20 | DefenseReward20 | 간식도 필요하니까 | 후드·안경·츄리닝, 장바구니를 들고 물건 비교 |
| 25 | DefenseReward25 | 어제 사 올걸 | 칫솔과 빈 치약, 어이없는 작은 표정 |
| 30 | DefenseReward30 | 모처럼의 외출 | 따뜻한 도시 조명 속 특별한 사복 외출 |
| 30 비하인드 | DefenseReward30Behind | 나 오늘 휴가인데! | 같은 외출 옷으로 몬스터에게 쫓기며 눈물콧물을 흘리는 억울한 울상. “으아앙!! 나 오늘 휴가인데!!” 느낌의 코믹 추격전 |

최소 성장 자원은 회차 최초 완료당 EXP 10·마정석 2다. 전체 합계 EXP 300·마정석 60으로 유한하다. 강도별 차이는 없으며 보상 수령 버튼을 별도로 여러 번 누르게 하지 않는다. 완료 기록·일러스트 해금·자원을 한 번의 저장에 반영한다. 코어, 보스 토벌, 메인 의뢰, 시설 업그레이드 자격은 지급하지 않는다.

완주 기록의 표기는 ‘완료한 안내 시간’으로 통일한다. 현 구성에서 30회 모두 완료하면 12시간이다. 사용자의 실제 운동 시간·심박·활동 열량이라는 이름으로 바꾸지 않는다.

## 8 비주얼과 아트 디렉션

얼굴 기준은 현재 홈의 `OperatorLifeIdle`이다. 부드러운 볼과 턱, 큰 회청색 눈동자, 작은 입, 청록빛이 아닌 푸른 하이라이트의 검은 층진 머리, 작은 금색 귀걸이를 유지한다. 성인 캐릭터의 비율을 지키며 어려 보이게 만들기 위해 머리를 과도하게 키우지 않는다. 얼굴을 날카로운 실사풍 미인으로 바꾸지 않는다.

| 요소 | 기준 |
|---|---|
| 렌더링 | 기존 원화와 같은 선명한 애니메이션풍 얼굴과 부드러운 회화적 재질. 피부·머리의 명암을 과도하게 사실화하지 않음 |
| 생활 컷 | 따뜻한 빛, 실내 생활 소품, 편한 옷의 주름, 시선이 머무르는 작은 대상 |
| 카메라 | 자연스러운 3/4 구도와 중간 거리. 동일 얼굴 정면 포즈 8장 반복 금지 |
| 복장 | 근무 외 카디건·잠옷·운동복·후드·외출복. 노골적인 수위와 신체 부위 강조 배제 |
| 배경 연결 | 대표 배경은 몬스터 습격으로 파손된 현대 도시·지부 앞 거리. 지하 격리 시설로 내려가는 진입로를 함께 배치해 기존 사건 장소와 연결 |
| 안전 영역 | 화면을 채우는 배경과 원화 감상을 분리. 그림 감상은 전체 비율 유지, 설명은 그림 밖 |
| 재사용 | 하나의 일관된 도심 방어선 배경에 상태 UI를 얹음. 견고하고 깨끗한 성채보다 파손 외벽·잔해·차량·임시 차단벽으로 습격의 흔적을 표현. 결석에 따라 피해가 늘어나는 시스템은 아님 |

UI 색상은 기존 정의를 따른다. 잉크 `#091117`, 청록 `#3BDBD4`, 보조 글자 `#A3B5C2`, 금색 `#C9B37D`, 양피지 `#F0EBDC`에 가까운 값이다. 경계 상태에만 차분한 호박색을 추가한다. 붉은색 전면 점멸·카메라 흔들기·눈부신 섬광을 상시 사용하지 않는다.

| 상태 | 표현 | 운동 중 제한 |
|---|---|---|
| 정상 | 차가운 석재와 따뜻한 생활 조명 | 정적 배경 |
| 경계 | 안내등 일부가 호박색, 격리 유지 문구 | 잦은 경보 점멸 없음 |
| 침입 대응 | 구간별 방어벽 상태와 통로 확보 표시 | 동작 지시보다 큰 피해 숫자·연타 UI 없음 |
| 귀환 | 청록 체크, 조명이 따뜻하게 돌아옴 | 긴 강제 연출 없음 |
| 최종 안정 | 경보 해제, 완주 표식, 생활 앨범 | 홈 원화·실제 시설 레벨 자동 교체 없음 |

시각 효과 우선순위는 구간 전환의 짧은 밝기 변화, 3개의 격리벽 완료 표시, 진행 막대다. 실제 조준·공격 버튼이나 사용자 움직임을 감지한 척하는 이펙트는 넣지 않는다. 향후 모션을 추가해도 오디오·타이머와 분리한다.

| 보상 생활 원화 | 7 | P0 | 새 제작, 현재 얼굴 기준, 메인 30회는 가장 높은 구성 완성도 |

| 도심 방어전 배경 | 1 | P0 | 습격으로 파손된 도로·건물, 임시 방어선과 지부 지하 진입로. 중앙은 운동 안내 가독성을 위해 비교적 비움 |
| 정상·경계·안정 오버레이 | 3 상태 | P0 | 코드 기반 색·상태 표시, 별도 배경 3장 불필요 |
| 운동 아이콘 | 7 | P0 | SF Symbols를 이용한 간결한 식별. 정확한 자세 시범 그림으로 오인시키지 않음 |
| 작전 아이콘 | 4 | P1 | 기존 심벌 언어 재사용 |
| 30회 기념 표식 | 1 | P0 | 벡터·글자 기반, 해금 후 표시 |
| 회차별 이야기 음성 | 120 | P0 | 회차마다 브리핑 1, 회복 2, 귀환 1 |
| 동작·강도 음성 | 21 | P0 | 7동작 × 3시간 설정 |
| 공통 안내 음성 | 10 | P0 | 시작·준비·정리·재개·완료 |
| 전용 배경음·효과음 | 초기 신규 0 | P2 | 새 소리를 성급하게 추가하지 않음. 음성 명료도 우선 |
| 동작 시범 연속 이미지 | 최대 14 | 추후 선택 | 각 동작 시작·끝 2장, 필요성 검증 뒤 운동 전문가 검토와 함께 제작 |

정식 초기 비트맵은 **9장**, 음성은 **151개**다. 앱 기존 원화·UI를 재사용하며 모든 동작에 새로운 캐릭터 애니메이션을 만드는 범위는 아니다. 음성 텍스트 수정은 해당 키만 다시 생성하고, 음색·발음 검수 여부는 기술적 파일 검사와 별도로 기록한다.

1회차 내부 검증에는 통로 배경 1장, 첫 생활 컷 1장, 4개 운동 심벌, 첫 회차 이야기 4개와 관련 공통 안내가 필요하다. 전체 제작 순서는 첫 생활 컷의 얼굴 일치 → 나머지 생활 컷 → 최종 메인·비하인드 쌍 → 인앱 크롭 확인이다.

## 10 PoC 구현 범위와 정식 제공 범위

사용자가 정식 콘텐츠 추가로 범위를 바꾸었으므로 **PoC만 제공하고 종료하지 않는다**. 다만 내부 검증은 1회차부터 진행한다.

| 단계 | 실제 결과물 | 통과 기준 |
|---|---|---|
| 내부 1회차 검증 | 24분 B안, 세 강도, 4동작, 브리핑·후일담·첫 그림 | 시간·동작 전환·음성량·준비 지루함·다음 회차 의향 확인 |
| 정식 콘텐츠 연결 | 30회·6막·4작전·7동작·7이정표·8보상 그림 | 잠금 순서와 각 회차 끝의 변화가 누락 없이 이어짐 |
| 운영 가능한 앱 | 저장·중단·재개·완료 보고·기록·앨범·기존 실내 입구 교체 | 강제 종료, 쓰기 실패, 중복 완료, 이전 저장 복구에 안전함 |
| 출시 검증 | 음성·그림 사용자 승인, iOS 빌드, UI 검증, 실기 운동 | 승인 전 IPA 제작 금지. 빌드 성공과 실제 운동 품질을 구분 |

시뮬레이터용 빠른 최종 회차 fixture는 DEBUG와 테스트 인자에서만 제공한다. 정식 사용자가 타이머를 건너뛰거나 바로 엔딩으로 가는 버튼은 없다.

## 12 리스크와 주의사항

| 리스크 | 대응과 검증 |
|---|---|
| 이전 원화를 사용해 얼굴이 달라짐 | 현재 `OperatorLifeIdle`을 명시하고 원본 비교 화면 제공. 잘못 만든 첫 베이커리 컷은 채택하지 않음 |
| TTS가 중간에 음색·발음을 바꿈 | 파일별 재생과 지적 ID 제공. 파형·길이·해시 통과를 음질 승인으로 간주하지 않음 |
| 복구하면서 앱 종료 시간을 운동으로 합산 | monotonic clock 기준, 저장에서 복원하면 항상 일시정지. 긴 실행 공백은 자동 일시정지 |
| 일시정지에도 음성이 끝난 뒤 재시작 | 음성 요청 취소와 재개 토큰 취소를 함께 적용하며 UI 시험으로 확인 |
| 안내끼리 겹침 | 한 재생기에서 단일 음성, 회복 시간에 다음 지시. 최단 준비 20초보다 안내가 충분히 짧은지 검증 |
| 완료 직후 저장 실패 | 현재 완료 세션 보존, 재저장 버튼. 기록·자원·다음 회차를 저장 성공 후 동시에 노출 |
| 중복 보상 | 회차 순서와 세션 ID로 중복 완료 무효화. 재감상은 정산을 부르지 않음 |
| 기존 실내 이용자의 기록 손실 | 신규 진입만 교체, legacy raw value와 저장 타입 유지, 진행 중 기존 활동은 복구·종료 가능 |
| 검사 없이 실제 운동했다고 표시 | ‘안내 완료 기록’으로 표기. 자세·열량 인증과 혼동시키지 않음 |
| 가벼운 강도에 불이익 | 동일 그림·이야기·자원. 기록의 사실 표기 외 등급 비교 없음 |
| 음성·자산 크기 증가 | WAV 목록과 전체 용량 검사, 불필요한 후보 이미지 미포함, 이미지 전체 일괄 디코드 금지 |
| 4분 준비가 부족함 | 추가 준비 안내, 일시정지, 실기 검증. 공개 운동 프로그램이라고 해서 모든 사용자에게 적합하다고 단정하지 않음 |
| 실기 없이 정식 품질이라고 단정 | 로직·콘텐츠 검사와 iOS 화면·24분 운동 검증 결과를 각각 보고 |
| 옛 앱으로 백업을 되돌림 | 구버전은 새 optional 필드를 다시 저장하며 제거할 수 있으므로 새 버전 백업 보관 안내 |

기술 참고: [Apple 오디오 중단 처리](https://developer.apple.com/documentation/avfaudio/handling-audio-interruptions). 현재 앱에서는 기존 `AudioDirector`의 interruption/route-change 처리를 재사용한다. HealthKit 권한이나 운동 자동 기록을 아직 추가하지 않는다.

## 13 바로 작업 가능한 우선순위

**지금 구현하는 최소 정식 범위:** 기존 실내 입구 교체, 30개 회차 데이터, 24분 운동 진행, 세 강도, 중단 저장과 재개, 완료 정산, 진척도, 기록, 생활 앨범, 최종 비하인드, 새 음성·그림 검수 화면. 현재 작업은 이 범위를 대상으로 한다.

**출시 전 필수:** 음성·일러스트 사용자 승인, 누락 자산 검사, iOS 컴파일과 작은/큰 화면 UI 테스트, 실제 iPhone에서 준비·전환·회복·중단을 포함한 24분 운동. 자동 테스트는 실제 발열·배터리·사용자의 운동 경험을 대신하지 않는다.

**결정을 미뤄도 되는 항목:** HealthKit와 Watch 연동, 정확한 kcal·체형별 성공선, 부정행위 정밀 판정, 잠금 화면 백그라운드 지속 운동, 전용 BGM, 움직이는 운동 시범, 추가 시즌, 보상 반복 파밍. 이 항목들을 이유로 기본 캠페인 UI에 미완성 메뉴를 노출하지 않는다.

검수 후의 변경은 파일 ID별로 처리한다. 얼굴 전체 기준이 달라지면 새 컷을 더 만들기 전에 기준 원화를 먼저 수정하고, 목소리 한 문장이 달라지면 그 문장만 재생성한다. 설치 파일에는 승인된 최종 파일만 포함한다.
