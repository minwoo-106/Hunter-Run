# 검증 상태와 출시 전 승인

기준일: 2026-10-07. 이 문서는 완료된 확인과 남은 확인을 구분한다.

## 확인한 것

- 전체 Swift 패키지 테스트 226개 통과, 실패 0개. WSL/Linux Swift 6.2에서 실행했다.
- 캠페인 전용 테스트 6개: 30회×3강도 시간 구성, 일시정지/재개/긴 공백, 30회 정산과 중복 지급 방지, 이전 세이브 읽기/쓰기, 잘못된 진행과 회차 건너뛰기 거부, 실제 legacy indoorTreadmill 기록을 가진 세이브의 캠페인 완료 후 기록 보존.
- 새 앱 화면과 연결 파일의 Swift 문법 검사. iOS SDK 타입 검사와 다르다.
- 승인 전 검토용 일러스트: 주요 회차 7장, 30회차 비하인드 1장, 전용 배경 1장. 잘못 사용한 예전 얼굴 기반 컷은 포함하지 않는다.
- 오디오 제작은 기존 승인된 합성 오퍼레이터 음성을 참고한 로컬 합성이다. 새 발화의 음색·억양이 모두 같다고 자동 판정하지 않는다.
- 전체 콘텐츠 검사 통과: 신규 음성 151개, 이미지 9개와 기존 앱 자산 연결 확인. 신규 음성 38.7 MiB, 그림 20.9 MiB. 운동 안내 최장 8.23초로 최단 준비 20초보다 짧다.
- 오프라인 검토 페이지를 Chrome에서 확인했다. 151개 음성 필터·검색, 이미지 확대, 로컬 음성 재생, 이미지 로딩, 문서 링크, 390px 화면의 가로 넘침 없음, JavaScript 오류 없음. 이것은 검토 페이지 검증이며 iOS 앱 UI 검증은 아니다.
- 음성 검토 체크 기능 확인: 좋아요/목소리 다름/억양·발음 수정, 문장별 메모, 새로고침 후 보존, 수정 대상 필터, 기준 목소리 재생, 복사 목록과 JSON 다운로드. 별도 테스트 브라우저에서 확인해 사용자 체크에 영향을 주지 않았다. 음성 파일이 교체되면 이전 파일의 승인 표시를 재사용하지 않는다.

## 음성 확인 방법

검토 페이지 상단의 ‘음성’을 누른다. 기준 목소리와 각 새 음성을 듣고 문장 아래 상태를 선택한다. 달라지는 시점이나 문구는 메모에 적는다. 회차별 또는 운동·공통 안내별로 나눠 들을 수 있다. ‘전체 151개’와 ‘수정할 음성만’을 함께 선택하면 회차와 관계없이 수정 대상을 모아본다.

체크 내용은 해당 브라우저에 보관되며 다른 PC/브라우저나 이 채팅으로 자동 전송되지 않는다. 검토를 마치면 ‘체크 목록 다운로드’로 받은 `HunterRun-voice-review.json`을 채팅에 첨부하거나 ‘복사할 목록 보기’의 내용을 전달한다. 브라우저가 로컬 저장을 막으면 화면에서 알리며 다운로드/복사로 보관할 수 있다. 단순 재생을 승인으로 간주하지 않는다.

## 검사 도구

- `scripts/validate.py`: 기존 콘텐츠와 신규 캠페인 전체 자산 검증.
- `scripts/validate-defense.py`: 30개 회차, 대사와 음성 151개 대응, WAV PCM 규격/길이/피크/해시, 이미지 9개 연결. 가장 짧은 동작 준비 20초 안에 안내가 끝나도록 운동 지시는 18초 미만을 요구한다.
- `scripts/build-defense-review.py`: 원본 얼굴 비교, 일러스트 확대, 대사 번호별 음성 재생, 전체 설계 문서를 포함한 오프라인 ZIP. IPA를 만들지 않는다.
- `scripts/check-ios-layout.sh defense`: 승인 후 Mac에서 실행할 작은/큰 iPhone UI 검사 경로. 실내 진입 교체, 3강도, 일시정지/배경 복귀, 이어하기, 최종 회차 보고와 별도 비하인드 버튼 검사를 준비했다.

## 아직 확인하지 않은 것

- I30-B 히든 일러스트의 눈물콧물 추격전 버전은 2026-10-07 사용자가 채택했다. 나머지 음성·일러스트 및 이날 교체한 B01 도심 배경은 전체 출시 승인과 별개로 검토 중이다.
- Xcode/iOS SDK로 앱 컴파일과 위 UI 테스트 실행. Windows/WSL 문법 검사만으로 통과했다고 말하지 않는다.
- 실제 iPhone의 전체 24분 운동, 화면 잠금·전화·이어폰 분리 후 복귀, 발열·메모리·배터리, 작은 화면/큰 글씨 사용감.
- 신체 동작 검증. 현재는 안내 완료 시간만 저장하며 실제 운동량·칼로리·자세를 인증하지 않는다.

## 이번 단계에서 실행하지 않는 것

사용자 승인 전 IPA 생성, 배포 워크플로 실행, 새 릴리스 게시를 하지 않는다. 검토 파일은 앱 설치 파일이 아니다. 현재 앱 버전 번호도 출시 완료로 올리지 않는다.

## 승인 후 순서

1. 승인된 이미지·음성을 파일별로 확정한다. 지적한 파일만 수정하고 다시 확인한다.
2. iOS 컴파일 및 큰/작은 화면 UI 검사를 실행한다. 실패하면 수정 후 관련 검사를 다시 한다.
3. 설치용 IPA를 만들어 실제 iPhone 검증으로 넘긴다.
4. 실제 24분 수행 결과를 반영하고 정식 공개 품질을 확인한다.

운동 안내 검수는 표준 강도 1회차를 우선한다. 준비 4분이 충분한지, 회복에서 동작으로의 전환을 눈으로 보지 않고 알 수 있는지, 대사가 과하지 않은지, 두 번째 작전을 하고 싶어지는지 확인한다.
