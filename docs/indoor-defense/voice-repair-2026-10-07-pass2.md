# 방어전 음성 검토 2차 수정

사용자 체크: `reviews/2026-10-07-voice-review-pass2.json`.
151개 중 141개 승인, 목소리 2개·기타 전달 8개 수정 요청. 직전 47개 후보 중 37개 승인이다. 실제 들은 후보의 해시가 모두 일치함을 확인했다.

| 번호 | 처리 |
|---|---|
| V018, V106 | 승인된 첫 문장 유지. 두 번째 문장만 같은 첫 문장과 기존 오퍼레이터 기준 음성에 연결해 재합성 |
| V116 | 첫째·셋째 문장 유지. ‘특별히 더 무리할 건 없어요.’만 교체 |
| V032, V036, V059 | 발화 종료 후 무음 뒤에 붙은 약 40ms 잡음 제거. 대사는 재합성하지 않음 |
| V060 | 첫 문장 유지. 매운맛을 뒤늦게 후회하는 말끝 여운과 쉼을 시도 |
| V080 | 앞 두 문장 유지. 장난스러운 의문형 말끝으로 변경 |
| V100 | ‘거창한 건 없고, 치약 하나 사 오려고요.’로 둘째 문장만 변경 |
| V120 | 완료의 안도·밝은 퇴근 인사를 목표로 문장을 묶어 억양 재생성 |

감정 표현은 기존 합성 목소리와 문장 구두점·쉼·묶음을 통한 후보다. 원하는 연기가 구현됐다는 자동 판정은 하지 않는다. 특히 V060/V080/V120은 사용자의 청감 재확인이 필요하다.

## 보존과 검증

- 작업 폴더: `../../work/defense-voice-repair-20261007-pass2`.
- `baseline/`은 사용자가 실제 검토한 151개 전체다. 직전 수정본 중 승인된 37개가 원래 불합격 음성으로 되돌아가는 것을 방지한다.
- `before/` 10개와 `after/` 10개, 판정 원본과 `repairs.json`을 보관한다.
- 앱 리소스와 대사 데이터는 그대로 유지한다. V100의 단어 수정 및 V080의 물음표는 검토 페이지에만 오버레이하고, 승인 뒤 실제 콘텐츠 생성 원본·catalog·lines·voice manifest에 함께 반영해야 한다.
- 페이지와 ZIP에 141개 승인 파일이 바이트 단위로 동일하게 유지됨을 확인했다. 후보 10개와 최신 비교 원본 10개, 판정·메모·변경 문구·해시·PCM·재생 길이·피크·ZIP 무결성 검증 통과.
- 유지하기로 한 문장 전체와 잡음 제거 전 발화 구간이 PCM 단위로 보존된 것도 확인했다.
- `scripts/test-defense-review-state.cjs` 통과. 실제 브라우저 배치와 감정 표현을 직접 검수했다고 주장하지 않는다.

재생성: `scripts/repair-defense-review-pass2.py`.
패키지 생성: `scripts/build-defense-review.py --repair-dir ../../work/defense-voice-repair-20261007-pass2`.
