# 방어전 음성 검토 1차 수정

사용자가 전달한 151개 체크의 원본은 `reviews/2026-10-07-voice-review.json`에 보관한다.

| 판정 | 개수 | 처리 |
|---|---:|---|
| 좋아요 | 104 | 원본 바이트와 승인 유지 |
| 목소리 다름 | 35 | 메모에 따라 문장 수정 또는 승인 음성 재사용 |
| 억양·발음 | 12 | 끝 잡음, 특정 문장, 전체 억양을 구분 |

## 수정 범위

- 전체 문장별 재합성 32개: 한 파일을 길게 생성하는 대신 각 문장을 같은 기존 합성 오퍼레이터 기준 음성에 연결한다. 매 문장의 준비 공백을 정리하고 짧은 문장 간 간격으로 합친다.
- 앞부분 보존·후반 교체 7개: V007, V015, V017, V022, V084, V097, V120. 사용자가 적은 초를 그대로 자르지 않고, 가까운 실제 문장 사이 무음에서 나눈다.
- 승인 음성의 같은 문장으로 조합 6개: V125, V126, V131, V133, V136, V141. 이미 승인된 동작명·20/30/40초 안내를 재사용한다.
- 말끝 잡음만 제거 2개: V070, V087. 발화가 끝난 뒤의 무음과 짧은 잡음만 제거하고 마지막 10ms를 페이드 처리한다. 앞부분을 재합성하지 않는다.

V088과 V089는 사용자가 표시한 시점이 첫 문장 끝과 겹치므로 음절을 잘라 이어 붙이지 않고 문장 전체를 다시 만든다. 대사 문구, 운동 시간, 스토리 내용은 변경하지 않는다.

## 파일과 검토 상태

수정본은 저장소 위 작업 폴더 `../../work/defense-voice-repair-20261007/`에 둔다.

- `before/`: 사용자가 검토했던 수정 대상 원본 47개
- `after/`: 새 후보 47개
- `segments/`: 재합성한 문장별 중간 음성
- `review-original.json`: 전달받은 판정 원본
- `repairs.json`: 각 파일의 전후 해시, 수정 방식, 원래 메모와 문장 이력

아직 앱 리소스를 교체하지 않는다. 모든 앱 음성 151개는 원래 해시를 유지한다. 검토 페이지 생성 시에만 `--repair-dir ../../work/defense-voice-repair-20261007`을 지정해 후보로 대체한다. 수정 전 음성도 함께 복사한다.

새 페이지는 기본적으로 수정본 47개만 표시한다. 기존 체크가 없는 브라우저에도 사용자가 전달한 판정을 기본값으로 보여주지만, 더 최근에 작성한 로컬 판정은 덮어쓰지 않는다. 104개 승인은 그대로이고, 해시가 바뀐 47개는 다시 판정해야 한다. 메모와 이전 판정 이력을 보존한다.

## 재현과 검증

1. Qwen 환경에서 `scripts/repair-defense-review.py`에 원본 체크, 출력 폴더, 로컬 모델, 기존 `voice-consistency-reference/run_start.wav`와 그 manifest를 전달한다. 원본 해시 불일치 시 진행하지 않는다. 이미 만든 문장은 캐시에서 이어간다.
2. `python scripts/validate-defense-repairs.py --repair-dir ../../work/defense-voice-repair-20261007`로 전체 후보, 승인 음성 불변, 대사 문장 누락, PCM·길이·피크·해시, 부분 보존을 검사한다.
3. `node scripts/test-defense-review-state.cjs`로 판정 보존·수정본 필터·원본 비교 연결을 검사한다.
4. `python scripts/build-defense-review.py --repair-dir ../../work/defense-voice-repair-20261007`로 기존 검토 페이지와 ZIP을 갱신한다.

자동 화자 유사도는 낮은 유사도의 재시도 여부를 정하는 보조 지표다. 음색·억양·발음의 최종 품질이나 사용자 승인을 의미하지 않는다. 실제 청감은 사용자 재검토 전이며, 그 전에는 IPA나 릴리스를 만들지 않는다. 승인 뒤에는 후보의 정확한 해시를 확인해 앱 리소스 및 manifest에 반영한다.

## 완료한 확인

- 기존 `HunterRun-defense-review/index.html`과 ZIP 갱신. 47개 수정본·47개 비교 원본·104개 승인 파일의 실제 해시와 페이지 데이터가 일치한다. ZIP 무결성과 인라인 JavaScript 구문도 확인했다.
