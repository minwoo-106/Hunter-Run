# 오퍼레이터와의 대화 — 기능·콘텐츠 설계

2026-09-13 / 차기 확장 설계 / 앱 미적용

본편의 반전은 이 문서에 적지 않는다. 실제 분기 대본은 [관계 대본](operator-relationship-scenes.md), 본편 전체는 [작가용 원고 · 스포일러](story-v1-writers-bible.md)에 분리한다.

## 홈에서의 사용 흐름

오퍼레이터를 터치하면 표정이 바뀌고 짧게 반응한다. 하단에 대화창이 열리며 지금 고를 수 있는 화제가 2~4개 나온다. 예: '오늘 의뢰 이야기', '잠깐 쉬어도 돼요?', '어떤 음료 좋아해요?'와 항상 보이는 '다음에 이야기해요'.

화제를 누르면 오퍼레이터가 말하고, 플레이어의 대사 선택지 2~3개가 나타난다. 선택에 따라 답과 표정이 달라지며, 대화가 끝나면 처음 본 이야기의 호감도가 반영된다. 특별한 대화 이후에는 새 화제·개인 에피소드·호칭·인사 변화가 열린다. 지나간 대화는 별도 추억 목록에서 다시 읽는다.

처음에는 이름·역할·임무 같은 화제가 중심이다. 이후 취향·관찰·장난, 자신의 고민, 둘만의 약속으로 넓어진다. 진전이 생기면 '새로운 이야기가 있어요'라는 작은 표시만 보여준다. 앱을 켤 때마다 전체 대화를 강제로 시작하지 않는다.

하단 탭은 사용자가 정한 홈 / 헌터 / 크게 표시한 헌터 활동 / 협회 관리 / 도감 구성을 유지한다. 설정 톱니는 우측 상단에 둔다. 새 대화는 홈의 캐릭터 터치로 열어 탭을 더 늘리지 않는다. '스토리' 버튼은 본편·잠김 개수·재열람을 담당한다. 관계 대화에는 돌아가기와 추억 보기를 둔다.

캐릭터 터치 영역이 설정·스토리·하단 탭을 가리지 않아야 한다. VoiceOver에는 '오퍼레이터와 대화'라는 버튼으로 노출한다. 조작 영역은 최소 44pt를 목표로 하고 큰 글씨에서는 선택지와 대화창을 스크롤할 수 있게 한다.

## 다섯 관계 단계

표의 점수는 도달 가능성을 확인하기 위한 초안이다. 플레이 화면에는 숫자 정답을 고르는 시험처럼 보이지 않도록 단계명·진행 막대·새 화제를 중심으로 표시한다.

| 단계 | 호감도 / 최소 본편 진척 | 말투·태도 | 새 대화의 종류 |
| --- | --- | --- | --- |
| 1. 배정된 파트너 | 0 / 등록 | 정중하고 짧은 해요체, 먼저 사생활을 묻지 않음 | 근무·장비·첫 활동 |
| 2. 익숙한 동료 | 8 / M03 해금 | 취향을 기억하고 가벼운 농담, 편한 미소 | 음료·낙서·서로의 습관 |
| 3. 믿고 기대는 사이 | 20 / M06 해금 | 의견을 부탁하고 작은 걱정을 먼저 말함 | 컨디션·개인 목표·기억하는 말 |
| 4. 특별한 파트너 | 36 / M10 해금 | 임무 밖에서 대화하고 싶다는 마음을 표현 | 비밀·서로에게 바라는 점·약속 |
| 5. 서로의 편 | 52 / M14 해금 | 편안한 장난, 개인적인 호칭, 미래 이야기 | 관계의 방향 선택·본편 후일담 |

호감도 조건이 먼저 채워져도 본편 조건 전에는 다음 단계가 열리지 않는다. 이때 모은 호감도는 사라지지 않는다. 본편 진행만으로 모든 개인 대화가 즉시 열리지는 않지만, 본편 결말 자체에 호감도 조건은 없다.

## 호감도와 선택의 역할

처음 완료한 관계 에피소드 12개는 각각 호감도 4를 준다. 공통 본편 이정표 M03/M06/M10/M13/M16은 각각 4를 주어 최대 68을 구성한다. 모든 기본 선택으로 최고 단계에 도달할 수 있다. 친절한 플레이어만 정답이고 농담하는 플레이어는 오답인 구조는 쓰지 않는다.

선택의 차이는 '답변만 바뀌고 끝'으로 만들지 않는다. 선택마다 기억 값을 남겨 이후의 대사·호칭·선택지를 바꾼다. 예를 들어 함께 조용히 쉬기를 골랐다면 다음번에는 '오늘도 잠깐 조용히 있을까요?'가, 먼저 농담을 건넸다면 두 사람만 아는 장난을 이어가는 선택지가 나온다. 관계의 깊이는 호감도로, 관계의 색깔은 선택 기록으로 만든다.

새 화제를 시작했다가 '다음에 이야기해요'로 나가면 보상은 없고 진행 지점만 저장한다. 끝까지 읽거나 선택까지 완료한 뒤 종료하면 한 번만 보상한다. 재열람·반복 터치·같은 일상 인사에는 호감도를 다시 주지 않는다. 전투 성능 보너스는 넣지 않고 대화·표정·기록·작은 장식이 보상이 된다.

호감도는 접속하지 않았다는 이유로 줄지 않는다. 매일 출석, 실제 시간대, 연속 운동일, 고강도 운동을 관계 조건으로 쓰지 않는다. 오전·저녁 인사 변화는 가능하지만 못 본 인사가 관계를 막지 않는다.

친밀한 선택을 원하지 않는 이용자는 동료로서 깊은 신뢰를 쌓을 수 있다. 마지막 약속에서 더 개인적인 호감 표현을 고르면 살짝 설레는 후일담이 열린다. 동료 선택도 같은 호감도·콘텐츠 분량을 제공한다. 관계 방향은 이후 별도 대화로 바꿀 수 있고, 추억 재생이 현재 선택을 덮어쓰지는 않는다.

## 콘텐츠와 분기 설계

- 본편 16화: 임무와 세계의 사건. 주요 인물의 과거와 사건 해결은 여기서 이해할 수 있다.
- 관계 12화: 한 장면 안에서 선택·응답·작은 후속 반응까지 완결. 본편 사건의 감정적 여백을 채운다.
- 일상 화제 6종: 오늘의 의뢰, 잠깐 쉬기, 음료, 책상의 물건, 오늘의 기분, 다음 약속. 단계·주요 선택에 따라 변형한다.
- 매번 새 음성을 만들지 않고 저작된 텍스트 분기로 동작한다. 인터넷·실시간 AI·추가 계정 없이 사용할 수 있는 범위다. 자유 입력 챗봇은 이번 범위에 포함하지 않는다.
- 선택지의 전체 조합마다 별도 장편을 만들지 않는다. 각 장면은 2~3개의 짧은 응답으로 갈라졌다가 합류하고, 중요한 취향·약속만 뒤에서 다시 사용한다.

### 반복 인사의 차이 예시

| 상황 | 낮은 호감도 | 높은 호감도 |
| --- | --- | --- |
| 홈에서 터치 | 부르셨어요? 필요한 자료가 있으면 말씀해 주세요. | 마침 잘 오셨어요. 오늘은 제가 먼저 물어볼 게 있어요. |
| 잠깐 쉬기 | 괜찮아요. 다음 의뢰는 준비되시면 확인해요. | 좋아요. 저도 잠깐 쉬려고 했어요. 오늘은 보고서 이야기 빼고요. |
| 활동 후 | 활동 기록을 저장했어요. 함께 확인해볼까요? | 잘 다녀오셨어요. 아까 그 장면, 저도 이야기하고 싶었어요. |
| 대화 마치기 | 네. 다음에 이어서 이야기해요. | 좋아요. 아까 하던 이야기는 제가 기억해둘게요. |

높은 관계에서도 활동 중 위험·페이스·토벌 정보는 짧고 정확하게 전달한다. 달리는 중 개인사·선택 대화창이 열리거나 음성 안내가 밀리면 안 된다. 활동 준비는 BGM 유지, 실제 활동 시작 시 기존 정책대로 BGM을 멈춘다.

## 표정과 움직임

캐릭터는 현재 승인한 큰 눈·귀여운 성인 외형을 유지한다. 기본 / 미소 / 장난 / 생각 / 걱정 / 안도 6종을 목표로 하되 동일 얼굴을 기준으로 제작한다. 친밀함을 표현할 때 과한 유아적 제스처·목소리 변화 대신 눈웃음·시선·짧은 머뭇거림을 쓴다.

터치 시 작은 시선 반응, 대화 시작 때 미소, 고민 대사에 시선 내림을 사용한다. 기본 호흡·불규칙 깜빡임과 대화 표정이 서로 덮어쓰지 않게 한다. 빠르게 여러 번 터치해도 애니메이션·음성이 겹치지 않는다. 화면을 떠나면 모션을 멈추고 동작 줄이기에서는 정적인 표정을 쓴다.

선택지를 누를 때마다 같은 호감도 효과음을 반복하지 않는다. 장면 종료 시 한 번만 작은 표시로 알려준다. 호감도가 높아져도 전투용 승인 음색은 일관되게 유지한다.

## 저장과 구현 계약

기존 Profile에 버전이 있는 선택적 관계 상태를 추가한다. 초안 필드: operatorName, affinity, completedBondSceneIDs, settledMilestoneIDs, dialogueMemory, relationshipPreference, activeDialogue, unlockedStoryIDs. 실제 타입·API 이름은 구현에서 확정한다.

activeDialogue는 sceneID/nodeID/선택 내역을 함께 보관한다. 재열람은 별도 읽기 모드로 실행하며 현재 기억·점수·해금 상태를 바꾸지 않는다. 새 장면 완료, 기억 갱신, 호감도 증가를 같은 저장 단위로 처리한다. '미리 보상 지급 → 저장 실패 → 다시 지급' 순서를 만들지 않는다.

dialogueMemory에는 음료·휴식 선호, 낙서 반응, 약속·호칭 선택처럼 재사용하는 값만 넣는다. 모든 사소한 선택을 숫자로 합쳐 성격을 추측하지 않는다. 이름을 바꿔도 완료 장면과 기억은 유지한다. 자유 입력 이름은 길이·공백·줄바꿈을 검증하고 '이에요/예요', '은/는', '이/가' 등을 렌더링에서 처리한다.

기존 이용자에게는 이름 설정을 추가하되 활동·등급·장비를 초기화하지 않는다. 기존 6편은 '이전 통신 기록'으로 보존하고 새 본편을 읽었다고 자동 표시하지 않는다. 기존 실제 업적으로 확인 가능한 공통 이정표만 한 번 정산한다. 저장에 증거가 없는 토벌 수나 선택 기억을 꾸며서 채우지 않는다. 새 전용 심사·복구 임무만 별도 진행하며 기존 상위 등급을 강등하지 않는다.

해금된 콘텐츠는 자원 소비·앱 재실행·날짜 변경으로 다시 잠기지 않는다. 모의 활동은 실제 관계 이정표를 충족하지 않는다. 모의 대화 검수에는 임시 상태를 사용한다. 정식 활동 진행/복구 중에는 기존 growthLocked 정책과 충돌하지 않도록 홈 선택 대화 진입을 제한한다.

## 도달성 검토용 최저 경로

관계 점수만을 위한 실제 운동 횟수는 추가하지 않는다. 아래는 본편 조건과 대화를 순서대로 완료했을 때의 경로다.

| 구간 | 이 구간의 관계 대화 | 누적 최소 점수 | 다음 단계 |
| --- | --- | --- | --- |
| 등록~M03 | R01, R02 + M03 | 12 | 2단계 가능 |
| M03~M06 | R03, R04, R05 + M06 | 28 | 3단계 가능 |
| M06~M10 | R06, R07, R08 + M10 | 44 | 4단계 가능 |
| M10~M14 | R09, R10 + M13 | 56 | M14 해금 시 5단계 가능 |
| M14~엔딩 | R11, R12 + M16 | 68 | 후일담 완료 |

해금 조건은 본편 읽음이 아니라 해당 장의 게임 진행 사실을 기준으로 한다. 다만 스포일러가 있는 개인 대화를 열기 전에는 해당 본편을 먼저 볼 수 있게 안내하며 '나중에'로 취소 가능하다. 원치 않으면 개인 대화도 보류할 수 있다.

## 구현 완료를 판단할 검사

1. 신규 등록부터 최소 경로의 점수만으로 12개 장면이 모두 열린다. 어느 장면도 자신의 완료 보상을 해금 조건으로 요구하지 않는다.
2. 모든 선택지에 응답이 있고 닫기·복귀가 가능하다. 선택 도중 종료 후 같은 노드로 돌아온다.
3. 장면 재생·앱 재시작·다중 탭으로 점수와 보상을 두 번 받지 않는다.
4. 본편만 진행해도 사건을 이해하고 엔딩을 볼 수 있다. 친밀·동료 방향 모두 최종 관계 장면에 도달한다.
5. 이전 이름·호칭이 화면에 고정되지 않는다. 이전 선택을 다시 언급할 때 없는 기억을 가정하지 않는다.
6. 사용자가 큰 글씨·작은 화면·동작 줄이기를 사용해도 선택지와 닫기가 가려지지 않는다.
7. 실제 활동 중 홈 대화가 전투 안내·BGM·센서·화면 유지 정책을 바꾸지 않는다.

이 문서는 기능·대사 설계 완료를 뜻한다. 앱 구현, 새 표정 리소스, 신규 녹음, 빌드와 iPhone 확인은 별도 작업이다.
