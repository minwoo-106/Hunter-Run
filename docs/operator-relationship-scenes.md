# 오퍼레이터 관계 대본 12편

2026-09-13 / 저작 원고 / **후반 본편 맥락·관계 후일담 포함** / 앱 미적용

화자 'O'는 사용자가 이름을 정한 성인 오퍼레이터다. 모든 선택은 선택한 응답 뒤 '합류'로 진행한다. 첫 장면 완료당 호감도 +4, 재열람 +0. 각 선택의 기억 값은 선택 완료 시 보관하며 장면의 실제 완료와 함께 확정한다. 닫기는 언제든 가능하고 보상 없이 해당 노드를 저장한다.

## R01 · 책상 반쪽

조건: 관계 1단계, M01 해금. 표정: 정중 → 작은 미소.

O: 이쪽은 헌터님 보고서를 놓을 자리예요. 아직 비어 있지만 곧 필요해질 거예요.

O: 원하시면 작은 물건도 놓아도 돼요. 책상 절반을 전부 서류로 채울 필요는 없으니까요.

선택:
- R01-A 「그럼 컵 놓을 자리부터요.」 → O: 좋은 생각이에요. 서류에는 최대한 안 쏟는 방향으로요. 저도 조심할게요. / memory.desk = cup
- R01-B 「보고서가 쌓이면 좀 뿌듯하겠네요.」 → O: 저도요. 첫 장은 맨 위에 남겨둘까요? 나중에 얼마나 달라졌는지 보게요. / memory.desk = firstReport

합류:

O: 이제 제 책상이 아니라 저희 책상이네요. 필요한 게 있으면 이야기해 주세요.

후속: R12 책상 물건 회수. 최고 단계 미도달 시에도 기본 홈에서 컵/첫 보고서 문구를 사용할 수 있다.

## R02 · 쉬는 시간의 규칙

## R07 · 말하지 않아도 되는 날

합류:

  - R12-B 「다음에도 이런 시간 같이 보내요.」 → O: 네. 저도 그러고 싶었어요. 다음 약속은 제가 먼저 꺼내도 되죠?
- partnership인 경우:
  - R12-C 「첫 장, 같이 읽어봐요.」 → O: 좋아요. 우리 둘 다 처음이던 이야기부터요. 솔직하게 적었으니까 너무 놀리시면 안 돼요.
  - R12-D 「우리 꽤 좋은 팀이네요.」 → O: 네. 이건 평가관님 서명이 없어도 제가 확실히 말할 수 있어요.
- undecided인 경우:
  - R12-E 「일단 오늘 같이 쉬어요.」 → O: 좋아요. 오늘은 오늘만 정해요. 그것도 충분히 좋은 약속이에요.
  - R12-F 「다음 이야기까지 여기 있어 주세요.」 → O: 그럴게요. 아직 같이 써볼 보고서도, 하고 싶은 이야기도 많아요.

합류:

O: 이제 처음으로 연결됐을 때보다 덜 어색하네요.

O: …아니에요. 조금은 여전히 떨려요. 반가워서 그런가 봐요.

## 일상 화제의 실제 짧은 분기

보상은 없다. 같은 입력에 예측 가능한 응답을 주되 최근 사용 대사 순환으로 과한 반복을 줄인다. 단순 반복 대사를 듣지 않아도 미열람 카운트가 쌓이지 않는다.

### D01 · 오늘의 의뢰

O: 지금 이어서 할 수 있는 의뢰를 찾아볼까요?
- 「추천 하나만 알려줘요.」 → O: 진행 중인 목표부터 보여드릴게요. 이미 모은 기록도 이어서 쓸 수 있어요. → 현재 퀘스트 카드
- 「오늘은 이야기만 할게요.」 → O: 좋아요. 의뢰함은 닫아둘게요. → 대화 화제 목록

추천 결과가 없는 경우: O: 지금 급히 확인할 의뢰는 없어요. 자유 활동이나 지난 기록을 볼 수 있어요. 실제 존재하지 않는 의뢰를 생성하지 않는다.

### D02 · 잠깐 쉬기

O: 잠깐 쉬어갈까요?
- quiet 기억: 「오늘도 잠깐 조용히 있어요.」 → O: 좋아요. 창문만 조금 열어둘게요.
- smallTalk 기억: 「오늘의 사소한 이야기 있어요?」 → O: 서류 모서리를 맞추다가 제 메모만 거꾸로 꽂았어요. 남의 기록은 두 번 확인하면서요.
- joke 기억: 「휴식 규정, 아직 유효하죠?」 → O: 물론이죠. 오늘은 보고서 이야기 금지 조항도 넣었어요.
- 공통: 「나중에 쉴게요.」 → O: 네. 필요할 때 다시 불러주세요.

### D03 · 음료

O: 오늘은 어떤 걸로 할까요?
- 「지난번에 골랐던 걸로요.」 → drink 기억에 맞는 준비 대사. 기억이 없으면 이 선택을 표시하지 않는다.
- 「오늘은 바꿔볼래요.」 → 따뜻한/시원한/그때그때 선택. 취향 기억만 갱신, 호감도 없음.

### D04 · 책상 구경

O: 오늘은 어떤 게 궁금하세요?
- 「첫 보고서요.」 → O: 여기 있어요. 지나간 건데도 꺼내보면 그때 생각이 나요. → 실제 첫 기록 또는 아직 없음 응답
- 「작은 그림이요.」 → 낙서 기억에 따른 응답. 미해금이면 선택을 표시하지 않는다.

### D05 · 오늘 기분

낮은 관계 O: 오늘은 관측값이 잘 정리돼서 마음이 놓여요. 아직 확인할 건 조금 남았지만요.

높은 관계 O: 오늘은 일 얘기 말고 먼저 인사하고 싶었어요. 보고서는 잠깐 기다려도 되니까요.
- 「저도 반가워요.」 → O: 그럼 인사는 성공이네요. 오늘도 잘 부탁해요.
- 「무슨 일 있었어요?」 → O: 특별한 일은 없어요. 특별한 일이 없을 때도 이야기하고 싶어서요.

### D06 · 다음 약속

R11 완료 이후에만 노출한다.

O: 지난번 약속, 어떻게 이어갈까요?
- 「조금 더 개인적인 시간으로요.」 → O: 좋아요. 저도 우리 이야기부터 하고 싶어요. → closer로 변경
- 「든든한 동료로 함께해요.」 → O: 네. 그 말도 저한테는 특별해요. 앞으로도 잘 부탁해요. → partnership으로 변경
- 「아직은 천천히 생각할게요.」 → O: 괜찮아요. 오늘 대화부터 편하게 해요. → undecided로 변경

변경은 확인한 현재 선택만 저장하고 기존 추억은 그대로 둔다. 이 대화로 추가 호감도나 반복 보상을 주지 않는다.

## 원고 점검 규칙

- 12편 모두 선택 후 응답과 합류가 있다. choice ID는 장면 안팎에서 중복하지 않는다.
- R07은 R02, R09는 R07, R10은 R06, R12는 R11을 선행 조건으로 둔다. 기억이 없는 선택의 후속은 기본 응답으로 처리한다.
- 본편 사실을 기억하지 못한 이용자를 위해 관련 본편 보기로 연결하되 개인 대화 취소를 허용한다.
- 사용자 취향을 실제 현실 정보로 확대하지 않는다. 컵·음료·책상은 허구의 지부 안에서 선택한 설정이다.
- 성인다운 해요체를 유지한다. 친해졌다는 이유로 자동 반말, 과한 아기 말투, 임의 이름을 읽는 다른 TTS를 섞지 않는다.
