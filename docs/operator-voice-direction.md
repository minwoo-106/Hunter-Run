# 오퍼레이터 음색 · 선택 기록

## 사용자 피드백
- A(F1)는 이전 후보 중 상대적으로 낫지만 A~C 모두 원하지 않는 기본 음성 느낌.
- D(F4), E(F5)도 B/C와 비슷하게 들려 거절.
- 요청: 조금 귀여우면서 차분한, 캐릭터성 있는 오퍼레이터 목소리.
- 프리셋 선택과 새 음색 설계를 구분합니다. 후보를 최종 음성으로 부르지 않습니다.

## VoiceDesign 첫 청취 피드백
- 기존 A~E보다 훨씬 좋다는 사용자 평가.
- 첫 번째 clear의 중간중간 자연스러운 숨소리를 특히 선호합니다.
- clear보다 조금 더 씩씩하고 밝게 조정 요청.
- 두 번째 velvet은 힘이 없어 제외합니다.
- clear 지시문과 시드 741을 기준으로 밝고 다정한 조정 / 한층 씩씩한 조정을 생성 중입니다. 설명을 바꾸는 재합성이므로 음색의 완전한 동일성을 보장하지 않습니다.

## 새 제작 방식
- 공식 Qwen3-TTS VoiceDesign: https://github.com/QwenLM/Qwen3-TTS
- 모델: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-VoiceDesign
- 고정 revision: 5ecdb67327fd37bb2e042aab12ff7391903235d3 (Apache-2.0 표기).
- 모델은 개발 PC에서만 사용하고 앱에는 확정된 녹음 WAV만 넣습니다.
- 실존 성우/유명인 녹음을 복제하지 않고 성인 여성의 음색·말투 설명으로 생성합니다.
- 맑고 다정한 톤 / 부드럽고 차분한 톤 두 방향. 과한 애교, 어린아이 느낌, 과장된 긴박감은 피합니다.
- `scripts/design-operator-voice.py`에 대사, 지시문, 시드와 생성 방식을 기록합니다.
- 샘플은 outputs/voice-designed-audition에 보존하며 최종 승인 전 앱에는 넣지 않습니다.

## 확정 후 순서
1. 사용자가 샘플 청취로 음색을 고릅니다. 합성 성공이나 파형 검사는 청취 검증을 대신하지 않습니다.
2. 선택된 자체 생성 음색을 참조해 기존 핵심 안내 14문장을 같은 목소리로 제작합니다.
3. 한국어 발음·대사 누락·끝 잘림, 긴 문장의 호흡, 스피커와 AirPods 상대 음량을 확인합니다.
4. 실제 활동 사건 타이밍에 맞춰 길이와 묵음·음량을 조절합니다.
5. v1 전체 대사/상황별 변형/반복 피로도 방지로 확장합니다.

현재 새 API 결제나 유료 가입은 하지 않았습니다. 성우 녹음 또는 유료 음성 서비스로 전환할 경우 실제 후보와 필요한 비용을 먼저 제시합니다.

## 밝은 조정본 피드백
- 사용자: 밝고 다정한 조정본 1번이 매우 좋음.
- 더 성숙한 음색 vs 더 귀여운 캐릭터 외형 중 어느 쪽이 좋은지 상담 중입니다.
- 제안: 1번의 밝음·자연스러운 숨소리를 유지하고, 기존 성인 캐릭터의 정체성과 복장은 유지하면서 눈매·작은 미소만 부드럽게 조정합니다. 위험 상황에서는 말투가 진지해지는 대비를 줍니다.
- 외형 편집은 아직 실행하지 않았습니다. 사용자 최종 디자인 방향을 확인한 뒤 적용합니다.
- 선호 음성: outputs/voice-designed-brighter/operator_bright_gentle.wav, 13.67초. manifest에 지시문/시드741/체크섬 기록.

## 2026-09-12 실제 대사 재조정
- bright_gentle 샘플을 참조한 14개 Base 합성 안내는 어린아이 같다는 피드백으로 거절. 배포 제외.
- 24세 성인 여성 설명으로 직접 설계한 실제 활동 안내 8.16초를 생성. 이후 더 성숙한 10.48초 후보와 비교했고, 사용자는 이전 8.16초 버전을 선호했습니다.
- 선택 참조: outputs/voice-adult-probe/operator-adult-activity.wav. 생성 지시문과 체크섬은 같은 폴더 manifest.json에 기록.
- 선택 참조로 활동 시작/발견 두 개만 Base 합성한 outputs/operator-adult-calibration을 청취 확인 중입니다. 전체 14개에 앞서 실제 대사 음색을 확인합니다.
- 캐릭터는 성인 22세 느낌의 큰 눈과 남색 브릿지로 변경, 사용자 승인 아래 Python으로 배경 제거 완료. docs/operator-art-v2.md 참고.
