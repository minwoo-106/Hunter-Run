# 9. 음성 반복 방지 원칙

최종전의 필수 정보는 한 번만 말한다.

센서 대기나 안전 정지 때문에 구간이 길어진다고 해서 스토리 음성을 처음부터 반복하지 않는다.

반복 가능한 것은 짧은 시스템형 안내뿐이다.

예:

- “여기서 기다릴게요.”
- “다시 잡혔어요.”
- “무리하지 마세요.”
- “신호 확인 중이에요.”

스토리 핵심 대사는 재생 완료 플래그를 남기고 한 번만 재생한다.

이렇게 해야 실제 러닝 중 신호 문제나 신호등 정지가 있어도 장면이 부자연스럽게 반복되지 않는다.
