# v1 남은 작업과 확인 기준

0.8 코드까지: 실제 활동 기록·모드·장비·부서 성장·누적 보스·이미지 도감·통신 기록·첫 이용 안내·개인 페이스 학습과 관측 보고·개인 서명 설치 경로를 구성했습니다. v1 전체 완성 선언은 하지 않습니다.

## 다음 기능 묶음
- 0.8에서 장기전/기습, 사건 시점 변화, 반복 대사 변형을 구현했습니다. 다음은 개체별 패턴·보스 단계별 음성, 더 많은 통신 대사와 모드별 콘텐츠 확대입니다.
- 현장 페이스 조정: 0.6의 최근 페이스 표시와 학습 결과를 실제 걷기·달리기에서 확인하고 신호 품질에 맞게 보정합니다. 합성 속도 재현 검사는 통과했지만 실제 GPS 잡음 원인은 기기 관측으로 확인합니다.

## 제작 마감 묶음
- 정식 한국어 오퍼레이터 음성: 캐릭터 톤·말 빠르기·발음 샘플 확인 후 전체 클립 교체. 0.8에 사용자가 승인한 음색의 19개 안내를 적용했습니다. 이후 상황별 대사와 통신 기록 음성을 확장합니다.
- BGM·효과음: 음량과 반복 피로도 조정, 음성·외부 음악·에어팟 전환 확인.
- 성장 밸런스: 실제 5/20/30분 기록에서 자원·승급·시설·장비의 도달 시간을 측정하고 조정.

## 실기기 완료 기준
- 20~30분 화면 잠금 활동, 정지와 재개, GPS 불안정, 이어폰 분리와 통화 후 일시정지·복구 확인.
- 앱 재실행·업데이트·백업 복원 시 진행도와 보스 HP 유지.
- 지원 화면 크기에서 주요 조작이 잘리지 않고 큰 글자에서도 스크롤 접근 가능.
- 모의 활동은 실제 성장과 기록을 바꾸지 않음.

0.5.0 테스트 완료는 사용자가 확인했습니다. 후속 변경의 실제 소리와 센서 동작은 별도로 확인합니다.
