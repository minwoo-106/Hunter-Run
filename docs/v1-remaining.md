# v1 남은 작업과 확인 기준

0.5까지: 실제 활동 기록·모드·장비·부서 성장·누적 보스·이미지 도감·통신 기록·첫 이용 안내·개인 서명 설치 경로를 구성했습니다. v1 전체 완성 선언은 하지 않습니다.

## 다음 기능 묶음
- 장기 페이스 참고: 양호한 GPS와 충분한 달리기 표본을 가진 실제 활동만 반영하고, 걷기·정지·차량·모의 활동을 제외합니다. 표본이 부족하면 기존 활동별 보정으로 돌아갑니다. 사용자가 이전 기록을 지울 수 있어야 합니다.
- 활동 후 피드백: 기록 품질과 기준 페이스의 신뢰도를 설명하고, 다음 활동에 반영된 이유를 볼 수 있게 합니다. 최대 속도를 요구하거나 무리한 기록 경쟁을 만들지 않습니다.
- 더 다양한 사건 구성: 모드별 차이를 늘리되 복구 중 대사와 판정이 앞서가지 않는지 검사합니다.

## 제작 마감 묶음
- 정식 한국어 오퍼레이터 음성: 캐릭터 톤·말 빠르기·발음 샘플 확인 후 전체 클립 교체. 현재 임시 음성 14개는 최종 품질이 아닙니다.
- BGM·효과음: 음량과 반복 피로도 조정, 음성·외부 음악·에어팟 전환 확인.
- 성장 밸런스: 실제 5/20/30분 기록에서 자원·승급·시설·장비의 도달 시간을 측정하고 조정.

## 실기기 완료 기준
- 20~30분 화면 잠금 활동, 정지와 재개, GPS 불안정, 이어폰 분리와 통화 후 일시정지·복구 확인.
- 앱 재실행·업데이트·백업 복원 시 진행도와 보스 HP 유지.
- 지원 화면 크기에서 주요 조작이 잘리지 않고 큰 글자에서도 스크롤 접근 가능.
- 모의 활동은 실제 성장과 기록을 바꾸지 않음.

0.4.0 테스트 완료는 사용자가 확인했습니다. 후속 변경의 실제 소리와 센서 동작은 별도로 확인합니다.
