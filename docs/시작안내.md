# Hunter Run 0.9.0 안내

오퍼레이터 전체56개 안내를 밝고 다정한 해요체로 교체했습니다. 실제 처치·피해·조사 결과와 개체 이름을 구분하고, 두 보스의 단계별 안내와 협회 통신6편의 짧은 음성 요약, 재생 대사에 맞춘 자막을 추가했습니다.

## 검증 완료 빌드
Codemagic19, 소스1346c58, Mac mini M2, 9분3초. 로직84개와 iPhone UI9개 테스트 통과. Release 컴파일, ZIP/IPA, 실제 포함된 음성56개 해시 검증 완료.
[다운로드 페이지](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa4bd20f3a3b494a30e757f?open-setting=build-artifacts).

## 업데이트
Artifacts의 **HunterRun-0.9.0-build10-install.zip (52.24MB)**을 받아 파일 앱에서 압축을 풀고, AltStore → My Apps → +에서 **HunterRun-0.9.0-build10-unsigned.ipa**를 선택합니다. 기존 앱을 삭제하지 않고 같은 Apple 계정으로 덮어 설치합니다.
홈 하단의 **FIELD DEMO · 0.9.0** 표시를 확인합니다.
[새 기능과 전체 대사](0.9-오퍼레이터-대사.md), [설치·센서 테스트](아이폰-첫테스트.md).

먼저 설정에서 목소리를 듣고, 준비 화면 하단 **20분 의뢰 모의 활동 · 장기전 포함**을 10배속으로 확인해보세요. 실제 기록과 보상에는 영향을 주지 않습니다. 협회 통신의 해금된 기록에서 ‘오퍼레이터 통신 듣기’도 확인할 수 있습니다.
