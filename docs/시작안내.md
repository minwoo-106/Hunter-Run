## 처음 실행할 때
[한국어 설치·첫 테스트 안내](아이폰-첫테스트.md)를 참고합니다.
- RUN에서 위치 권한을 허용하고, 외부 음악을 켠 상태로 음성 테스트.
- 첫 실제 테스트는 5분, 추격 OFF로 시작.
- 정상적인 이동과 정지를 확인한 뒤 20~30분 테스트로 확장.
- 가짜 센서로 확인하려면 3분 모의 러닝 사용. 모의 보상은 실제 진행에 반영되지 않음.

## 안내
가입·인증·기기 신뢰·개발자 모드 등 본인 조작이 필요한 단계는 별도로 안내합니다.
미서명 IPA는 다운로드만으로 설치되지 않습니다.
사용자가 설정한 무료 설치 경로의 호환성도 첫 테스트에서 확인해야 합니다.

## Windows 설치 준비
[AltStore Classic 공식 Windows 안내](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)를 따릅니다.
공식 안내에 연결된 iTunes·iCloud와 AltServer를 설치하고 iPhone을 USB로 연결합니다.
Apple 계정 로그인, 컴퓨터 신뢰, 개발자 모드 설정은 사용자가 직접 진행합니다.
AltStore Classic 설치 후 생성된 IPA를 개인 서명하여 설치합니다.
무료 개인 서명 앱은 7일마다 갱신이 필요합니다.
관련 제한과 갱신 방법은 [AltStore 공식 시작 안내](https://faq.altstore.io/altstore-classic/your-altstore)를 확인합니다.
