# Hunter Run 0.7.0 안내

하단은 홈 / 헌터 / 중앙 헌터 활동 / 협회 관리 / 도감 순서입니다.
홈의 큰 활동 버튼은 제거하고 이름·등급 아래 톱니바퀴로 설정을 엽니다.
활동 준비까지 BGM이 이어지며 활동을 시작하면 멈춥니다. 진행 중인 활동에서만 자동 잠금을 방지합니다.

## 검증 완료 빌드
Codemagic 17번 빌드 완료(소스 53e28a9, 9분 51초). 게임 로직 68개와 아이폰 화면 검사 8개, 실제 아이폰용 컴파일과 설치 파일 검증을 통과했습니다.
HunterRun-install.zip은 43.69 MB입니다.
[빌드 페이지](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa432a01c8c285ff0061c1a).

## 업데이트
Artifacts의 HunterRun-install.zip을 받아 파일 앱에서 압축을 풀고 AltStore → My Apps → +에서 HunterRun-unsigned.ipa를 선택합니다.
기존 앱을 삭제하지 않고 같은 Apple 계정으로 업데이트합니다. iPhone을 연결하는 PC에서 AltServer가 실행되어 있어야 합니다.
홈의 FIELD DEMO · 0.7.0 표시를 확인합니다.
[메뉴·자동 잠금 테스트](0.7-음성과-메뉴.md), [설치·센서 테스트](아이폰-첫테스트.md).

## 음성
이번 설치본은 기존 임시 음성을 유지합니다. 사용자에게 공개한 새 음색은 별도 청취본이며 앱에 아직 적용하지 않았습니다.
밝고 다정한 조정본 1번을 선호한다는 피드백을 받았고 캐릭터와의 분위기를 조율 중입니다.
