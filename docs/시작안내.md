# Hunter Run 0.11.0 안내

다크엘프·서큐버스 계열의 일반2종/엘리트2종, 장비8종, 협회 부서Lv.3, 전용대사16개를 추가했습니다. 승인 음성64개는 유지합니다.

## 업데이트

[다운로드 페이지](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa51cfe6d07de75e140b03f?open-setting=build-artifacts).
Artifacts의 **HunterRun-0.11.0-build13-install.zip (79.11MB)**을 받아 파일 앱에서 압축을 풀고, AltStore → My Apps → +에서 **HunterRun-0.11.0-build13-unsigned.ipa**를 선택합니다. 기존 앱을 삭제하지 않고 같은 Apple 계정으로 덮어 설치합니다.
홈 하단의 **FIELD DEMO · 0.11.0** 표시를 확인합니다.

## 새 콘텐츠 체험

헌터 활동 → 신규 개체 · 월영과 몽환 → 원하는 개체 모의 활동 준비 → 선택 개체 모의 활동 시작.
20분 분량을10배속으로 체험합니다. 모의 체험은 실제 발견·보상을 해금하지 않습니다.

실제 출현 조건과 연계장비는 [0.11 안내](0.11-월영과-몽환.md), 설치 문제는 [아이폰 첫 테스트](아이폰-첫테스트.md)를 참고합니다.
빌드 검증 결과와 설치 파일 체크섬은 WORK-STATUS.md와 build-0.11-manifest.json에 기록합니다.
