# Hunter Run 0.2.0 안내

## 현재 상태
- Codemagic 데모 빌드 6 성공: 커밋 d503224, 2026-09-11, Mac mini M2, 4분 30초.
- 게임 로직 검사 23개와 아이폰 화면·조작 검사 2개 통과.
- iPhone 17 Pro / iOS 26.5 시뮬레이터에서 검사. 사용자의 실기기 OS와는 다릅니다.
- 0.1.1 설치와 홈 화면 수정, 스피커·AirPods 음성 재생은 사용자 확인 완료.
- 새 0.2.0 설치와 실제 이동·화면 잠금 동작은 사용자 테스트가 필요합니다.

## 추가된 게임 기능
- 탐험·계약·게이트 모드. 게이트는 D급과 관측부 2레벨 달성 후 열립니다.
- 무기·방어구·신발·유물 12종 구매와 착용.
- 협회 4개 부서별 2레벨 확장 및 콘텐츠 해금.
- 등급 심사, 모드별 보상, 게이트 보스 코어.
- 기존 저장 데이터 읽기와 진행 중 러닝의 장비·사건 구성 보존.

## 업데이트
[성공한 빌드](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa38c51d8c577d2313b50c1)의 Artifacts에서 **HunterRun-install.zip (7.10 MB)**을 받습니다.
iPhone 파일 앱에서 압축을 풀고 AltStore → My Apps → +에서 **HunterRun-unsigned.ipa**를 선택합니다.
기존 앱을 삭제하지 않고 같은 Apple 계정으로 업데이트합니다.
설치할 때 iPhone을 연결하는 PC는 눈앞의 PC이며, 그 PC에서 AltServer가 실행되어 있어야 합니다.
홈 화면의 **PROGRESSION DEMO · 0.2.0** 표시를 확인합니다.

[설치·센서 테스트 안내](아이폰-첫테스트.md), [성장 기능 테스트 안내](0.2-성장-테스트.md).
