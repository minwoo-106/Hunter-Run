# Hunter Run 0.5.0 안내

홈의 큰 RUN으로 활동을 준비하고, 하단 중앙 협회 관리로 시설과 주요 보스 게시판을 엽니다.
장비 12종, 시간·거리·자유 목표, 활동 기록은 계속 사용할 수 있습니다.
이번에는 RUN 외 화면의 BGM 연속 재생, 첫 이용 안내 4장, 성장에 따라 열리는 협회 통신 6편을 추가했습니다.

[0.5 기능 테스트 안내](0.5-통신-테스트.md), [설치·센서 테스트](아이폰-첫테스트.md).

## 빌드
Codemagic 15번 빌드가 완료됐습니다(소스 74662e7, 9분 4초). 게임 로직 검사 51개와 아이폰 화면 검사 7개, 실제 아이폰용 컴파일과 설치 파일 검증을 통과했습니다.
HunterRun-install.zip 용량은 43.64 MB입니다.
[빌드 페이지](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa3f2b105d4cecd5b0308ad).

## 업데이트 방식
Artifacts의 HunterRun-install.zip을 받아 iPhone 파일 앱에서 압축을 풀고,
AltStore → My Apps → +에서 HunterRun-unsigned.ipa를 선택합니다.
기존 앱을 삭제하지 않고 같은 Apple 계정으로 업데이트합니다.
설치할 때 iPhone을 연결하는 눈앞 PC에서 AltServer가 실행되어 있어야 합니다.
홈 화면의 STORY DEMO · 0.5.0 표시를 확인합니다.

## 검증 구분
사용자가 0.4.0 적용과 테스트 완료를 확인했습니다.
이번 변경의 실제 거리 기록, 화면 잠금, 통화·이어폰 전환과 BGM 소리는 아이폰 확인이 필요합니다.

## 남은 작업
전체 v1 완성본은 아닙니다. 장기 페이스 학습, 현장 사건·음성 스토리 확장, 정식 오퍼레이터 음성과 음악 품질·밸런스 조정이 남아 있습니다.
현재 14개 안내 음성과 새 협회 BGM은 임시 제작본입니다.
