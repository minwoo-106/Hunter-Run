# Hunter Run 첫 데모 안내

## 현재 상태
- Swift 게임 엔진의 자동 테스트 14개 통과.
- iPhone 코드의 문법 검사 통과. Apple SDK 컴파일은 아직 실행 전.
- 사건 4개, 임시 한국어 음성 14개, 승인된 오퍼레이터 기반 분리 이미지 준비.
- 전체 v1이 아닌 설치·센서·오디오·저장 검증용 0.1 데모.
- 아직 설치 가능한 서명된 IPA나 실기기 테스트 결과는 없음.

## 다음 단계
1. GitHub 저장소를 Private으로 전환.
2. 이 프로젝트 폴더의 내용을 저장소 루트에 업로드.
3. Codemagic에서 Check for configuration files를 눌러 ios-demo 설정 확인.
4. 개인 계정 M2 무료 잔여 시간 안에서 빌드 실행. 유료 billing은 켜지 않음.
5. 성공한 빌드의 HunterRun-unsigned.ipa를 받음.
6. Windows AltServer/AltStore Classic으로 개인 서명 후 iPhone에 설치.

## 처음 실행할 때
- RUN에서 위치 권한을 허용하고, 외부 음악을 켠 상태로 음성 테스트.
- 첫 실제 테스트는 5분, 추격 OFF로 시작.
- 정상적인 이동과 정지를 확인한 뒤 20~30분 테스트로 확장.
- 가짜 센서로 확인하려면 3분 모의 러닝 사용. 모의 보상은 실제 진행에 반영되지 않음.

## 안내
가입·인증·기기 신뢰·개발자 모드 등 본인 조작이 필요한 단계는 별도로 안내합니다.
미서명 IPA는 다운로드만으로 설치되지 않습니다.
사용자가 설정한 무료 설치 경로의 호환성도 첫 테스트에서 확인해야 합니다.
