# Hunter Run 0.3.0 안내

## 이번 업데이트
홈의 큰 버튼이 협회 관리로 바뀌었고, 하단 중앙 RUN이 강조됩니다.
장비 12종에 개별 일러스트를 넣고 상세·착용 현황·보유 필터를 연결했습니다.
시간 목표 외에 1/3/5/10 km 거리 목표와 자유 활동을 고를 수 있습니다.
헌터에서 활동 기록 상세를, 메뉴에서 이용 가이드를 볼 수 있습니다.

[0.3 기능 테스트 안내](0.3-현장-테스트.md), [설치·센서 테스트](아이폰-첫테스트.md).

## 검증된 빌드
2026-09-11 Codemagic 데모 빌드 8, 커밋 51c061f, Mac mini M2, 6분 33초.
게임 로직 31개와 화면·조작 검사 4개 통과. 홈 콘텐츠와 하단 메뉴의 간격 검사도 포함합니다.
[설치 파일 페이지](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa3af69107aa975edb5028c)에서 HunterRun-install.zip (23.50 MB)을 받습니다.

## 업데이트 방식
Artifacts의 HunterRun-install.zip을 받아 iPhone 파일 앱에서 압축을 풀고,
AltStore → My Apps → +에서 HunterRun-unsigned.ipa를 선택합니다.
기존 앱을 삭제하지 않고 같은 Apple 계정으로 업데이트합니다.
설치할 때 iPhone을 연결하는 눈앞 PC에서 AltServer가 실행되어 있어야 합니다.
홈 화면의 FIELD DEMO · 0.3.0 표시를 확인합니다.

## 검증 구분
기존 버전의 설치, 홈 화면, 스피커·AirPods 음성은 사용자가 확인했습니다.
새 버전은 게임 로직과 클라우드 아이폰 컴파일·화면 검사 후 전달합니다.
실제 거리 오차, 화면 잠금 중 기록, 통화와 이어폰 변경 후 동작은 실기기 확인이 필요합니다.

## 남은 작업
전체 v1 완성본은 아닙니다. 주요 보스 누적, 장기 페이스 학습,
가입·세계관 도입, 몬스터 일러스트·사건 확장, 협회 외형 성장,
정식 오퍼레이터 음성·BGM과 밸런스 조정이 남아 있습니다.
현재 14개 음성은 임시 음성입니다.
