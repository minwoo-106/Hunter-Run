# iPhone 첫 테스트

이 버전은 센서·음성·저장 동작을 먼저 확인하는 0.1 데모입니다.
장비, 협회 성장, 전체 모드 등은 후속 v1 작업입니다.

## 설치

1. [공식 Windows 설치 안내](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)를 따라 AltServer와 AltStore Classic을 준비합니다.
2. [Codemagic의 성공한 빌드](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa353b068916f7168331c7d)에서 Artifacts를 열고 HunterRun-unsigned.ipa를 받습니다. Codemagic 로그인이 필요합니다. 별도의 artifacts.zip은 빌드 로그입니다.
3. IPA를 iPhone의 파일 앱에 저장한 뒤 AltStore Classic의 My Apps에서 + 버튼으로 선택합니다.
4. 개인 서명과 설치가 끝나면 Hunter Run을 실행합니다. Apple 계정 로그인과 기기 신뢰는 직접 진행합니다.

파일 다운로드만으로 설치되지는 않습니다. 무료 설치의 실제 호환성은 이 단계에서 확인합니다.
앱 실행이 막히면 오류 문구와 발생 단계를 알려주세요.

## 실내에서 3분

협회 화면에서 캐릭터와 RUN 버튼이 잘리는지 먼저 확인합니다.
다른 앱으로 음악을 재생한 뒤 RUN의 음성 테스트를 눌러 음성이 들리는지 확인합니다.
3분 모의 러닝을 실행해 사건 안내, 일시정지, 결과 화면을 확인합니다.
모의 러닝은 실제 경험치와 보상을 올리지 않습니다.

## 밖에서 5분

안전하게 이동할 수 있는 곳에서 실제 러닝 5분, 추격 OFF로 시작합니다.
위치·동작 권한을 허용하고 화면을 잠근 채 걷거나 가볍게 달립니다.
중간에 약 15초 멈췄다가 다시 움직입니다. 종료 후 거리·활동 시간·정지 기록을 확인합니다.
직접 일시정지한 상태에서는 움직여도 자동으로 재개되지 않아야 합니다.

## 알려주실 내용

- 설치 성공 여부와 오류가 있었다면 정확한 문구
- 화면이 잘리거나 버튼을 누르기 어려운 곳
- 화면 잠금 후 거리·시간 기록과 음성의 지속 여부
- 음악과 음성의 크기, 안내가 잘리거나 겹치는 현상
- 정지·재개가 지나치게 늦거나 기록이 사라지는 현상

처음에는 이 다섯 가지 피드백이면 충분합니다. 실제 기록이 안정된 것을 확인한 뒤 20~30분으로 확장합니다.
