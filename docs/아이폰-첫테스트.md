# iPhone 첫 테스트

0.3.0은 협회 중심 홈과 장비 일러스트, 거리·자유 목표, 활동 기록 상세를 추가한 버전입니다.
[새 기능 테스트 안내](0.3-현장-테스트.md)를 참고합니다.

## 설치

1. [공식 Windows 설치 안내](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows)를 따라 AltServer와 AltStore Classic을 준비합니다.
2. [Codemagic 빌드](https://codemagic.io/app/6aa34d1b5a8fa8a63bc40bb9/build/6aa3af69107aa975edb5028c)를 iPhone Safari에서 열고 로그인합니다. Artifacts에서 **HunterRun-install.zip**을 다운로드합니다. 이름에 빌드 번호가 붙은 Hunter-Run_…_artifacts.zip은 로그·시뮬레이터 화면·검사 결과 등의 진단 자료입니다.
3. iPhone의 파일 앱에서 다운로드한 HunterRun-install.zip을 탭하면 압축이 풀립니다. 생성된 폴더 안의 **HunterRun-unsigned.ipa**를 AltStore Classic → My Apps → +에서 선택합니다. [Apple의 ZIP 열기 안내](https://support.apple.com/ko-kr/102532)를 참고할 수 있습니다.
4. 개인 서명과 설치가 끝나면 Hunter Run을 실행합니다. Apple 계정 로그인과 기기 신뢰는 직접 진행합니다.

파일 다운로드만으로 설치되지는 않습니다. 무료 설치의 실제 호환성은 이 단계에서 확인합니다.
설치할 때는 iPhone을 눈앞의 PC에 USB로 연결하고 그 PC에서 AltServer를 실행해 둡니다. 원격으로 사용하는 집 PC와 구분합니다.
Safari 다운로드 목록에 재시도 버튼만 있으면 저장이 완료된 것으로 간주하지 않습니다. ZIP도 실패하면 다운로드 오류를 확인해야 합니다. 이 ZIP은 IPA를 파일로 전달하기 위한 포장이며, 인증이나 네트워크 오류를 해결한다고 보장하지 않습니다.
앱 실행이 막히면 오류 문구와 발생 단계를 알려주세요.

## 0.3.0 업데이트 확인

기존 앱을 삭제하지 말고 AltStore에서 새 IPA를 기존 앱 위에 업데이트로 설치합니다. 같은 Apple 계정을 사용합니다.
앱을 다시 열어 협회 화면 아래에 **FIELD DEMO · 0.3.0**이 보이는지 확인합니다.
오른쪽 헌터명·등급과 RUN 카드의 오른쪽 모서리가 화면 안에 들어와야 합니다.
첫 설치 때 AltStore가 형식 오류를 띄운 뒤 앱은 실행됐다는 보고가 있습니다. 원인은 미확인입니다.
AltStore My Apps에도 Hunter Run과 만료 기간이 표시되는지 별도로 확인합니다.

## 실내에서 3분

협회 화면에서 캐릭터와 RUN 버튼이 잘리는지 먼저 확인합니다.
다른 앱으로 음악을 재생한 뒤 RUN의 음성 테스트를 눌러 음성이 들리는지 확인합니다.
3분 모의 러닝을 실행해 사건 안내, 일시정지, 결과 화면을 확인합니다.
모의 러닝은 실제 경험치와 보상을 올리지 않습니다.

## 밖에서 5분

안전하게 이동할 수 있는 곳에서 실제 러닝 5분, 추격 OFF로 시작합니다.
위치·동작 권한을 허용하고 화면을 잠근 채 걷거나 가볍게 달립니다.
중간에 약 15초 멈췄다가 다시 움직입니다. 종료 후 거리·활동 시간·정지 기록을 확인합니다.
직접 일시정지한 상태에서는 움직여도 자동으로 재개되지 않아야 합니다.

## 알려주실 내용

- 설치 성공 여부와 오류가 있었다면 정확한 문구
- 화면이 잘리거나 버튼을 누르기 어려운 곳
- 화면 잠금 후 거리·시간 기록과 음성의 지속 여부
- 음악과 음성의 크기, 안내가 잘리거나 겹치는 현상
- 정지·재개가 지나치게 늦거나 기록이 사라지는 현상

처음에는 이 다섯 가지 피드백이면 충분합니다. 실제 기록이 안정된 것을 확인한 뒤 20~30분으로 확장합니다.
