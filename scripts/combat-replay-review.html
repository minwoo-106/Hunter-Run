재생 속도는 입력 단계 기준입니다. 실제 음성은 재생하지 않으며, 안내가 발생한 시점과 종류를 오른쪽에 표시합니다. 마지막 정산 전에는 EXP가 0으로 보이는 것이 정상입니다.

자동 판정 결과

    이 판정은 마지막 단계의 실제 결과와 고정된 기대값을 비교한 것입니다.

    현재까지의 주요 변화

    직접 다른 입력을 재생하려면

    거리·속도·움직임·GPS 상태가 들어 있는 입력 파일을 내려받아 수정한 뒤 실행기에 넣을 수 있습니다. 정지·복귀·앱 복구·세션 전환도 같은 파일에 기록합니다.

    입력 내용과 실행 방법 보기

    속도는 m/s, 거리는 이번 입력에서 이동한 m입니다. GPS가 여러 초를 묶어 보낸 거리는 distanceDuration에 해당 시간을 함께 적습니다. 재생 화면 자체는 수정한 입력을 계산하지 않습니다.

    swift run HunterDebugRunner --scenario 입력파일.json --output 검증결과

    python3 scripts/build-combat-replay-review.py 검증결과

    합성 입력을 사용한 검증입니다. 과거 활동 보고의 거리·페이스 합계는 실제 GPS 원본이 아니므로 정밀 재생 자료로 취급하지 않습니다. 센서 흔들림과 음성 간격의 체감은 실제 기기에서 별도로 확인해야 합니다.
